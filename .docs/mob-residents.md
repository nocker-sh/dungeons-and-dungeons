# 住民の造形

名前・紹介・台詞・画像参照は[[concept/data/characters.json|住民データ]]、本人固有の暮らし・来歴・造形は個別資料を正とする。名簿、生成順、完了件数をここに複製しない。

- 通常と会話は顔と両目を相手へ向ける。仕事中の固有の仕草とは分ける。
- 会話中は口の動きだけでなく、本人に合う控えめな手・肩・胴の動きを付ける。道具を見るために相手から目線を外さない。
- 年齢、体形、髪、本人の目の形・色・瞳孔、職業の道具を保持する。
- 虹彩の蛍光色は単色のベタ塗りで表す。光沢や発光エフェクトへ変えない。閉眼や髪に隠れた目を勝手に開かない。
- 目を四角や台形へ戻さず、曲線と少数の太いまぶたの線で個性を出す。ダンの白目は上側も滑らかな楕円にする。
- 部屋着では仕事の装備と道具を外す。衣服を替えたことから未設定の私生活を確定しない。

共通の塗りと構図は[[image-generation]]、取り込みは[[artwork]]を参照する。
