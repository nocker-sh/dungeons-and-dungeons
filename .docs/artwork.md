# 画像素材の取り込み

絵柄・造形・構図は[[image-generation]]、対象固有の条件は個別の設定資料を正とする。採用中の画像は実行用JSONから確認する。過去のファイル名一覧を採用状態の根拠にしない。

## 原画と表示用画像

- 原画は加工せず保存する。元PNG、生成時の参照、正確なプロンプト、採用・差し戻しの根拠は制作記録として保持する。プロンプトは公開可能とする。
- 表示用画像は原画から生成する。公開画像の配置は移行用の実装詳細であり、設定資料から一時パスを参照しない。
- 人物・敵の全身と上半身は3:4。画像を変形せず、必要な透過余白を足す。上と左右に髪・手・袖・武器を収め、胴と衣服は下端まで連続させる。
- v0とv1、通常・表情・衣装・攻撃を別の用途として扱う。ファイル名の版番号だけで採用を決めない。

## 変換

`vp exec bun scripts/prepare-artwork.cjs <元PNG名...>` で取り込む。対応する原画と公開先は取り込み表へ登録する。

- 画質82から始め、可視画素のPSNR 36 dBを下回る画像は86・90・95・100の順に上げる。届かない場合は可逆圧縮を使う。品質基準を下げない。
- アルファ品質100とし、透過画素の一致を確認する。白い服・歯・白目を背景と一緒に抜かない。
- 背景除去は外周につながる白と、目視で背景と確認した指定領域だけに適用する。追加の背景シードと明度の指定は[[scripts/artwork-background.cjs|背景除去処理]]の入力に合わせる。
- 複数枚の変換は `ARTWORK_CONCURRENCY=4` で最大4枚。既定は1。並列でも品質・アルファの検証を省かない。

## 登録と確認

- [[concept/data/images.json|実行用画像一覧]]へ公開パス・原画・レビュー状態を登録し、対象データの画像参照と対応させる。
- 通常、表情、衣装、攻撃、ワザ、睡眠、戦闘不能を取り違えない。攻撃の対応は[[monster-attacks]]を参照する。
- 原画と変換後の輪郭・顔・手・透過を照合し、実行データ・配信画像・画面で同じ画像を使っていることを確認する。
- 画像本体はコミットしない。プロンプトの公開可否と、原画の配信・Git管理は別に扱う。
