# Sitemap

ゲームは `/` 一つで動くSPA。画面はゲーム内の場面として切り替え、URLは変えない。下の名前は画面の呼び名（`client/components/screens`）。

各画面の目的・主役・操作は [[ux-design|ゲームUX設計]]、動きは [[ui-direction|画面演出]] を参照。画面コンセプトを採用した理由は[[decisions/003-mock-into-app]]、現在の受入条件は[[features]]を参照する。

## 常設

- 隊列（Formation）：下端に3人の札（上半身・HP・防具耐久・Lv）。押すと立ち絵、戦闘中は詳細。左上にバッグ。
- バッグ：アイテム・装備・素材のタブ。

## 街

- 街（トップ）：見出しなし。主役は「ダンジョン」。吹き出しは「冒険者ギルド」「商店街」（市場への脇道）「ダンジョン」（奥の門から街はずれへ）。名前の登録前はダンジョンを押せない
- 冒険者ギルド（ホール）：絵の位置に「受付」「宿」「秘密の部屋」
  - 受付：受付嬢と「クエスト」「募集」「会話」。名前の登録もここ
    - クエスト：探索の討伐依頼・街・農場の一覧（引き受ける・報告する・戦う）
    - 募集：一覧（雇う）
  - 秘密の部屋：召喚石で悪魔を召喚し、契約する
  - 宿：「屋根裏」「普通の部屋」「高い部屋」
    - 部屋：料金と効果、「泊まる」→ 夜 → レベルアップ → 雑談 → 朝
- 商店街：「武器と防具」「道具屋」「薬屋」
  - 店：店主と「購入」「売却」「会話」、武器と防具・道具屋は「鑑定」

## 大渓谷

- 探索：道のり図と「進む」「撤退」。分岐では地点を押して選ぶ。宝箱・罠・戦利品の板
- 戦闘：行動順のリボルバー、指示（攻撃・ワザ・防御・アイテム）、1行動1結果
