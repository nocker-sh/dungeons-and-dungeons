# モンスターの攻撃と画像

2026-10-13のユーザー依頼に基づく制作・実装方針。攻撃の動作を先に決め、その動作に合う画像を設定する。数値の最終バランスを確定する資料ではない。

## 攻撃の決め方

- 基本の標的は画面手前のプレイヤー。顔・視線だけでなく、打撃面や飛び道具の先端・軌道もこちらへ向ける。攻撃先が左右の画面外や地面に見える画像は採用しない。奥の発射元から手前へ迫る遠近と重なりで示す。
- 通常攻撃は、その個体が実際に持つ部位を使う。鳥の足、蟹のハサミ、壁の岩拳、スライムの粘腕、スネイルの殻など。名称と近接・遠距離は実行用の `world.json` の `attack` を正とする。
- ワザは `foes.json` の `skills` が示すものを使う。名称と効果は `skills.json`、本人に合わせた呼び名は `world.json` の `skillNames` を正とする。足で蹴るダックに爪を追加しない。
- 同じ動作で威力や対象数だけが異なる場合は画像を共用できる。物理的な打撃と、毒・結晶・歯車・星・呪いの放出は分ける。状態異常は結果の演出でも示す。
- 色違いと個体差は本人の通常を参照して描く。通常の手足・触手・翼の数、顔と目、眼柄、殻・帽子・武器の大きさを固定する。別個体の攻撃画像を借りない。

## 画像の対応

- `world.json` の `attackImage` が通常攻撃、`skillPortraits` のワザIDが各ワザの3:4全身画像。同じワザIDでも、モンスターが違えば本人の画像を登録する。
- `appearances` にも本人の `attackImage` と `skillPortraits` を置く。元種だけの設定で色違いへ誤った画像が流れないようにする。
- 戦闘はエンジンが返す `acted.skill` で画像を選ぶ。手番の番号で異なる攻撃画像を巡回しない。通常攻撃や未登録のワザは本人の通常攻撃画像、なければ通常画像へ戻る。
- 敵の行動は一度だけ確定し、画像のデコードと描画を待って攻撃を開始する。表示HPは結果の演出が到着するまで保持し、手番の終了は演出の完了を待つ。
- `/dev/monsters/{slug}` では通常・通常攻撃・本人の各ワザ・睡眠・戦闘不能を名前付きで確認する。shadcnの既存Cardを使い、セクション一覧を保つ。

## 造形を確認する場所

各個体の動作と固定条件は [[concept/README|モンスター資料]]、参照・プロンプト・制作出力は [[concept/prompts/monster-attacks.json]]、原画は `private/art/originals/`、公開素材と人のレビューは [[concept/data/images.json]] に置く。

生成物を通常と並べ、部位の本数・接続・眼と瞳・配色・殻や翼の比率・効果の見切れ・透過を確認する。人の画像承認はAIの確認と分け、AIが合格を記録しない。
