# 画面演出のコンセプトと脚本

## 一手一幕

一回の操作を短い映像の一幕として見せる。操作、結果の提示、次の判断を一つの流れにし、今見せたい物を一つに絞る。世界はファンタジーとして描き、無機質なサイバー表現や意味の重複する英語の飾りを足さない。

この文書は演出意図を定める。画面の構造は[[sitemap]]、操作条件は[[features]]、時間・入力・終了処理の契約は[[animation-rules]]を正とする。

## 画面の文法

- 主役は一つ。判断するときは主操作、結果を受け取るときは敵・品物・数字を主役にする。
- 脇役は背景や背後の層に置く。詳細を求めたときにだけ前へ出し、閉じると元の位置へ戻す。
- 敵・場所・報酬は登場時に名前とともに紹介する。常設の説明板で画面を埋めない。
- 文字を無理に傾けず、板・配置・大きさで勢いを付ける。日本語の可読性と操作領域を守る。
- 場所は背景の絵とカメラで示す。カメラの移動と要素の登退場を組み合わせ、場面が変わったことを伝える。
- 絵がない部分は色付きの仮表示を使う。既存の無関係な絵を流用して完成扱いにしない。
- スクロールは必要な一覧の内側へ閉じる。詳細・会話・演出が前面にある間は背面の操作を受け付けない。

## 動きの目安

| 種類 | 見せ方 | 目安 |
| --- | --- | --- |
| 登場 | 画面外から入り、少し行き過ぎて止まる | 0.35〜0.5秒 |
| 退場 | 次の場面を邪魔しない方向へ加速して抜ける | 0.2〜0.3秒 |
| 小さな出来事 | 一つの変化を一拍として読ませる | 0.12〜0.25秒 |
| 名前 | 文字を順に着地させる | 一字0.04〜0.07秒ずらす |
| 数字 | 変化を大きく見せ、対象へ戻す | 0.4〜0.8秒 |
| 衝撃 | 揺れ・閃光・集中線を短く重ねる | 0.1〜0.3秒 |

これらは演出設計の目安で、操作完了を待つための固定sleepには使わない。結果が読めることと、同じ操作を重複実行しないことを優先する。動きを減らす設定でも結果と完了通知を失わせない。

## 場面ごとの脚本

### 街と施設

街の主目的は次の出撃。背景の門・ギルド・市場への脇道と移動の吹き出しを一致させる。名前登録前の出撃は許可せず、ギルドの受付へ案内する。

施設へ入ると用事を主役にする。受付は登録・依頼・募集、店は購入・売却・鑑定、宿は部屋と宿泊を扱う。場所の階層は[[sitemap]]に従い、演出のために別の酒場・工房・独立した宿を増やさない。

### 出撃と探索

乗り場では到達済みの層を選び、昇降機で降りる。探索へ入ると層の名前と進行を見せ、次の主役を「進む」に渡す。出撃前に独立した長い準備画面を挟まない。

一歩進んだら、移動の手応え、出来事、次の判断の順に見せる。宝箱・罠・休息はそれぞれ一つの結果として提示する。分岐は選択肢の危険と報酬を比較できるようにし、分岐そのものを毎回大きな文字で紹介しない。

### 遭遇と指示

敵を名前とともに紹介し、戦う位置へ収める。指示中は現在の仲間・使えるワザ・選ぶ対象が分かるようにする。3人分の指示が揃うことと、倒れて指示できない仲間がいることを区別する。

敵を詳しく見るときは前へ出す。対象選択では射程や可否をQueryに従って表示し、画面独自の計算で選べる敵や味方を増やさない。

### 行動と結果

行動者とワザを提示し、必要な画像の読込・描画を待って動作へ入る。打撃・魔法・回復などの結果は対象へ到達したタイミングで数字と表示HPへ反映する。エンジンの確定値を演出より先に見せない。

戦闘不能や退場を含め、行動の完了を待って次の行動を開く。演出中の連打で支払い・結果・手番を重複させない。

### 帰還と成長

探索を終えた理由と結果を示し、持ち帰った報酬と成長へつなぐ。全滅時に失った物と残った物を混ぜない。成長演出は各人の変化を短く読ませ、次の支度へ戻す。

### 会話

立ち絵とセリフ枠を同じ登場・退場の寿命で扱う。同時に出す立ち絵は最大2人。3人目は誰かが退場してから入れる。悪魔の会話はプレイヤーと悪魔の二者に限定する。

登場中・終了処理中に送り入力を通さず、枠と立ち絵がそろってから会話を進める。表情・衣装・話者は実行用台本へ対応させる。

## 確認方法

[[dev-studio]]で場面・種・隊列・敵・HP・表示サイズを固定し、途中時刻と実際の操作を確認する。静止画だけでなく、登場・判断・結果・退場のつながりを通す。画像の同一性、演出の再現性、操作の分かりやすさを別々に評価する。
