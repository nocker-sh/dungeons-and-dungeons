# 物語の自動検証

物語を変更するときは、開始条件・選択肢・状態変化・得るもの・繰り返した結果を、本番データと実際の進行処理に対するテストへ反映する。テスト専用の進行規則や台本を作らない。乱数・時計・ID・保存先などの外部境界だけを固定する。

`vp run test:story` はブラウザなし、1ワーカーで会話のデータ検証・条件判定・実操作・保存再開の検査を実行する。全体テストにも同じ検査を含む。重い検査は直列で行い、ブラウザ確認は並列実行しない。

`tests/builder/discovery-resumption.test.ts` は正本の全層・全発見地点・全選択肢と提示される全祝福を、隣接地点から本物の前進処理へ通す。未知の地点では2つの開始種から有限範囲で種を探索し、発見へ到着する実際の抽選を使う。候補を見つけられなければ失敗し、対象を除外しない。金貨・素材・HPの不足と未選択の結果表示の終了を拒否し、全保存内容と乱数・ID連番を変えないこと、表示された代償と実際の支払い・所持品・HPが一致することを照合する。選択の前後でSessionをJSONから作り直し、重複選択・結果表示の終了・帰還・再帰還の拒否を通常進行と全保存内容で比較する。所持金・素材・到達層・隣接地点は局所的な開始条件で、発見の未処理状態や報酬は注入しない。入手・育成・層の入口からの全経路、全ての乱数種・祝福の全受取人・全負傷条件・画面の配置は対象外。

`tests/client/components/game/focus-lifetime.test.ts` は本物のキーボード・パッド操作の購読と、正本の品物を使う売買をつなぐ。実際のDOM変更から予約される選択更新を終了時に取り消し、取消済みの処理を配送しても新しい操作の選択と決定を保つことを検査する。古いパッド更新は購入や次の予約を行わず、購入中に操作処理が終了した場合は、その購入だけを確定して続く取消操作と再予約を行わない。品物は本物の購入で用意し、終了しない通常の処理と全保存内容を照合する。所持金と街は局所条件で、差し替えはDOM・機器API・フレーム配送と画面を閉じる出力だけとする。再生する入力の寿命とゲーム結果の検査であり、街への到達・画面の全遷移・実機の配送・最終画像は対象外。

## 条件の検査と到達の検査

会話を読み込む入口は、ID・話者・場所・進行度・要求フラグの生成元を照合する。同じフラグを要求と除外の両方に指定した台本は、開始不能な条件として拒否する。実データを変えて入口が拒否する回帰テストも保つ。形が正しいことと、実際にその状態へ到達できることは別に検査する。

条件を与えた制作画面のシナリオは、その条件下の表示と操作可否を確かめるために使う。途中の進行度やフラグを直接与えた試験を、最初から到達できる証明へ読み替えない。実進行の検査は新しいゲームから本物のコマンドを送り、会話の開始と完了で生まれた状態を次の操作へ渡す。

`onboarding.test.ts` は新しいゲームから開幕の会話と選択肢を列挙して実操作で辿り、到達した台本と回答の集合を本番データの全件と照合する。選択で立つフラグを確認し、街へ出る・名前を登録する・受付の会話を終えるまで進める。実際に通った状態と遷移から、探索したどの状態にも開幕を終える経路があることを照合し、終端のない閉路を成功にしない。各操作後の保存をJSON経由で復元し、同じ初期状態と乱数・操作列から再実行した状態・会話の問い合わせ・イベント・保存結果が一致することも確認する。

`event-conversation-scene.test.tsx` は正本の全会話と全選択肢を、本物の Game・Query・保存デコーダー・React Context と EventConversationScene へ通す。会話の表示時に取得した ConversationPhase を終了通知まで保持し、通知時に現在の別の会話を取り直さない。別の保存へ読込んだ後の古い終了通知は、既存の PhaseBase の状態所有判定で拒否し、全保存状態・再生中の会話・未読と選択フラグを変えない。新しい表示の終了通知は本物の一操作を直接送った対照と一致し、二度届いても追加確定しない。各返答で自動保存を一回失敗させ、前の本文を保持し、操作を再送せず再保存してから別のゲームへ読込む。開幕から街へ着き最初の依頼を聞く二択は通常の本番コマンドで連続して進め、前の開幕通知が新しい話へ答えないこと、保存失敗直後に現在の所有者を破棄して古い本文から返答をやり直しても一度分の全状態と保存になることも確認する。全件の所有者検査では、必要な仲間・悪魔・親しさ・進行度・既読と依存フラグ、および会話中の状態は局所条件で、実デコーダーで正規化し Query の問題がないことを検査する。差し替えは固定の実行環境と保存先・書込み障害、EventConversationView への出力関数の観測と完了通知の配送だけで、View 本体と hooks は保つ。全会話の自然な解放やそこまでの入手・選択経路、各行と返答を読む UI 操作・DOM の入力と終了アニメーションの配送、同じ台本を同一の表示で再開始する経路、実機・最終画像はこの追加検査の対象外。

## 検査の境界
