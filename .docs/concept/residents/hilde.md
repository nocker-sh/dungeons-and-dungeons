# ヒルデ

来歴と暮らしの文は [[concept/data/conversation-profiles.json]] の `background` を正とし、ここには複製しない。台本は [[content/data/conversations.json]] の `hilde-talk-*` と、この人物が登場する `visit-*`。

## 制作上の決め事（確定）

- 鍛冶屋。巨人の骨片を素材に使うのは鍛冶屋（武器と防具の店ではない）。
- 炉の火を落とさない。

## 制作案

- 数えるもの：預かって打ち直した刃。取りに来ない客の分も棚に残しておく。
- 手放さないもの：炉の火と、父のハンマー。

## 関係

- オットー：元弟子。隣で武器と防具の店をひとりで営む。
- ミレナ：ミレナが街に来た日から世話している腐れ縁。幼なじみではない。

## 未決定

- 父の生死。ハンマーを「形見」とは書かない（台本に父の死の記述がないため）。

## 画像から確認した造形

大量の桃巻髪を後ろで結び、黄緑眼、筋肉質の腕。茶赤作業前掛け、白腰結びと金鎖、黒い大槌の金閉眼印。髪量と槌の大きさを保つ。

## 目の色

ユーザー指定で虹彩を #B9FF00 fluorescent lime の鮮やかな単色へ変更。色の強さを光沢や発光エフェクトにせず、ベタ塗りで表す。本人の目の形・視線・表情を保持。髪・口・体格・服・手・小道具・状態ごとの動作を元画像と照合し、網点の塗りを保持。

## 生活動線の制作設計

炉の仕事、骨の加工、食事、就寝を同じ床で済ませない。残り火は管理して保ち、作業後は粉と煤を落としてから居室へ戻る。

## 整合性を守る境界

父のハンマーを遺品と扱わず、骨の加工と寝具の保管を隣接させない。

来歴・会話・報酬をこの生活設計から書き換えない。収納と休息の場所は、ゲーム内の追加効果を意味しない。
