# オットー

来歴と暮らしの文は [[concept/data/conversation-profiles.json]] の `background` を正とし、ここには複製しない。台本は [[content/data/conversations.json]] の `otto-talk-*` と、この人物が登場する `visit-*`。

## 制作上の決め事（確定）

- 武器と防具の店をひとりで営む。ヒルデの鍛冶屋は隣。
- 一人称は「僕」。人当たりがよく、少し商売上手。
- 抱えている兜は売り物ではなく、兜の話はオットーの趣味として扱う。ゲームに兜の部位は作らない。

## 制作案

- 数えるもの：帰ってきた盾の傷。裏の革を張り替えながら、どこで受けたかを聞く。
- 手放さないもの：ヒルデが十六歳で打った最初の兜。

## 関係

- ヒルデ：元の師匠。
- ミレナ：ギルドの煮込みにツケがある。

## 未決定

- 兜にまつわる台本の順序（最初の披露と後日談）は台本側で整理する。

## 画像から確認した造形

薄紫短髪、赤眼。赤紫長衣、段重ね片肩の灰鎧、緑腰布と兜。兜を持つ通常と兜のない表情候補は姿勢差。

## 目の色

ユーザー指定で虹彩を #FF7700 fluorescent orange の鮮やかな単色へ変更。色の強さを光沢や発光エフェクトにせず、ベタ塗りで表す。本人の目の形・視線・表情を保持。髪・口・体格・服・手・小道具・状態ごとの動作を元画像と照合し、網点の塗りを保持。

## 生活動線の制作設計

一人で接客できるよう、採寸の場所から出入口が見える配置にする。借りた炉での作業を終えたら道具を持ち帰り、店の床を寝床にしない。

## 整合性を守る境界

十六歳で作った兜を商品や実装済み装備枠に昇格させない。

来歴・会話・報酬をこの生活設計から書き換えない。収納と休息の場所は、ゲーム内の追加効果を意味しない。
