# ウォルター

来歴と暮らしの文は [[concept/data/conversation-profiles.json]] の `background` を正とし、ここには複製しない。台本は [[content/data/conversations.json]] の `walter-talk-*` と、この人物が登場する `visit-*`。

## 制作上の決め事（確定）

- 道具屋。一人称は「わし」、語尾は「〜じゃ」「〜わい」。
- 谷に残す小さな謎は、ウォルターの扉の1本だけ。
- 扉は錆びた鉄橋（2層）の下。鍵は若いころ仲間とはぐれたときに拾った。
- 開けない理由は「怖い」と「はぐれた仲間と『みんなで開けよう』と約束した」の二つ。腕が足りない、場所を覚えていない、とはしない。
- 鍵の紋・古い組合・ロイドの祖父の帳面の話は使わない。

## 制作案

- 数えるもの：毎朝、店の前で百二十本の鍵を数えて磨く。
- 手放さないもの：若いころ拾った、扉の鍵。
- 喪失の話で閉じず、毎朝鍵を数えて磨く習慣で閉じる。扉の話は濁すが、暗くしすぎない。
- 扉の夢は「ときどき扉の夢を見る」程度にとどめる。向こうから叩く音など、怪談に寄る描写は使わない。
- モルナのお茶は「よく眠れるお茶」として受け取る。

## 関係

- モルナ：夜歩きを心配して、店先に油を置いていく。

## 未決定

- 扉の向こうと、扉を開ける結末。

## 画像から確認した造形

灰白髪と髭、尖耳、片眼鏡。深緑肩布と赤茶襟布、白手袋、鍵束と茶腰袋。片眼鏡を両眼鏡にしない。

## 目の色

ユーザー指定で虹彩を #FFCC00 fluorescent yellow の鮮やかな単色へ変更。色の強さを光沢や発光エフェクトにせず、ベタ塗りで表す。本人の目の形・視線・表情を保持。髪・口・体格・服・手・小道具・状態ごとの動作を元画像と照合し、網点の塗りを保持。

## 生活動線の制作設計

朝に鍵を数える卓と、売り物を渡す台を分ける。百二十本の鍵は散らばらない枠へ掛け、客の手が私物の鍵へ届かないようにする。

## 整合性を守る境界

扉を開けない理由を技術不足に変えない。戸の向こうの音や正体を付け足さない。

来歴・会話・報酬をこの生活設計から書き換えない。収納と休息の場所は、ゲーム内の追加効果を意味しない。
