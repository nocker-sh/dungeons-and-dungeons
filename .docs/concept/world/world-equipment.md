# 谷の素材を装備へ仕立てる

## 発見したくなる装備

谷は冒険者が働く場所で、街には採った素材を加工し、装備を直して渡す仕事がある。生計のために潜る世界のまま、見つけた一品から「次はこれを持って潜りたい」と思える装備を作る。

使い道が想像できる主形と、その素材でしか出せない働きを一つ持たせる。大剣なら一枚の大きな刃と受け止める背、鎧なら身体を守る厚い面と動かせる関節を先に設計する。名前に雑貨を付け、元の形を大きくしただけの装備へ戻さない。

装備制作の共通方針。新しい鍛冶システム、装備枠、属性耐性、発動効果、古代文明などを追加する確定仕様ではない。実行できる働きは既存のワザ・数値の範囲と照合する。

## 素材と加工

| 素材系統 | 武具としての主な役割 | 描く形 |
| --- | --- | --- |
| 鉄 | 基礎となる強さと扱いやすさ | 連続する鍛造面、厚い根元、研いだ縁、持ち替えられる握り |
| 巨骨・牙 | 硬い外皮と軽い芯、固有の稜線 | 切り出した積層部、削った稜板、金属との一体感 |
| 橋の鋼材 | 支える断面と丈夫な接合 | 打ち直した鋼板、曲がりに強い背、目的のある継ぎ目 |
| 温室の繊維・樹脂・種殻 | 軽い複合材、内側へ収まる力 | 引き揃えた繊維、樹脂の積層、磨いた殻、内部の細い色筋 |
| 祭壇の封印材 | 金属の内側で力を閉じる核 | 刃や胸甲を支える鋼と、小さく収まった朱色の核・封止 |

骨を丸ごと飾りにせず、刃や保護板へ加工する。蔦を切刃や握りへ絡ませず、繊維や内部の力として扱う。蝋を荷重を受ける刃や鎧の面に使わず、封止する箇所へ限定する。歯車や灯りは用途に必要な部位だけに収める。

## 武器と防具の違い

武器には、持つ場所から働く先端までつながった一つの強い輪郭を作る。少数の大きな部材と、その素材を加工した形で格好よさを出す。鋲・ベルト・棘の数を増やすだけで迫力を作らない。

防具には、守る面と動く箇所を両方作る。頑丈なものは胴や関節の厚さ、軽いものは守る場所を絞った丈と分割、力を支えるものは荷重を受ける背や帯を見せる。同じローブの色替えや、身体へ素材を巻いただけの形にしない。

## 契約で借りる力

契約装備は、普通の剣や鎧と同じ外形にそろえない。身体や石群そのものが変わる力は、その強い造形を残す。「欠けゆく勇者」などの戦闘上の武器種は戦い方の分類で、手持ちの剣であることを示すものではない。表示は契約の力と分かるようにする。
