# 魔法の流派

魔法は信仰によって流派が分かれる。

- **悪魔の信仰**: 悪魔を信仰して使う魔法。
- **自然の信仰**: 星、大地、太陽、植物などを信仰して使う魔法。

魔法は魔法銃や短剣などの武器を通して使う。

流派ごとの効果・得意分野、召喚師と悪魔の契約との関係は未設定。流派の区分は実データ（仲間の `schools`、ワザの `school`）に入っている。

## 流派ごとの得意分野（調整用・仮）

確定ではない。魔法の流派を実装するときの下書き。

| 流派 | 得意分野                             | 使う仲間（案）                     |
| ---- | ------------------------------------ | ---------------------------------- |
| 悪魔 | 呪い・状態異常、自分を削って強い一撃 | マユ、リゼ、ミミカ、ネム           |
| 星   | 遠くから当てる攻撃、敵全体への攻撃   | ルカ、リオ                         |
| 大地 | 守り、防具の耐久の回復               | ガルド、セラ、リベット、モート     |
| 太陽 | 回復・浄化、倒れた仲間を起こす       | シオン、アルマ、アルダ（回復だけ） |
| 植物 | 毒、少しずつの回復                   | ツムギ、ジグ                       |

ハスキー、ゴウ、クレフは魔法を使わない案。
