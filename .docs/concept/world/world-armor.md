# 防具の素材とキャラごとの仕立て

## 制作方針

素材を採集したまま体へ巻き付けず、加工した板・織物・留め具として、着られる服にする。素材の特徴と強さの理由を、胸・肩・前腕の保護、下衣の厚み、関節の動きやすさで伝える。防具の名前・説明・能力・入手条件は実行用データを正とする。

同じ防具で共有するのは、素材、主要な保護部材、素材を示す大きな形、役割。襟、裾、袖、布の差し色、留め方、肩当ての比率は本人へ合わせて変える。性別から可愛さ・露出・装飾を決めない。本人の性格、仕事、体格、普段の服の配色を先に読む。新しい出身地・所属・素材ドロップや未実装の耐性は、この設計を理由に補わない。

重装は胸と腹に面で受ける部材を置き、軽装は守る範囲と重量を絞る。術者の服も厚布と補強で守る構造を示す。単なる薄着に高い数値を付けた見え方を避ける。現行の防具は耐久が先に被害を受ける仕組みで、防御率や素材別耐性が付くわけではない。

## 防具ごとの構造

素材の加工と保護する形は、各防具の正本JSONの `construction` に記す。同じ表をここへ転記せず、制作時は対象の資料から正本を参照する。

## 本人に合わせる仕立て

- アルダ：明るく活動的な前衛。大きな武器を振れる肩と肘、短く整えた上着、普段の赤を布の差し色へ使う。露出で活動性を示さない。
- ガルド：大柄で頼れる守り手。広い胸当てと厚い肩、落ち着いた青緑の襟、黄土色のコート。威圧より安心できる強さ。
- モート：実務的で気の抜けた墓守。落ち着いた青緑の仕事着、邪魔にならない襟、簡潔な留め具。派手な死者の意匠を追加しない。
- リベット：小柄で几帳面な工房の盾持ち。四角い金具、整ったパネル、締まった袖口、普段のからし色と暗赤の差し色。小ささと可愛さを同一視しない。
- シオン：丁寧な癒やし手。青緑と白、端正な襟、手が使いやすい袖と白い手袋。
- ルカ：芝居がかった軽口を言う魔術師。暗赤と黒、左右差のある襟や合わせ、表情のある着こなし。シオンと同じ角度・同じ手の位置にしない。
- マユ：寝坊するが危険を察する黒魔術師。落ち着いた暗色のゆったりした襟、手首は整える。耳と本人の眠そうな雰囲気を保持。
- ツムギ：丁寧な仕立て屋。整った縫い目と折り返し、使える小さなポケット。飾りのリボンを性別から足さない。
- ジグ：足跡を読む狩人。短い裾、肘の動き、落ち着いた森の色。少年の体格を保持。
- ゴウ：負けず嫌いの斧使い。力強い肩と腕、黒と暗赤の簡潔な仕立て。角と本人の赤い肌を保持。
- リオ：竜を連れ歩く旅人。丈夫な肩帯と暖色の旅装、普段の竜の籠を邪魔しない形。
- ミミカ：驚かせるのが好きな影絵師。暗色に小さな白の差し色、左右差のある合わせ、指を使える袖。現行の本人の顔と髪を保持。
- クレフ：得意げで元気な扉担ぎのタンク。白い尖り髪・尖耳・青い眼を保持し、普段の赤と白を布の差し色に使う。普段の灰色の肩当てと籠手は防具の着替えに混ぜない。
- 主人公の外見候補：黒い目元の帯と各髪色を保持し、服の合わせとポーズを分ける。未設定の性格を決め付けない。

## 画像で確認する条件

- 同一防具のキャラを並べ、素材の共通性と仕立ての違いが両方読める。
- 同一キャラの防具を並べ、向き・表情・手の位置に実際の違いがある。体格と頭の表示倍率は保持。
- 顔、髪、服の彩度・明暗・線の太さ・網点の密度が揃う。鎧だけ写実的にしたり、顔だけを貼り付けたりしない。
- 胸の保護、留め具の接続、関節の自由、素材の加工が小さい表示でも分かる。
- 髪・両袖・両腕を左右と上の枠内に収める。
- 画像が完成した種類だけを反映済みとし、設計資料の更新を全画像の完成と呼ばない。
