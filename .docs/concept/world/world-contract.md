# 召喚師と悪魔の契約

## 設定・制作メモ

主人公は悪魔召喚師。開始時はロクスと契約済み。追加の悪魔の契約書を物語で手に入れ、召喚して会話する。悪魔が求める品を別のバイオームで探し、契約料と一緒に渡すと仲間になる。一度呼んだ相手には契約書なしで再び会える。抽選・レア度・重複契約・見送りはない。戦闘では契約した悪魔と合体する。

秘密の部屋では、仲間となった悪魔に直接話しかける。日常と探索の会話を重ね、互いを知っていく。仲間の価値を強さの階級で扱わない。数値と加入の条件は実行用データに置く。
