# 巨人たちの墓場の地点配置図

巨人の骨と墓標の間を通る。供物と刻字の仕事を、人の通路と踏み荒らさない位置で続ける。

地点の座標・接続・遭遇条件は実行用データを正とする。この図は各地点の資料へつなぐ索引であり、抽象的な一歩を建物のメートル寸法へ変換しない。帰還用の昇降機と道を結び、存在しない線路や新しい層を足さない。

## 層内の作業と汚れ

巨人の骨と墓標の間を通る。供物と刻字の仕事を、人の通路と踏み荒らさない位置で続ける。

この地点では骨と湿った土が衣服や荷に付く。墓標と骨を勝手に資材置き場へ変えない。食事の包み、飲用水、使用済みの布は別に持ち、汚れを上の街へ運ぶ前に荷をまとめる。
