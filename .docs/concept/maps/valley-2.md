# 錆びた鉄橋の地点配置図

古い鉄橋の梁と作業足場を渡る。橋は昇降機とは別の構造物であり、鉄道施設ではない。

地点の座標・接続・遭遇条件は実行用データを正とする。この図は各地点の資料へつなぐ索引であり、抽象的な一歩を建物のメートル寸法へ変換しない。帰還用の昇降機と道を結び、存在しない線路や新しい層を足さない。

## 層内の作業と汚れ

古い鉄橋の梁と作業足場を渡る。橋は昇降機とは別の構造物であり、鉄道施設ではない。

この地点では錆と落ちた金具が衣服や荷に付く。床の欠けと落下物を確かめ、荷を手すりに預けない。食事の包み、飲用水、使用済みの布は別に持ち、汚れを上の街へ運ぶ前に荷をまとめる。
