# 街道と谷のワールド地図

座標と隣接は実行用データを正とし、ここは街・道・拠点の個別資料への索引にする。格子一つを距離や一日の所要時間へ換算しない。

街から街道、村へつながり、村を中心に北の岩山、東の森、南の湿地へ道が分かれる。森と岩山の拠点が指す探索先は同じ谷の各層。別々のダンジョンや第五層を追加しない。

街の家々、村の暮らし、拠点での支度は、探索資源の一覧へ還元せず個別の場所資料で扱う。解放条件は変えず、資料の追加を実装済みの施設や無料の宿泊機能と取り違えない。
