# 毒沼の温室の地点配置図

割れた温室の骨組みと湿地の間に歩ける足場が残る。植物の採集と水の危険を分けて考える。

地点の座標・接続・遭遇条件は実行用データを正とする。この図は各地点の資料へつなぐ索引であり、抽象的な一歩を建物のメートル寸法へ変換しない。帰還用の昇降機と道を結び、存在しない線路や新しい層を足さない。

## 層内の作業と汚れ

割れた温室の骨組みと湿地の間に歩ける足場が残る。植物の採集と水の危険を分けて考える。

この地点では泥と植物片が衣服や荷に付く。湿地の水を飲用にせず、手洗い用にも清潔な持参水を使う。食事の包み、飲用水、使用済みの布は別に持ち、汚れを上の街へ運ぶ前に荷をまとめる。
