# 底なしの祭壇の地点配置図

段と柱の間を、灯りの届く範囲でたどる。第四層の先については地形も結末も決めない。

地点の座標・接続・遭遇条件は実行用データを正とする。この図は各地点の資料へつなぐ索引であり、抽象的な一歩を建物のメートル寸法へ変換しない。帰還用の昇降機と道を結び、存在しない線路や新しい層を足さない。

## 層内の作業と汚れ

段と柱の間を、灯りの届く範囲でたどる。第四層の先については地形も結末も決めない。

この地点では蝋と石粉が衣服や荷に付く。灯りを裸火のまま荷物へ入れず、既知の帰路を空ける。食事の包み、飲用水、使用済みの布は別に持ち、汚れを上の街へ運ぶ前に荷をまとめる。
