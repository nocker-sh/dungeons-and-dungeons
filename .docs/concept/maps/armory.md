# 武具店の仕事と住まいの配置図

表通り側の仕事場の奥に、生活の区画を伸ばす。xは入口から見て左から右、yは表から裏。台所・寝室・洗い場・便所は西側の幅1.2mの通路へ個別に開き、通路の終端に裏口を置く。生活するために客の前や炉のそばを毎回横切る設計にしない。

仕事場の裏扉から通路へ入り、寝室を通らず裏口まで抜ける。飲用水と食料は台所へ、使用済みの布は洗い場へ、排泄物の回収は便所から裏口へ運ぶ。異なる荷を同時に運ばず、薬品・骨粉・金属片を生活設備へ混ぜない。

## 戸口の対応

正面の部屋から生活用通路へ入り、各生活設備へは通路側の個別の戸で出入りする。寝室の戸は寝台の足元側に寄せ、寝台を押さなければ開けられない配置にしない。戸の両側の位置と幅は doors に一組ずつ記録し、室内寸法と寝台の使用範囲へ照合する。
