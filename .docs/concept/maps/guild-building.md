# ギルド建物の生活配置図

外形18×14m、壁厚0.3mの内側を座標化する。西から東へx、表通りから裏庭へy。部屋の寸法は各室資料を正とし、この地図は配置だけを持つ。

一階西側はホール。その奥の左に宿受付と折り返し階段、奥右に地下への階段を置く。東側の幅1.4mのサービス通路は炊事・洗濯・洗身・便所を順につなぐ。受付と酒場の配膳台を兼ねない。吹き抜けや二階回廊は作らない。

客室階は中央のy=5.2〜8.2mが共用通路。西の階段と東の非常用外階段をつなぐ。普通客室二室、上等客室二室と屋根裏一室で二十床。客室の入口はすべて共用通路側。奥の客室へ行くために別の客室を通らない。

屋根裏は建物全体にもう一階を足さず、裏側の小切妻内に一室を納める。西の階段から入る。低い軒側を寝台、中央の高い部分を歩く場所とする。

地下は既存の4×5mの共用室を中心に、ヨル一人、ハロ一人、ロクスとザザ、ヌイとトリスの寝室へ分ける。東側のサービス通路は食事準備・洗身・便所・寝具の手入れを結ぶ。共用室東の前室から奥右の階段へ戻り、別経路として通路端の外部避難口を確保する。光を遮る覆いと換気を両立させ、地下で裸火を使わない。部屋の起源とロクスとの約束は明かさない。

## 地下の西側の部屋へ通る経路

西側の三寝室と東側の生活設備の間を、他人の寝室を経由せず通れるよう、西側に幅1.4mの通路を通す。共用室はx=6.8、y=3.4からの4×5m。ヌイとトリスの寝室はx=6.8、y=0からの4.4×3.2mに収める。

東のサービス通路から共用室へ入り、室内南寄りのy=7.1〜8.3mを幅1.2mの東西の通路として空け、西の通路へ抜ける。直径1.5mの円は中心y=5.4m、ベンチは北壁へ置き、通り道と重ねない。共用室の扉の幅は1.2m。西通路の終端にも裏庭へ退避できる明瞭な避難口を置く。寝室を非常時の共用通路として当てにしない。

## 屋根裏へ入る向き

屋根裏の側壁には四つの寝台が並び、軒高は1.3mしかない。側面に成人用の入口を無理に開けず、階段から幅1.2mの前室を回って、棟の高い正面中央の戸へ入る。一階の客室階段はホール奥左の開いた区画内、客室階と屋根裏階では配置として明記する。
