# ネムと相棒の住まいの生活配置図

表の居間にネムの食卓と一体の相棒の休息面を分け、その奥に生活用通路と台所・ネムの寝室・洗い場・便所を並べる。相棒の身体と三つの器で入口を挟まない。各室の入口は西側の通路へ開き、通路の終わりは裏口。

寸法は制作設計であり、家賃や移動時間を実装した値ではない。窓を開ける面と裏口を残し、物理的に通れない場所を背景の省略で済ませない。

東側に4×4.2mの庭を追加し、配置図の幅8.7mは庭を含む敷地を表す。家の居室部分の幅は4.5mのまま。居間から庭への戸と庭の門は幅1.6mとし、相棒の動線を人の生活用通路から分ける。

## 戸口の対応

正面の部屋から生活用通路へ入り、各生活設備へは通路側の個別の戸で出入りする。寝室の戸は寝台の足元側に寄せ、寝台を押さなければ開けられない配置にしない。戸の両側の位置と幅は doors に一組ずつ記録し、室内寸法と寝台の使用範囲へ照合する。
