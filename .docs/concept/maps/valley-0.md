# 結晶の洞窟の地点配置図

採掘場の足元に光る結晶があり、作業の粉と飲用水を分ける。岩棚は採掘の場所であり寝室ではない。

地点の座標・接続・遭遇条件は実行用データを正とする。この図は各地点の資料へつなぐ索引であり、抽象的な一歩を建物のメートル寸法へ変換しない。帰還用の昇降機と道を結び、存在しない線路や新しい層を足さない。

## 層内の作業と汚れ

採掘場の足元に光る結晶があり、作業の粉と飲用水を分ける。岩棚は採掘の場所であり寝室ではない。

この地点では結晶の粉が衣服や荷に付く。採掘した荷と人の退避位置を分ける。食事の包み、飲用水、使用済みの布は別に持ち、汚れを上の街へ運ぶ前に荷をまとめる。
