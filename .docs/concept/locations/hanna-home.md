# ハンナの住まい

農場から帰ったハンナが、食事・読書・洗身・睡眠を取れる住まい。家族構成と農地の所有者は決めず、農場の娘という来歴を一人暮らしの確定へ置き換えない。

居間の奥に生活用通路を通し、台所・寝室・洗い場・便所へ個別の戸を設ける。表の入口と通路の終わりの裏口を空け、各室から屋外へ退避できる。地上階だけで食事・就寝・洗身・排泄が完結する。家の所有者や未指定の番地は決めない。

寝室の四床は利用上限を示す制作設計であり、四人家族の設定ではない。子供だけで火・重い水・回収物の作業を全て担う暮らしにはしない。名前のない家族の人数や現在地を、この空間から確定しない。
