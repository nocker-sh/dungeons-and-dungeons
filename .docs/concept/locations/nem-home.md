# ネムと相棒の住まい

相棒は三つの頭を持つ一体のケルベロス。三つの食器と一体分の横になれる面を用意する。人の食事の卓と餌の場所を分け、相棒の身体と荷物で出口を挟まない。

人の寝台は相棒の休む床と分ける。人も食事と睡眠を取り、餌代のために本人が生活できなくなる配置や運営を正解にしない。

台所、寝室、洗い場、便所、生活用通路はそれぞれ個別の資料へ分ける。既存の人物の生活に必要な場所を作る設計であり、新しい来歴や結末を補わない。敷地の位置は街の町家と路地の範囲とし、未指定の番地や家主の素性を確定しない。
