# 六席の影絵小屋

客席は二列三席の六席。舞台は奥行1.5m、右側の幅1.2mを入口から舞台脇の退避口まで空ける。紙と灯りの間を離し、子供のために空ける一席へ道具を積まない。

興行の片付けを終えてから休む。人形と紙は乾いた箱へ、灯りの器は冷ましてから別の棚へ戻し、舞台の上を寝床にしない。

台所、寝室、洗い場、便所、生活用通路はそれぞれ個別の資料へ分ける。既存の人物の生活に必要な場所を作る設計であり、新しい来歴や結末を補わない。敷地の位置は街の町家と路地の範囲とし、未指定の番地や家主の素性を確定しない。
