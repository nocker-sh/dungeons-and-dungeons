# 街道の村

## 場所の意味と動線

街と街道の分かれ道を支える小さな集落。旅の人の荷を受ける表の場所と、住民が休む家の内側を分ける。

## 生活と物の流れ

村の食事、手洗い、便所、泊まる場所は住人の暮らしとして成立させる。ゲームの集落表示を無条件の無料宿や回復効果に変えない。周囲の農地の収穫と街からの塩・布を交換し、飲用水と家畜の水場を分ける。

## 実装との境界

移動の可否、回収物、解放条件、出撃先は正本の規則を使う。この資料は価格・回復・新しい移動操作を追加しない。
