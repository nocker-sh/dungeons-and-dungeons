# ハスキーが維持する二人の貸間

二人で使う卓を置く。二本の鍵は紐でまとめて首から下げるため、通路へ引っ掛かる金具を出さない。相棒の席を物置へ変えず、離れている間も二人分の居場所を維持する。

寝台を二つ置き、相棒の寝台を荷物置き場にしない。相棒の生存を前提とするが、今いる場所と帰還の時期は決めない。

台所、寝室、洗い場、便所、生活用通路はそれぞれ個別の資料へ分ける。既存の人物の生活に必要な場所を作る設計であり、新しい来歴や結末を補わない。敷地の位置は街の町家と路地の範囲とし、未指定の番地や家主の素性を確定しない。
