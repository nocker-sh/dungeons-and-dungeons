# スクラップアイ

## 暮らし（制作案）

2層・錆びた鉄橋の梁に住む、青緑の二本足の魔物。太い尾を三本目の脚にして梁にふんばり、落ちてきた鉄くずや歯車を拾っては自分の山に積む。柄の先の目玉を左右ばらばらに動かし、山に近づくものを見張る。中ボスとしては山が通り道の上にかかった個体で、近づくと積んだ鉄の塊を落としてくる。

倒れたあと、山が崩れ、錆びた歯車とガラクタが散らばる。

## 制作メモ

仲間の成長と回復を強めた編成が、錆の層の節目で準備と回復を使う相手として攻撃の目安を調整する。体力・ワザ・報酬は維持し、通常戦全体を一律に強めない。

## 画像から確認した造形

青緑の直立獣、淡い腹、二本の長い眼柄に黄白の四角眼、短い腕、大きな足と尾。眼柄を角にしない。
