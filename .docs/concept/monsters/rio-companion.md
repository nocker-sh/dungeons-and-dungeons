# リオの相棒の幼竜

リオの背負う卵の殻の籠にいる、小さな緑の竜。人物の持ち物として名前だけを並べず、一体の生き物として休息と食事の扱いを記す。独立した敵の登録や、リオに追加で使えるワザを作る資料ではない。

## 滞在先での世話

籠はリオの寝台から様子を確かめられる乾いた位置へ下ろす。人が扉へ向かう通路、椅子を引く場所、湯の桶を運ぶ経路から外し、安定した床か低い台で受ける。籠を壁や布で囲い切らず、周囲に空気を通す。暖かさを取るために裸火を寄せない。

餌の結晶と清潔な水は、それぞれ浅い専用の器に分け、人の食器と混ぜない。餌の袋は換金する荷と分け、リオが取っておいた粒を掃除の残り物として捨てない。器を使った後は洗い、汚れた敷布は袋へ分けて運ぶ。排泄物は蓋付きの回収容器へ入れ、滞在先の便所の回収経路へつなぐ。飲用水や雨水の溝へ流さない。

籠の外へ出すときも、本人が戻れる休む場所を残し、宿の共用通路を遊ぶ場所にしない。籠を下ろすと起きる習慣を踏まえ、寝たままの荷物として放り出さず、リオが落ち着くのを見届ける。成長して窮屈になった場合の対応は、別の種や固定の成体寸法を作って解決しない。

## 物語と実装の境界

故郷を探し続けるリオの動機と、いつか別れるかもしれない気持ちは人物と台本の正本を参照する。この資料で故郷の場所や結末を埋めない。餌の説明から消費アイテム、ドロップ、価格、回復効果を新設しない。
