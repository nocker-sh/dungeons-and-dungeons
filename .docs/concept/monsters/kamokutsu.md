# スタンプダック

## 暮らし（制作案）

0層・結晶の洞窟に群れで住む白い鳥。冒険者が谷に落としていった靴や帽子を拾って身に着ける習慣があり、オスは靴、メスは帽子を選ぶ。素足の個体はまだ自分の一足を見つけていない若いオスで、大きな水かきを高く振り上げ、結晶を踏み割って地面を掘る。気に入った一足が見つかるまで、群れの中でほかの個体の靴をうらやましそうに見ている。

倒れたあと、飲みこんでいた結晶のかけらと、踏み割るのに使っていた爪の欠けが残る。

## 制作上の決め事（確定）

- ユーザー選定の元画像を採用。
- ダックリングはスタンプダックのヒナ（ユーザー指定）。
- スタンプダックはさまざまな靴を履き、靴ごとに亜種を増やせる。ブーツダックとマッドダックはその亜種。ベレーダックは帽子違いの亜種で、帽子の種類でもシリーズを増やせる（ユーザー指定）。
- オスはブーツを履き、メスは帽子をかぶる（ユーザー指定）。ブーツダックとマッドダックはオス、ベレーダックはメス。
