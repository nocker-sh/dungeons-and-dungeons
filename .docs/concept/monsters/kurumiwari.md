# ナッツハイド

## 暮らし（制作案）

2層・錆びた鉄橋に住む、大きなクルミの殻を家にした小さな生き物。殻のふたを少しだけ持ち上げて黄色い目と前足をのぞかせ、長い片耳だけを外へ立てて足音を聞いている。橋で拾ったボルトや歯車を、木の実のように殻の中へしまいこむ。

倒れたあと、殻の中から、しまってあった錆びた歯車が出てくる。
