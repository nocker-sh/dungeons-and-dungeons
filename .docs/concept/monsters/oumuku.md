# エコーパロット

## 暮らし（制作案）

2層・錆びた鉄橋の手すりに止まる、青い冠羽のオウム。片足をあごに当てて首をかしげ、橋を渡る冒険者の掛け声をまねる。「上がるぞ」「先に行け」とまねされた声に、仲間かと思って振り向く者がいる。光る物も好きで、歯車を足でつかんで持ち歩く。

倒れたあと、つかんでいた歯車がそのまま落ちる。

## 画像から確認した造形

白顔と胸、青緑の冠羽・翼、巨大な黒嘴、灰脚。小嘴の別鳥へ変えない。

## 攻撃の動作と画像

攻撃の内容を先に決める制作定義。攻撃名と近接・遠距離は実行用JSON、ワザの効果と確率は content のJSONを正とし、数値は引き続き暫定値。共通の[[monster-attacks|攻撃仕様]]を使う。
