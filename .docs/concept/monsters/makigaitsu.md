# スピラスネイル

## 暮らし（制作案）

3層・毒沼の温室の、ガラスの内側を這うカタツムリ。紫の殻は平たい面を組み合わせた渦巻きで、飛び出した黄色い目で前を確かめながら、曇ったガラスをなめるように進む。同じ道を毎日なぞるので、ガラスには粘液の筋が何本も重なって光る。

倒れたあと、殻の口に粘液と毒花の種がこびりついている。

## 制作上の決め事（確定）

- 紫の巻き貝を背負ったカタツムリ。殻は渦巻きの面で組まれ、黄色い目が飛び出している（採用画像）。

## 未決定

- 数値とワザは仮。3層の道中の敵として、入れ替える前の敵の強さを引き継いでいる。遅いがとても硬い。殻ごとぶつかって粘液で絡め（殻ぶつけ）、毒の粘液を撒く（粘液まき）。

## 画像から確認した造形

大きな紫の多面体の殻、象牙色の角張った渦と腹、短い二本の眼柄と平たい金色の楕円眼。体は殻の下でコンパクト。攻撃でも殻を縮めず胴を引き伸ばさない。旧 attack は小殻・長胴になっているため再利用しない。現行 attack-ram は殻ごと前へ寄せる。
