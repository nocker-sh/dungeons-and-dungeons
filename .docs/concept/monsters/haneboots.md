# ブーツダック

## 暮らし（制作案）

自分の脚より大きな黄色い作業靴を見つけた、青い羽のスタンプダックのオス。靴の中で脚が泳いでも脱ごうとせず、重い靴底ごと前へ蹴り出してくる。眠るときもブーツを履いたまま、つま先をそろえる。

倒れたあとも、ブーツだけはまっすぐ立ったまま残っていることがある。

## 制作上の決め事（確定）

- スタンプダックの亜種。大きなブーツを履いた姿。スタンプダックはさまざまな靴を履き、靴ごとに亜種を増やせる（ユーザー指定）。
- 採用画像の青い羽毛とブーツの形を保持する。
- スタンプダックのオスはブーツを履き、メスは帽子をかぶる（ユーザー指定）。
- 顔はスタンプダックと共通の、小さな黒い目と幅広く開いた黄色いくちばしに揃える（ユーザー指定）。

## 未決定

- 数値とワザはスタンプダックと共通の暫定値。

## 画像から確認した造形

青白の鳥と巨大な黄色いブーツ。普通の水掻きに置換しない。
