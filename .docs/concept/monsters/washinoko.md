# ボーンホーク

## 暮らし（制作案）

1層・巨人たちの墓場で、巨人のあばら骨の上に巣を作るワシのひな。頭の両側に大きく張った眉羽を広げ、腰に翼を当てて胸を張る立ち方は、巣の下に立つ親を見て覚えた。骨をくわえて高く舞い上がり、落として割る親のまねをするが、まだ小さな骨しか運べず、割れなかった骨は両足で踏んで割る。

中ボスとしては、巣立ちの近い個体が骨の通り道に降りてくる。

倒れたあと、踏み割ろうとしていた骨片が足もとに残る。
