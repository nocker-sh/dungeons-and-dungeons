# クビコキ

## 暮らし（制作案）

2層・錆びた鉄橋の手すりで、長い首をくねらせて立つ白いサギ。半目のまま、手すりの外を何時間でも見ている。突くときだけ首がまっすぐになる。

## 制作上の決め事（確定）

- 首を大きくくねらせた白いサギ。半目で口をすぼめ、どこかとぼけている（採用画像）。
- ユーザー指示により不採用。道中の出現候補とdevの採用モンスター一覧から外す。保存データとの互換性のため、敵の定義と画像は保持する。

## 未決定

- 数値とワザは仮。2層の道中の敵として、入れ替える前の敵の強さを引き継いでいる。速く、長い首をしならせて突く（しなり突き）。錆びた牙を落とす。沼色の亜種はヌマコキ。

## 画像から確認した造形

白灰の折れた長首、黄色い長嘴、青灰の頭羽、黄脚と黒爪。首の折れ方と眼の位置を維持。
