# ヌマコキ

## 暮らし（制作案）

3層・毒沼に住みついたクビコキ。毒沼の水に浸かって魚を待つうちに、白い羽が黄緑に染まった。

## 制作上の決め事（確定）

- クビコキの沼色の亜種。白い羽が毒沼の黄緑に染まっている。
- ユーザー指示により不採用。道中の出現候補とdevの採用モンスター一覧から外す。保存データとの互換性のため、敵の定義と画像は保持する。

## 未決定
