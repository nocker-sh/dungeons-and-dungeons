# パッチクローク

## 暮らし（制作案）

4層・底なしの祭壇に住む小さな生き物で、拾った布切れや石片を継ぎ合わせた青緑と砂色のまだらの羽織に、すっぽり体を隠している。継ぎ目が増えるほど羽織は重くなるが、外したことはなく、隙間から黄色い目と細い足だけを出して歩く。お腹にも口があり、拾った物はまずそちらでかんで確かめる。

倒れたあと、羽織の縫い目から黒い封蝋のかけらがぽろぽろ落ちる。

## 画像から確認した造形

青白黄の面でできたマント状の包み、黒い顔と黄色い眼、細い灰脚。布の面模様を維持。
