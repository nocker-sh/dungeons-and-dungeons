# ウッドミミック

## 暮らし（制作案）

0層・1層で、冒険者が置いていった木箱に住みついたタールスライム。ふたの隙間からあふれた黒い粘体が、金具の上を伝って床まで垂れている。拾った物を箱の中へしまいこみ、人が近づくとふたを閉じてただの箱のふりをする。

倒れたあと、箱の底からしまいこんでいた回復薬が出てくる。

## 制作上の決め事（確定）

- 口を持たない真っ黒な粘体。左右で大きさが異なる黄色い目と小さな瞳孔で、可愛さの中に狂気を感じる表情を作る。宝箱から垂れる粘体と、箱の材質で強さの段階を表す。

## 未決定

- 数値・仲間化。現在の数値は暫定値。

## 画像から確認した造形

茶の木箱と金具、箱から溢れる黒い液状の体、非対称の黄色い眼。口や歯はない。箱の型・眼の左右は個体ごとに確認。lash は前へ一本の腕、surge は周囲の滴。

## 攻撃の動作と画像

攻撃の内容を先に決める制作定義。攻撃名と近接・遠距離は実行用JSON、ワザの効果と確率は content のJSONを正とし、数値は引き続き暫定値。共通の[[monster-attacks|攻撃仕様]]を使う。

通常攻撃：黒い、または本人の色の粘体から一本の腕を前へ出す。目と輪郭を本人に合わせる。

顔と視線、打撃面や飛び道具の先端・軌道は画面手前のプレイヤーへ向ける。横や地面への攻撃にしない。手前ほど大きく、発射元と重なる遠近で示す。通常と並べ、顔・目と瞳・体形・部位数・接続・固有模様・殻や翼の比率を確認する。元PNG・参照・プロンプト・生成出力の記録は [[concept/prompts/monster-attacks.json]]。人の画像承認はAIの確認と分ける。
