# ソウルキャンドラ

## 暮らし（制作案）

4層・底なしの祭壇の段に並んで灯る、黒く濁った蝋のキャンドラ。紫の火は熱を持たず、近づいたものの魂を細く引き寄せて燃える。誰に頼まれたわけでもなく、片側に長く垂れた蝋を手で押し上げながら、今日も祭壇を照らしている。

倒れたあと、黒い蝋が固まり、封蝋のかけらのように割れて残る。

## 制作上の決め事（確定）

- キャンドラの黒い亜種。蝋が黒く濁り、紫の火が灯っている。
- 太い蝋の体、片側に長く垂れた蝋、非対称の足元の蝋溜まりと曲がった芯でキャンドラと区別する。

## 未決定

- 数値とワザは仮。4層の道中の敵として、入れ替える前の敵の強さを引き継いでいる。とても強い。魂を引き抜き（魂抜き）、蝋を砕いて叩きつける（封蝋割り）。

## 画像から確認した造形

紫の垂れ蝋、紫の炎と帯、小さく沈んだ青い眼。通常キャンドラの白蝋・橙炎と区別。
