# ペリカーゴ

## 暮らし（制作案）

2層・錆びた鉄橋に住みつき、落ちた物を拾い集めるペリカン。くちばしの袋は荷箱のように角ばっていて、両の翼で前に抱えて運ぶ。中身を誰にも見せず、重くなりすぎても捨てないので、袋に入った冒険者の落とし物は戻ってこない。

倒れたあと、袋の口が開き、錆びた歯車とガラクタが転がり出る。

## 制作上の決め事（確定）

- くちばしの袋を前に抱えたペリカン。袋は黄色い箱のように角ばっている（採用画像）。
- 2層の鉄橋に住みつき、落ちた物を袋にしまう。

## 未決定

- 数値とワザは仮。2層の道中の敵として、入れ替える前の敵の強さを引き継いでいる。遅いがとても硬い。袋で包みこむ（まるのみ）。縛りと毒が効きにくい。

## 画像から確認した造形

白と青灰の太った鳥、胴ほど大きな黄色い角張った嘴袋、黄色い足。普通の小さな鳥の嘴へ縮めない。
