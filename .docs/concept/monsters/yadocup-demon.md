# デビルカリクス

## 暮らし（制作案）

二本の角と赤い山形の模様がある、黒紫の器を背負ったカリクス。ほかの個体と器を取り合って勝ち続け、今の器を手放さない。器の角を橋の鉄骨にこすって磨くのが日課。

倒れたあと、器の中に磨き粉のような錆と歯車が残る。

## 制作上の決め事（確定）

- 二本の角がある黒紫のカップを背負う悪魔の姿。
- 色だけでなく、殻・羽・角・尾などの形と大きな模様で見分けられるようにする。

## 攻撃の動作と画像
