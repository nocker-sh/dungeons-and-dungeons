# ケムレイス

## 暮らし（制作案）

1層・巨人たちの墓場に漂う、薄紫の煙の魔物。角ばった煙を螺旋に巻き、自分の体を両腕で抱くようにして夜を越す。冒険者の焚き火の跡に寄っては、まだ温かい灰へ尾の先を伸ばす。

倒れたあと、煙の匂いと、巻きこんでいた骨片が残る。
