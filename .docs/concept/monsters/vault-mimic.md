# グランミミック

## 暮らし（制作案）

4層・底なしの祭壇で、真鍮の錠前を付けた古い大金庫に住みついたタールスライム。分厚い扉の内側で長く暮らすうちに粘体は増え、目も三つになって、扉の隙間から外へあふれている。しまいこんだ物を数えるように、ときどき扉をきしませる。

倒れたあと、金庫の奥から回復薬と光るガラクタが出てくる。金庫そのものは重すぎて持ち帰れない。

## 制作上の決め事（確定）

- 口を持たない真っ黒な粘体。左右で大きさが異なる黄色い目と小さな瞳孔で、可愛さの中に狂気を感じる表情を作る。宝箱から垂れる粘体と、箱の材質で強さの段階を表す。

## 未決定

- 数値・仲間化。現在の数値は暫定値。
- 大金庫が祭壇にある理由は書かない。

## 画像から確認した造形

厚い金具の黒い箱、大きな鍵穴、黒い液体と三つの黄色い眼。二眼ミミックへ揃えない。
