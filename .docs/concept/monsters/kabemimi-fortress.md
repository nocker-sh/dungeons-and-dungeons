# ウォールタイタン

## 暮らし（制作案）

錆びた鉄橋の出口まで歩いてきて、そこに居座ったミミウォール。耳は物見の塔のように伸び、胸には閉じた木の門ができた。苔の生えた城壁の顔は、目だけが小さくなって、昔と同じとぼけた口をしている。

## 守っているもの（制作案）

胸の門の奥にためこんだ拾い物。門を閉じたまま橋の出口に固まり、通ろうとするものを門のすき間の錆びた鉄杭で噛む。冒険者にとっては、鉄橋の向こうへ進むたびにどかさなければならない、職場の大きな障害。

どかしても、しばらくすると同じ場所へ戻って固まっている。

倒れたあと、門が少しだけ開き、しまっていた歯車やガラクタがこぼれる。

## 制作上の決め事（確定）

- 耳が塔になった城門の姿。胸の大きな閉じた門と城壁の凹凸、厚い控え壁を持つ。元のとぼけた顔と左右で違う耳を残す。
- 2層・錆びた鉄橋の終点にいるボス。橋の出口に城門のように居座り、道をふさぐ。
- 目を大人の姿よりさらに小さくし、城門の巨大さを見せる。元のとぼけた表情を維持する。
