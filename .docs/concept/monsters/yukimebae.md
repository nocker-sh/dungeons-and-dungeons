# シードロード

## 暮らし（制作案）

温室の奥で大きく育った草の子。芽を出したときの白い種の殻を、育ったあとも割らずに外套のようにまとい、胸の前で両手を合わせて閉じている。頭の双葉だけが殻の外へ伸び、割れたガラス屋根からの光を受けている。

## 守っているもの（制作案）

温室のいちばん奥にある苗床。パラソリーフやバドアイはそこから芽を出す。シードロードは苗床の前に立ち、近づくものに蔦をしならせ、抱えた殻を開いて毒の風を吹き出す。毒花の種を集める冒険者にとっては、温室の奥の仕事場をふさぐ番人。

倒しても苗床はそのままで、しばらくすると次のシードロードが殻を抱えて立っている。

倒れたあと、抱えていた殻が割れ、中から毒花の種がこぼれる。

## 制作案：系統

パラソリーフは若葉の姿、バドアイは蕾の姿、シードロードは温室の奥で大きく育った姿。同系統の成長と環境差としてまとめる案。
