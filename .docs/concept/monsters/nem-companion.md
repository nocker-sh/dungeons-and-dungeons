# ネムの相棒のケルベロス

三つの頭を持つ一つの身体。食器は三つ、休む床は一体分として設計する。二つの首輪と中央の縄という既存の特徴を守る。仲間の食費を払うネムの動機とつながるが、相棒を新しい敵や追加の召喚能力へ変えない。

住まいでは人の寝台を使わず、居間の乾いた面で休む。餌と水は人の食事の器から分け、足の洗浄と排泄物の回収は庭へつなぐ。雨ざらしの庭だけを寝床にせず、屋内へ戻る戸を空ける。生活機能は居間の animal_support、洗浄と回収の経路は庭の資料を参照する。
