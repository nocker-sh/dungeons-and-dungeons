# サバトゴート

## 暮らし（制作案）

4層・底なしの祭壇に住む、地面に届きそうなあごひげを垂らした白い山羊。草の生えない祭壇で、紙切れや黒い封蝋、ろうそくの燃えさしを草の代わりにかじり、半分閉じた目のまま口だけはずっと動いている。中ボスとしては祭壇の中ほどの段に寝そべって道をふさぐが、何かを守っているのではなく、動く気がないだけ。

倒れたあとも、ひげには黒い封蝋のかけらが絡んだまま残る。

## 画像から確認した造形

灰緑の四足山羊、長い白胸毛、緑眼、短い金角と蹄。胸毛は服ではない。
