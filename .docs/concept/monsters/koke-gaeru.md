# モストード

## 暮らし（制作案）

1層・巨人たちの墓場の湿った土で、骨の陰から動かなくなったブリックトードの仲間。待ち続けるうちにレンガ色の肌は苔の緑に覆われ、背中には淡い帯が走った。苔が厚くなるほど体は重くなったが、舌だけは昔と同じ速さで伸びる。

倒れたあと、背中の苔の形が地面に湿った跡で残る。

## 制作上の決め事（確定）

- ブリックトードの苔むした亜種。体が湿った苔の緑に変わっている。
- 色だけでなく、短い脚の幅広い体と、背中の大きな淡い帯でブリックトードと区別する。

## 未決定

- 数値とワザは仮。1層の道中の敵として、入れ替える前の敵の強さを引き継いでいる。ブリックトードより大きく、硬く、強い。

## 画像から確認した造形

緑の丸い蛙、黄色い帯模様と大きな白腹。旧無地の緑蛙を模様の基準にしない。
