# ホークロード

## 暮らし（制作案）

墓場で拾った鉄の棒を杖にして立つ、ボーンホークの大人。両端を角張った金具で太くした棒を翼の先で握り、手首には骨のあいだで見つけた金の輪をはめている。骨を高くから落として割り、割れなかった骨は棒で叩いて割る。墓場の住人には、骨のあいだに立つ姿が守り神のように見えている。

## 守っているもの（制作案）

墓場の奥、あばら骨の上の巣と、そこで育つひな。大人は巣の真下の道に立ち、近づくものに棒を突き出し、骨を降らせる。墓場の奥へ骨片を拾いに行く冒険者にとっては、毎回向き合う番人。

追い払っても巣はそこにあり、次の季節にはまた別のひなが育っている。

倒れたあと、鉄の棒は手放さないまま、周りに割りかけの骨が散らばる。
