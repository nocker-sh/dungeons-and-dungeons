# ベレーダック

## 暮らし（制作案）

大きな赤いベレー帽を見つけたスタンプダックのメス。片方の翼でいつも帽子のふちを押さえ、首をあまり傾けずに歩く。帽子が汚れると、群れから少し離れたところで羽でぬぐう。

倒れたあとも、帽子は脱げずに頭に残っている。

## 制作上の決め事（確定）

- スタンプダックの亜種。頭を囲む帽子の帯、つば、天ボタンのある赤いベレー帽をかぶった姿。帽子の種類で亜種を増やせるシリーズの起点（ユーザー指定）。
- 靴違いのブーツダックとともにスタンプダックの系統にまとめる。
- スタンプダックのオスはブーツを履き、メスは帽子をかぶる（ユーザー指定）。
- 顔はスタンプダックと共通の、小さな黒い目と幅広く開いた黄色いくちばしに揃える（ユーザー指定）。

## 未決定

- 数値とワザはスタンプダックと共通の暫定値。

## 画像から確認した造形

白い鳥、赤い帽子形の冠と赤い首布。冠を普通の鶏の細い鶏冠へ変えない。
