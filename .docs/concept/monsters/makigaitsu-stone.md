# スピラスネイル（岩殻）

## 画像から確認した造形

灰緑の短い胴と金色の楕円眼。岩の殻に赤い角張った渦と緑の上面。紫殻の元種と配色を混ぜない。既存攻撃画像は通常より殻が小さく胴が長いので新規差分の体型基準にしない。
