# パラソリーフ

## 暮らし（制作案）

3層・毒沼の温室に生える草の子。茶色い細身の体から伸びた二枚の大きな葉を、細い腕で傘のように掲げ、割れたガラス屋根から落ちる毒のしずくをよけて歩く。しずくが落ちない日も、葉を下ろさない。中ボスとしては、温室の通路の真ん中に根を下ろした個体。

倒れたあと、葉が閉じてしおれ、根元に毒花の種が残る。

- ユーザー選定の元画像を採用。

## 制作案：系統

パラソリーフは若葉の姿、バドアイは蕾の姿、シードロードは温室の奥で大きく育った姿。同系統の成長と環境差としてまとめる案。

## 制作メモ

仲間の成長と回復を強めた後も、温室の節目で防護と回復が働く相手として攻撃の目安を調整する。体力・ワザ・報酬は維持し、毒が通らないことと被害の大きさを分けて測る。

## 画像から確認した造形

緑の大きな葉傘、葉の腕、茶の細い胴、黄色い眼。傘は植物の葉。
