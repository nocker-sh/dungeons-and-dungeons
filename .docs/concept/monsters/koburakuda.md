# アクアサウル

## 暮らし（制作案）

1層・巨人たちの墓場の水たまりを渡り歩く、首の長い生き物。緑の胴にひれのような四本の脚を持ち、細長い首の先の顔はいつも口の端だけで笑っている。骨のあいだにたまった雨水へ首を差しこんで飲み、水が少ない日は首を骨に巻きつけたまま次の雨を待つ。

倒れたあと、首を巻きつけていた骨片が残る。

## 制作上の決め事（確定）

- ユーザー選定の元画像を採用。長い首と緑の胴、淡い腹側を保持する。

## 未決定

## 画像から確認した造形

淡緑の長首と四本脚、白い多角形の顔、波形の口、短い尾。ヒレの旧案と四本脚を混ぜない。
