# キャンドラ

## 暮らし（制作案）

1層・巨人たちの墓場で、骨のあいだに立って灯る白い蝋のろうそく。頭のとがった火を何より大事にしていて、自分の息で消さないように、いつも両手で口元を押さえている。困った顔のまま背を丸めて火をかばい、近づくものにだけ、その火を吹きつける。

倒れたあと、溶けた蝋の溜まりと曲がった芯が残る。

## 制作上の決め事（確定）

- 溶けかけた白いろうそく。頭に灯った火がとがった形で揺れ、口元を手で隠して困った顔をしている（採用画像）。
- 黒い亜種はソウルキャンドラ。

## 未決定

- 数値とワザは仮。1層の道中の敵として、入れ替える前の敵の強さを引き継いでいる。頭の火を吹きつける（ろうそくの火）。

## 画像から確認した造形

象牙色の垂れた蝋の体、細い赤眼、橙色の菱形の炎。炎を角や髪として固定しない。
