# ベノムコルンバ

## 暮らし（制作案）

3層・毒沼の温室に住みついたコルンバ。パンくずの代わりに毒花の種をついばむうちに毒が効かなくなり、羽は淡い緑に、まだらは紫に変わった。吐く息に毒が混じり、体の周りにはいつも緑の泡が浮いている。

倒れたあと、のどの袋にためていた毒花の種がこぼれる。

## 制作上の決め事（確定）

- 淡い緑の羽毛と紫のまだら模様を持つ。周りに毒の泡が浮かぶ。
- 色だけでなく、殻・羽・角・尾などの形と大きな模様で見分けられるようにする。

- 数値は元の種を基準とする暫定値。仲間化は未設定。

## 制作メモ：戦闘での役割

3層の通常戦と終盤の戦闘に独立した亜種として配置する。毒に強く、単体へ毒を吐く。温室の硬い敵に対して速く低体力にし、先に倒して毒を止める役割にする。報酬も同じ層の強さに合わせる。数値と出現頻度は暫定調整で、確定仕様を意味しない。

## 画像から確認した造形

灰緑の鳩、暗赤の斑点と黄緑の泡。毒泡は翼の模様と別。
