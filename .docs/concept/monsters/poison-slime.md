# ヘドロスライム

## 暮らし（制作案）

1層・巨人たちの墓場の、湿った窪みに住む粘体。水たまりに浸かっているうちに濁った紫に染まり、体のあちこちから黄緑の泡が湧いている。垂れた目はいつも眠たげで、這った跡にはしばらく草が生えない。

倒れたあと、泡の消えたしみの中に、しまっていた回復薬の瓶がひとつ残る。

## 制作上の決め事（確定）

- 濁った紫と緑の粘体。黄緑の垂れ目で、黒・白とは違ういやらしさを出す。口は持たない。
- 体の表面と足元の毒の泡で、紫・緑の粘体の性質を示す。

## 画像から確認した造形

紫と黄緑が流れる面模様の液体、黄緑の細眼と泡。単色スライムにしない。
