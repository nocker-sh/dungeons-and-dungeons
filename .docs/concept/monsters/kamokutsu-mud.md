# マッドダック

## 暮らし（制作案）

水たまりの多いあたりに住むスタンプダックのオス。薄茶の羽に泥色のまだらを散らし、折り返しの付いた茶色の長靴で、ほかの個体が入らない泥の中を大股で歩いて餌を探す。長靴には前の持ち主が描いたらしいジグザグの帯が残っていて、本人はそれを気に入っている。中に泥をためたまま歩くので、足取りは重いが踏みこみは深い。

倒れたあと、長靴の中から泥と結晶のかけらが出てくる。

## 制作上の決め事（確定）

- 薄茶色の羽毛に大きな茶色の斑点を持つスタンプダック。細い鳥の脚が履き口に入り、折り返しと厚い靴底のある茶色の長靴を実際に履く。長靴には淡いジグザグの帯がある。
- ブーツダックと同じ「靴違い」のシリーズ（ユーザー指定）。マッドダックはスタンプダックの亜種。鳥の脚が別の長靴の履き口に入る姿にする。
- ダックリングはスタンプダックのヒナ（ユーザー指定）。
- スタンプダックのオスはブーツを履き、メスは帽子をかぶる（ユーザー指定）。
- 顔はスタンプダックと共通の、小さな黒い目と幅広く開いた黄色いくちばしに揃える（ユーザー指定）。

## 制作メモ：戦闘での役割

0層の通常戦と終盤の戦闘に独立した亜種として配置する。元の種より遅く、泥はねで足止めする。序盤の手数を増やしすぎないため体力と攻撃を抑える。数値と出現頻度は暫定調整で、確定仕様を意味しない。

## 画像から確認した造形

茶白の鳥、巨大な靴状足の白いジグザグ。旧小さい裸足の案を使わない。
