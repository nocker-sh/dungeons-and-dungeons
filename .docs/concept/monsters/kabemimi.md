# ミミウォール

## 暮らし（制作案）

1層・巨人たちの墓場で、墓石に混じって立つ灰色の石壁。左右で形の違う耳を生やし、見られると目を丸くしたまま固まる。誰も見ていないときだけ短い四本の足で少しずつ歩くので、墓石の並びは来るたびに少し変わっている。

倒れたあと、崩れた壁のかけらに、垂れた耳の形が残っていることがある。

## 制作上の決め事（確定）

- 崩れかけた石の壁に、垂れた耳と小さな足が生えたもの。驚いた顔で固まっている（採用画像）。
- 可愛さを生かして大きな大人や強いバージョンへ展開する（ユーザー案）。大人の石壁と強い城門型の画像を追加し、小さな姿も保持する。

## 未決定

- 数値とワザは仮。1層の道中の敵として、入れ替える前の敵の強さを引き継いでいる。とても遅く硬い。石の体ごとぶつかってくる（石壁あたり）。縛りが効きにくい。
- 大人・城門の出現場所と数値、仲間としての成長。

## 画像から確認した造形

灰色の欠けた壁板の小さな胴、左右の耳状の石、白い小さな縦眼、短い足。大眼の旧案を使わない。
