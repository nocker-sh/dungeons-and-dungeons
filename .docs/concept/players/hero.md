# 紫髪

主人公（悪魔召喚師）の外見候補の一つ。表示名と画像は [[concept/data/players.json]] を正とする。主人公の設定は外見4種で共通とし、この資料にまとめる。外見は後から変えられるので、来歴や想いを外見ごとに分けない。

## 制作上の決め事（確定）

- 主人公は悪魔召喚師。固定のセリフは持たない。気持ちは返答の選択肢で表し、決めつけない。
- 悪魔のロクスに借りがあり、ロクスをダンジョンの最奥へ連れて行ってあげたい。これが物語の軸。
- 4層（底なしの祭壇）より先は未開拓で、最奥はまだ誰も知らない。
- 本人は防具を着けず、レベルでも成長しない。戦う力は契約した悪魔から得る。呼んだ悪魔はみんな秘密の部屋に住み、見送りはない。

## 制作案（勤めと稼ぎ）

- 召喚師も、谷では日当で働く冒険者の一人。毎朝籠で降り、夕方に換金して帰る。
- 稼ぎは、雇った仲間への支払いと、秘密の部屋に住む悪魔たちの暮らしに消える。呼んだ悪魔を見送らないぶん、養う口は増えていく。
- ロクスへの借りと二人のあいだの約束は、ロクスの会話の端や、主人公が籠に乗り続けることから「何かあったんだろう」と感じられる程度にとどめる。

## 未決定

- 借りの中身、二人の過去、約束の中身、出会い方。資料には書かない。
- 最奥に何があるか、最奥に着いたときのこと。

## 画像から確認した造形

紫短髪、黒ピクセル目隠し、白黒服と紫肩布。瞳や顔の別案を補わない。
