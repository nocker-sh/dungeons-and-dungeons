# 夜の森の焚き火

街の外へ出た先で、森の空き地に焚き火を囲む場所。ワールドマップの実装時に使う予定の背景で、ここで会話・演出の場面（ムービー）を流す想定。はじめから遊ぶときの開幕の場面（街へ着く前の夜。台本は [[content/data/conversations.json]] の `opening-campfire`）の背景にも使う。ワールドマップ上の位置、行き先、街からの距離は未設定。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

街を出た夜、道の脇の空き地で火を焚いて休む旅の一場面。光は焚き火が中心で、周りは夜の暗さを保つ。

### 広さと使う人数

空き地は約10m×8m。焚き火の石組みは直径約0.6m、腰掛ける倒木は長さ約2m・高さ約0.4m。会話で2〜3人の上半身を焚き火の左右に重ねる。

### 配置と接続

空き地の奥を土の道が横切り、柵沿いに曲がって森の奥へ続く。道の先、木々の間に遠い街の灯りを小さく置く（街を出てきた方向として描いたもので、位置関係は確定しない）。

### 主ショット

空き地の端、高さ約1mの低い魚眼。左右の端の幹が内側へ傾いて画面を囲い、上は枝葉の切れ間に紺の夜空と細い月。

手前は平らな土と短い草、中景は焚き火と倒木・荷物・やかん、奥は道・柵・針葉樹の並び・遠い街。

### 矛盾を防ぐ確認

人物を描かず、焚き火の左右と手前に上半身を重ねられる空いた地面を残す。焚き火・倒木・荷物を魚眼の迫力のために巨大化しない。焚き火の灯りは平らな暖色の面で描き、光のにじみや煙で表さない。

## 場所の意味と動線

森側の荷と人が支度する拠点。火の周囲、寝る場所、荷を置く場所を分け、夜でも出口へ足が届くようにする。

## 生活と物の流れ

ここからつながる層は同じ谷の第一層。別のダンジョンを増やさない。飲用水は蓋付きで運び、汚れた水と排泄物は生活圏から分離して回収する。ゲームの到達条件を資料から解放しない。

## 実装との境界

移動の可否、回収物、解放条件、出撃先は正本の規則を使う。この資料は価格・回復・新しい移動操作を追加しない。
