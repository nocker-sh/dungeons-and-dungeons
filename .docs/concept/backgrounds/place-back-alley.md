# 路地裏

商店街の店の裏手にある荷受けの小さな中庭。短い依頼戦闘を行う場所で、探索の移動を挟まず一戦に入る。個々の裏口がどの店のものかは未設定。

## 暮らし（制作案）

店の裏口に空き箱と樽が積まれ、窓の間に洗濯物の綱が渡る。返す瓶や仕入れの箱がここを通る。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

細い路地が開けた石敷きの中庭。戦う床は中庭の中央。

### 広さと使う人数

中庭は約7m×6m、路地の幅約2m。裏口は高さ2.1mで低い石段2〜3段、箱約0.5m、雨水の樽約1m、2〜3階建て。

### 配置と接続

商店街の店の裏側。奥で路地が細くなって曲がり、灯りのある通りが少し見える。溝は一本の直線。

### 主ショット

路地の入口の箱の脇、高さ0.6mから見上げる魚眼。張り出した上階と軒が左右から迫る。

手前は左の積み箱・袋と右の雨水の樽、中景は中庭の石敷き、奥は裏口と灯り・積み箱・洗濯物・通りへの抜け。

### 矛盾を防ぐ確認

普通の大きさの裏庭にとどめ、建物で巨大な谷を作らない。積み箱を床の中央に置かない。

## 戦闘用背景のショット計画（制作案）

探索・場所の背景とは別に、戦闘の後ろに置く絵。通常の背景（低い位置から仰ぐ強い魚眼）とは別のショット。高さ約2.5m・約25°見下ろしの弱い魚眼で、奥の壁で閉じる。画面の下から上4割近くまでを平らで何も置かない床にし、敵の立つ中央を空ける。手前の縁取りは左右端の小さな形だけにする。

| 項目   | 内容                                                                                                                     |
| ------ | ------------------------------------------------------------------------------------------------------------------------ |
| 戦う床 | 店の裏の小さな石敷きの中庭（約7m×6m）。灰ベージュの石敷きの色面。溝は下端の一本だけ                                      |
| 奥     | 2〜3階の木骨の建物の裏                                                                                                   |
| 置く物 | 裏口（2.1m）と低い石段二段・小さな灯り、高い位置の洗濯ひも、左奥に細い路地の抜け。積み箱は左端、雨水の樽（1m）は右端だけ |
| 上端   | 軒の間の上端だけに紺の夜空                                                                                               |

戦闘中は背景の層が約1.18倍に寄って少し傾き、明るさ35%・彩度70%に落ちる（`director.ts` の突入演出）。縦は上部に行動順と敵の札、下部に隊列と指示、横は右上に敵の札・右下に発動が重なるため、主張のある物は奥の壁の左右に小さく置く。
