# 商店街の曲がり角

[[concept/backgrounds/place-shop|商店街]]の通りが曲がる角。店を閉めたあとの通りで、短い依頼戦闘を行う。商店街の施設画面とは別のショットで、同じ通りを指す。新しい店は足さない。

## 暮らし（制作案）

閉店後、鎧戸を半分下ろした店先に、翌朝の品や箱が残る。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

商店街の通り（幅4m）が曲がり角で少し広がる場所。戦う床は角の前の石畳。

### 広さと使う人数

角の空きは約7m×6m。店の階高約3m、戸の高さ2.1m。

### 配置と接続

商店街の主ショットと同じ通り・庇・看板の絵柄を引き継ぐ。角の向こうへ道が続き、建物の角に隠れる。

### 主ショット

通りの中ほど、高さ0.7mから曲がり角を見上げる魚眼。左右手前に店の柱・陳列台・樽・布をかけた箱、上端に庇と絵看板。

手前は陳列台と庇、中景は角の石畳、奥は鎧戸の店と曲がって消える道。

### 矛盾を防ぐ確認

通りを巨大な都市の谷にしない。看板は絵のみで文字を焼き込まない。施設画面の商店街と材質・灯りを揃える。

## 戦闘用背景のショット計画（制作案）

探索・場所の背景とは別に、戦闘の後ろに置く絵。通常の背景（低い位置から仰ぐ強い魚眼）とは別のショット。高さ約2.5m・約25°見下ろしの弱い魚眼で、奥の壁で閉じる。画面の下から上4割近くまでを平らで何も置かない床にし、敵の立つ中央を空ける。手前の縁取りは左右端の小さな形だけにする。

| 項目   | 内容                                                                         |
| ------ | ---------------------------------------------------------------------------- |
| 戦う床 | 通りが角で広がる石畳（約7m×6m）。灰ベージュの石畳の色面                      |
| 奥     | 鎧戸を閉めた二階建ての店の並びと縞の庇                                       |
| 置く物 | 絵だけの小さな吊り看板。通りは右奥で建物の角に隠れる。樽と陳列台は左右端だけ |
| 上端   | 上端だけに紺の夜空                                                           |

戦闘中は背景の層が約1.18倍に寄って少し傾き、明るさ35%・彩度70%に落ちる（`director.ts` の突入演出）。縦は上部に行動順と敵の札、下部に隊列と指示、横は右上に敵の札・右下に発動が重なるため、主張のある物は奥の壁の左右に小さく置く。
