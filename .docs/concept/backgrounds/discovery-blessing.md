# 渓谷の祝福

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

道の脇に人が近づいて使う小さな祭壇。各層で共通するため、周囲の岩や光だけを層に合わせる。

### 寸法と動線

祭壇は幅1.2m×奥行0.7m×高さ0.9m、隣の台に長辺0.3mの本。人が立つ幅0.9mと、道へ戻る足場を残す。結晶の欠片は手で持てる0.1〜0.2m。

### 主ショット

人が近づく側、高さ0.6mから祭壇の縁越しに本と欠片を仰ぐ魚眼。手前の石の角、中景の使う天板、奥の戻る道を一つの床につなぐ。

### 寄りと整合の確認

本へ寄る時も同じ隣の台を使う。人用の祭壇を神殿の巨大な基壇にしない。誰が作ったか、どの神に属するかは決めない。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
