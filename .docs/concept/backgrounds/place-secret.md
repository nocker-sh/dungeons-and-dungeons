# 秘密の部屋

## 設定・制作メモ

フードを被った番人が悪魔の召喚を見守る。召喚石を使い、呼び出した悪魔と契約する。

## 暮らし（制作案）

ギルドの奥の部屋。呼び出した悪魔はここに住む。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

ギルド奥で契約する私的な部屋。酒場のにぎわいから一枚の扉で離れる。

### 広さと使う人数

内寸4m×5m、天井2.8m程度。中央の契約に使う床は直径1.5m、壁際の腰掛けは長さ1.8m。

### 配置と接続

酒場の奥の扉を入口とし、正面に契約の床、左右に本と待つ腰掛け。入口から床まで幅0.9m以上を通す。悪魔の居住の細かな部屋割りは未決定。

### 主ショット

入口の片側、高さ0.7mから床と奥の棚を仰ぐ魚眼。扉枠と頭上の梁で小さな部屋に包まれる感覚を出す。

手前は契約に使う台の縁、中景はヨルと相手が立つ床、奥は本棚と入口の反対の壁。弱い紫の灯りとギルド由来の暖色。

### 用事と寄りのショット

相手の立ち位置からヨルの向こうに酒場側の扉が見える中景。床の印の寄りで新しい宗教や文字を作らない。

### 矛盾を防ぐ確認

部屋を魔法の巨大図書館にしない。月形の灯りを残す場合も高さ0.3m程度の器具として計画し、部屋の実寸から決める。

## 画像から確認した造形

紫の床印と紫灯り、木梁と帳場、奥の紙や瓶。印の形を別の魔法陣に変えない。

## 縦版のショット計画（制作案）

スマホの縦長の画面（`useWide` が偽）では `world.json` の `image`、横長の画面では `wideImage` を使う。縦版は横版 `secret-fisheye-comic-v3.webp` と同じ場所・家具の左右関係・色相を保ち、縦の枠で構図を組み直す（中央の切り抜きにしない）。

- ショット: 入口の低い位置から丸い部屋を見上げる。閉じた目の紋のある丸い石床を中央下寄り、三日月の飾りを上端の中央、奥の壁に本棚と扉、左右に赤い旗。扉の輪は左端、肘掛け椅子と封の巻物は右端と右下の隅。紋は平らな紫の面で光らせない。下端から赤い敷物が入る。
- 共通: 主役を中央70%の幅に収め、手前の枠の物は左右の端と下の隅だけに置く。下の中央（横20〜80%、縦55〜88%）は人物の上半身を重ねるため、平らで物の少ない床にする。
- 描き込み: 農場の縦版 `quick-farm-v1-fisheye-comic-v3` の密度を上限にし、横版より減らす。小物・木目・目地・板や瓦の一枚ずつ・細かな装飾を省き、大きな形と平らな色面で組む。網点は影の一部だけ。
- 明るさと線: 横版と同じ時間帯・明るさ・色相を保ち、明るさの補正をしない。大きな面すべてに太い黒の輪郭を引き、影には境界の分かる漫画の網点をはっきり使う。ブラシ跡・グラデーション・霞は描かない。

## 共用室と住まいの範囲

既存の4×5mの見え方は地下の共用室。ヨルと五人の悪魔の就寝は個別の寝室へ分ける。食事準備、洗い場、便所、寝具の手入れも独立させる。地下全体の配置は map:guild。秘密の部屋の由来と約束の内容は明かさない。
