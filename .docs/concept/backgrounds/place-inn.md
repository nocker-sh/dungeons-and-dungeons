# 宿

## 設定・制作メモ

冒険者ギルドの建物の中にある宿（ユーザー指示）。以前は街の右の独立した建物だったが、ギルドの中へ移した。屋根裏・普通の部屋・高い部屋の3段階。宿泊、成長、仲間との雑談の場。料金や効果は [[content/data/rooms.json]] の暫定値。

## 暮らし（制作案）

冒険者の多くが住まいにしている。部屋の格は財布の中身で決まり、屋根裏から始めて普通の部屋へ移るのが一人前の目安。仕送りや借金の返済を優先して、稼げるようになっても屋根裏に残る者もいる。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

ギルドの1階奥にある宿の帳場と、上階の客室へ上がる階段。ギルドのホールから階段の角へ回り込むと、帳場から同じ建物の客室へ進めることを見せる。

### 広さと使う人数

ギルドの外形約18m×14mの中に収める。描く帳場の一角は内寸6m×5m、天井3m程度。4人が荷を持って並べる待ち場所と、幅1.2mの階段を取る。

### 配置と接続

ギルドのホールから宿の帳場、奥の廊下、上階へ続く階段へつなぐ。外への出入りはギルドの正面入口を使い、宿の専用の玄関の有無は未決定。階段は約18段で3m上がる折り返しを計画し、全体を受付の小さな段差に押し込まない。上階に客室、さらに屋根裏。客室総数は未決定。

外壁を仮に片側0.3m取ると、ギルドの外形18m×14mに対して上階で使える範囲は17.4m×13.4m。客室奥行5m＋廊下1.4m＋客室奥行5mの11.4mが収まる。幅方向は普通の部屋5m＋高い部屋6m＋階段や壁を含む帯4.4mという検証用の並びを置ける。これは客室数の決定ではなく、外観の中に両方の部屋と廊下を収められるかの確認。

```text
上階の配置を確かめる断面例（縮尺図ではない）
┌───────────┬────────────┬─────────┐
│ 普通の部屋  │ 高い部屋     │ 階段等の帯│ 奥行5m
│ 内寸5×5m   │ 内寸6×5m     │ 幅4.4m   │
├───────────┴────────────┤         │
│ 廊下：幅1.4m                         │         │
├────────────────────────┤         │
│ 反対側の客室に使える奥行5m            │         │
└────────────────────────┴─────────┘
```

階段は幅1.2mの2列と踊り場で折り返す。18段をおおむね9段ずつに分け、一列の水平距離約2.4mと踊り場約1.2mを取る。屋根裏では側壁際の低い部分を通路へ数えず、中央の立てる床へ入口をつなぐ。

### 主ショット

入口から一歩入った高さ1m、右の帳場と奥の階段を同時に見る斜めの魚眼。

手前は荷を置く低い台か扉枠、中景は受付、奥は階段の曲がり角と上階の廊下。赤い絨毯の階段と鍵棚を、ギルドのホールに見える宿の一角とそろえる。

### 用事と寄りのショット

受付の用事は客の目線から帳面を見る中景。階段の手すり越しの振り返りで、階下の暖かい灯りと客室へ向かう動線を見せる。

### 矛盾を防ぐ確認

鍵や呼び鈴は片手で扱える寸法。受付と客室で階高・梁・窓の向きを変えない。大きな荷物で階段と入口を塞がない。

## 画像から確認した造形

橙灯り、赤紫敷物、木の帳場と階段、奥の棚。ベッドのある客室とは別。

## ギルドの中の宿としての候補

- 候補: inn-guild-fisheye.webp。元PNGは `private/art/originals/scenes/inn-guild-fisheye.png`。
- 承認済みの現行画像を編集対象にし、配置を保ったまま壁をギルドのホールと同じ木組みに、左手前の外への扉をホールへの開口に替えた。
- 現行データは承認済みの `inn-fisheye-comic-v4.webp` のまま。差し替えはユーザーの判断を待つ。

## 描き込みと明暗の見直し

小物・窓枠・目地・木目を省き、大きな形と平らな色面、影の部分だけの網点で構成する。明るめ・低コントラスト・くすんだ彩度にし、輪郭線以外の黒に近い影を使わない。- 候補と旧街・農場を並べ、アルダとミレナの上半身を重ねた一覧で比べて選んだ。人による合格は未記録。

## 縦版のショット計画（制作案）

スマホの縦長の画面（`useWide` が偽）では `world.json` の `image`、横長の画面では `wideImage` を使う。縦版は横版 `inn-fisheye-comic-v4.webp` と同じ場所・家具の左右関係・色相を保ち、縦の枠で構図を組み直す（中央の切り抜きにしない）。

- ショット: 入口から一歩入った低い位置から斜めに見上げる。中景の右に帳場と鍵棚、中央奥に赤い絨毯の階段を寄せ、手前から階段へ赤い絨毯の通路を通す。扉の輪は左端、赤い荷箱は右下の隅だけに置く。鍵棚は大きな四角の塊に省く。
- 共通: 主役を中央70%の幅に収め、手前の枠の物は左右の端と下の隅だけに置く。下の中央（横20〜80%、縦55〜88%）は人物の上半身を重ねるため、平らで物の少ない床にする。
- 描き込み: 農場の縦版 `quick-farm-v1-fisheye-comic-v3` の密度を上限にし、横版より減らす。小物・木目・目地・板や瓦の一枚ずつ・細かな装飾を省き、大きな形と平らな色面で組む。網点は影の一部だけ。
- 明るさと線: 横版と同じ時間帯・明るさ・色相を保ち、明るさの補正をしない。大きな面すべてに太い黒の輪郭を引き、影には境界の分かる漫画の網点をはっきり使う。ブラシ跡・グラデーション・霞は描かない。
