# 普通の部屋

## 設定・制作メモ

宿の有料の部屋。宿泊中に成長と仲間との会話が起こる。

## 暮らし（制作案）

寝台と小机があり、仲間と同じ部屋で話ができる広さ。屋根裏から移った夜に、荷をほどきながら話す場面に使える。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

宿の上階の相部屋。4人が休み、荷をほどいて話せる普段の居場所。

### 広さと使う人数

内寸5m×5m、天井2.7m程度。寝台4台は2.1m×0.9m、小机は幅0.8m×奥行0.5m、椅子座面0.45m。

### 配置と接続

寝台は左右の壁に沿って2台ずつ。奥の中央に小机と窓、手前の中央に廊下側の入口。机に向かう椅子を引いても幅0.9mの出入口動線を残す。荷箱は寝台下。

### 主ショット

入口の横、高さ1mから対角の窓へ向ける魚眼。左右の寝台が迫り、天井の梁が画面を包む。

手前は寝台の足と入口の枠、中景は仲間が集まる床と机、奥は外観に対応した出窓。布の質と立てる天井で屋根裏との違いを出す。

### 用事と寄りのショット

椅子に座る高さから、同じ部屋の寝台越しに向かいの仲間を見る。すべての会話を部屋全景で説明しない。

### 矛盾を防ぐ確認

4台を成人寸法で配置できる。外観の出窓と窓枠、同じ階の梁を引き継ぐ。画像ごとに入口と窓を左右逆へ入れ替えない。

## 画像から確認した造形

木梁の室内、左右の二床、赤い寝具、中央の赤敷物と黄灯り。

## 縦版のショット計画（制作案）

スマホの縦長の画面（`useWide` が偽）では `world.json` の `image`、横長の画面では `wideImage` を使う。縦版は横版 `room-normal-fisheye-comic-v3.webp` と同じ場所・家具の左右関係・色相を保ち、縦の枠で構図を組み直す（中央の切り抜きにしない）。

- ショット: 寝台の高さから赤い敷物越しに、奥の壁の中央の窓（月）を見上げる。赤い毛布の寝台を左右の壁際に2台ずつ奥へ並べ、間に小卓とランプ。扉の輪と枠は左端、手前の寝台の足は右下の隅だけに置く。
- 共通: 主役を中央70%の幅に収め、手前の枠の物は左右の端と下の隅だけに置く。下の中央（横20〜80%、縦55〜88%）は人物の上半身を重ねるため、平らで物の少ない床にする。
- 描き込み: 農場の縦版 `quick-farm-v1-fisheye-comic-v3` の密度を上限にし、横版より減らす。小物・木目・目地・板や瓦の一枚ずつ・細かな装飾を省き、大きな形と平らな色面で組む。網点は影の一部だけ。
- 明るさと線: 横版と同じ時間帯・明るさ・色相を保ち、明るさの補正をしない。大きな面すべてに太い黒の輪郭を引き、影には境界の分かる漫画の網点をはっきり使う。ブラシ跡・グラデーション・霞は描かない。

## 物理的な部屋との区別

この資料は客室の共通の見え方を扱う。具体的な寝床、出入口、生活設備は rooms/ の各室資料、配置は地図 map:guild を正とする。普通・上等は各二室、屋根裏は一室。画像の共有は同じ物理的な部屋という意味ではない。
