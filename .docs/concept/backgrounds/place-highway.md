# 街道

街から畑の方へ出る土の道で、短い依頼戦闘を行う場所。探索の移動を挟まず一戦に入る。どこまで続く道か、他の街とつながるかは未設定。

## 暮らし（制作案）

朝の市へ野菜を運ぶ荷車が毎日通る、普通の田舎道。曲がり口では荷車が脇へ寄ってすれ違う。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

街を出てすぐの、荷車の轍が残る道。戦う床は道が膨らんだすれ違い場。

### 広さと使う人数

道幅約5m、曲がり口のすれ違い場は約8m×6m。道標の石約0.8m、道沿いの柵約1m、灯りの柱約2.2mを目安にする。

### 配置と接続

街の門の方から畑の方へ続く。奥の小高い位置に街の屋根と門を小さく置く。農場との距離・位置関係は厳密に決めない。

### 主ショット

路肩、高さ0.7mから道の曲がり口を見上げる魚眼。左手前に道標の石と低い石垣、右手前に傾いた柵の柱で画面を囲う。

手前は石垣・柵・草、中景はすれ違い場の土の床（轍は長い平らな帯）、奥は曲がって消える道・生け垣・遠い街の灯り。

### 矛盾を防ぐ確認

街を人の寸法のまま遠くに置く。道標や柵を魚眼の迫力のために巨大化しない。床に物を置かず、4人と敵が立てる平らな面を残す。

## 戦闘用背景のショット計画（制作案）

探索・場所の背景とは別に、戦闘の後ろに置く絵。通常の背景（低い位置から仰ぐ強い魚眼）とは別のショット。高さ約2.5m・約25°見下ろしの弱い魚眼で、奥の壁で閉じる。画面の下から上4割近くまでを平らで何も置かない床にし、敵の立つ中央を空ける。手前の縁取りは左右端の小さな形だけにする。

| 項目   | 内容                                                                                   |
| ------ | -------------------------------------------------------------------------------------- |
| 戦う床 | 道が膨らんだすれ違い場（約8m×6m）。茶の土の色面と、長い平らな帯の轍                    |
| 奥     | 低い石垣（0.8m）と生け垣                                                               |
| 置く物 | 左に道標の石（0.8m）、右に灯りの柱（2.2m）と短い柵。生け垣の向こうの丘に小さな街の屋根 |
| 上端   | 上端だけに紺の夜空                                                                     |

戦闘中は背景の層が約1.18倍に寄って少し傾き、明るさ35%・彩度70%に落ちる（`director.ts` の突入演出）。縦は上部に行動順と敵の札、下部に隊列と指示、横は右上に敵の札・右下に発動が重なるため、主張のある物は奥の壁の左右に小さく置く。

## 場所の意味と動線

荷車と徒歩が行き違う街道。道の幅を荷の仮置きで塞がず、車を止める場所を歩く流れから外す。

## 生活と物の流れ

街と村の食料・日用品・郵便をつなぐ。馬車が運ぶ手紙と荷を混ぜず、休憩時は車輪を止めて幌と綱を確かめる。

## 実装との境界

移動の可否、回収物、解放条件、出撃先は正本の規則を使う。この資料は価格・回復・新しい移動操作を追加しない。
