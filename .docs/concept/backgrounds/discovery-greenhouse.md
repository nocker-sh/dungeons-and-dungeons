# 温室の種床

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

温室の通路に沿って、種床と煎じる道具が残る小さな作業場所。

### 寸法と動線

種床1.5m×0.8m・高さ0.75m。やかん0.25m、机の作業面0.75m、通路幅1.5m。描く植物は高さ1〜2mを目安にし、根元と土を持つ。

### 主ショット

通路側、高さ0.8mから近い葉の下を通して種床と割れたガラスを見る魚眼。手前の葉、中景の土とやかん、奥の屋根。

### 寄りと整合の確認

煎じる寄りではやかんを安定した作業台へ置く。種床と通路は毒水より高い同じ支持床。葉を増やして使う場所を隠さない。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
