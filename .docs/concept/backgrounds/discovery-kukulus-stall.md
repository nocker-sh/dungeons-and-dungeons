# ククルスの露店

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

探索の道の脇で品を並べるククルスの取引場所。現在の挿絵は本人の画像で、未使用のゴブリン露店を完成背景として流用しない。

### 寸法と動線

制作する場合は台幅1.2m×奥行0.6m、客側の足場幅0.9m。台高は本人の既存の体格と作業できる高さを照合して決める。瓶0.1〜0.25m、包みは手で運ぶ大きさ。

### 主ショット

客が屈んだ高さ0.8mを候補に、台の縁越しに品を見る魚眼。手前の台、中景の品と本人の立つ位置、奥の戻る道。本人の体格が決まる前にカメラ高さを固定しない。

### 寄りと整合の確認

品の寄りでも既存の本人の姿と台の高さを保つ。商人を人と同じ身長へ引き伸ばさない。屋根や建物を新しい常設施設として確定しない。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
