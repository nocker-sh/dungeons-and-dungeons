# 巨人たちの墓場

## 設定・制作メモ

1層。大昔に死んだ巨人たちの骨が眠る谷。巨人は骨だけの背景で、生きた巨人や巨人の魔物はいない。道は骨の間を縫って続く。巨人の骨片は鍛冶屋で素材になる。

## 今の雰囲気（制作案）

静かで風の音が大きい。骨の間に古い墓碑と供物台が残り、冒険者は骨を掘る手を止めずに、通りがかりに供物台へ軽く頭を下げる。ミミウォールが墓石に紛れて歩くので、墓碑の数は数えるたびに合わない。

## 切なさの種（制作案）

墓守の灯には、誰かがまだ油を足している。墓守はもう谷に降りていないはずだが、灯は絶えない。供物台には干した果物が一つずつ置かれていく。置いていく人の顔は書かない。

## 持ち帰る物と、それで守られているもの（制作案）

巨人の骨片は鍛冶屋のヒルデが炉に入れ、骨の武器や骨鎧に仕立てる。ヒルデは骨を炉に入れる前に一言断る。骨鎧は、前に立つ者を一日でも長く谷から帰すための品として売られる。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

巨人の骨が眠る谷。大きな死んだ骨と、小さな人の仕事を同じ地面に置く。

### 広さと使う人数

巨人の肋骨の幅約6m、頭骨約3mをひとまとまりの制作基準とする。人用の道2m、墓碑高さ0.8m、供物台高さ0.75m。谷全体の寸法は決めない。

### 配置と接続

道は骨の間を縫い、供物台と休む場所は道の脇に置く。骨は岩や地面に支えられ、落ちた位置と埋まり方を持つ。生きた巨人は置かない。

### 主ショット

道の脇、高さ0.5mから肋骨の内側を斜めに仰ぐ魚眼。

手前は人用の墓碑か灯り、中景は通る道と骨の接地点、奥は肋骨と頭骨。大小の差を主題にし、巨人の骨に合わせて灯りや道具を巨大化しない。

### 用事と寄りのショット

供物台側から同じ骨を背に見せる中景。骨片の寄りは手で運べる欠片として扱う。

### 矛盾を防ぐ確認

一体分の骨の比率と床への接地。繰り返す巨大骨を飾りの柱にしない。墓守の灯・供物台は人用の作業場所。

## 画像から確認した造形

紫に照らされた灰の墓石と巨大な骨、暗い岩の墓場。

## 戦闘用背景のショット計画（制作案）

探索・場所の背景とは別に、戦闘の後ろに置く絵。通常の背景（低い位置から仰ぐ強い魚眼）とは別のショット。高さ約2.5m・約25°見下ろしの弱い魚眼で、奥の壁で閉じる。画面の下から上4割近くまでを平らで何も置かない床にし、敵の立つ中央を空ける。手前の縁取りは左右端の小さな形だけにする。

| 項目   | 内容                                                                                                                                    |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| 戦う床 | 骨の間の踏み固めた土の空き地（幅約8m）。灰紫の土の床                                                                                    |
| 奥     | 肋骨と頭骨の奥に立つ灰紫の岩の崖                                                                                                        |
| 置く物 | 奥の左右から肋骨（一本約6m）、右奥に半分埋まった頭骨（約3m）、左に人用の墓碑（0.8m）と供物台（0.75m）・小さな灯り。骨は中央を横切らない |

## 探索の背景の候補とショット計画（制作案）

ユーザー指示「同じ画像だと飽きる」「宝箱を見つけたり休憩する場所もほしい」に合わせ、層の背景を地点ごとに替える。地形・色・素材はこの層で揃え、地点だけを変える。どれも下へ潜る向きで描く。寸法と配置は上の空間設計に従う制作案で、確定したゲーム仕様ではない。

`world.json` の層の場所の `scenes` に縦（`image`）・横（`wideImage`）の組で登録する。エンジンは出来事が宝箱なら `treasure`、休む・手当ての選択肢がある発見なら `rest`、それ以外（戦闘・罠・ほかの発見）なら `path` の候補を、同じ種類の地点を通るたびに順に回して選ぶ。

一度生成した版はユーザーの背景への差し戻し（明るすぎる、輪郭と漫画のトーンが少ない）を受け、構図を保ったまま地下の暗さ・すべての大きな面の太い輪郭・影の網点を増やして描き直した（ファイル名の `-ink`）。後処理の明るさ補正は使っていない。描き直し前の版も消さずに残す。
