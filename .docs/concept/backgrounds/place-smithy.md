# 鍛冶屋

## 設定・制作メモ

ハンマーを持つ鍛冶屋の姐さんヒルデの店。武器と防具の強化と生産。

## 暮らし（制作案）

炉の火は朝から落ちない。巨人の骨片、錆びた歯車、黒い封蝋など谷から上がった素材が炉の脇に積まれ、ヒルデは素材を炉に入れる前に一言断ってから使う。修理代を払えない冒険者には古い鉄で継ぎを当てる。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

武器店の隣の仕事場。材料を置く、炉で熱する、金床で打つ流れが分かる。

### 広さと使う人数

作業場は内寸6m×7m、天井3.2m程度。炉は幅1.5m、金床は長さ0.7mで台を含む作業面高さ約0.8m。

### 配置と接続

右奥の炉、中央寄りの金床、左の材料と帳場。炉から金床へ1.2mの作業動線を取り、客が待つ床を入口側へ分ける。奥の扉を金床で塞がない。

### 主ショット

入口側の作業台の端、高さ0.6mから金床と炉を斜めに見上げる強い魚眼。

手前は台と金床の角、中景は職人が立つ場所、奥は炉と石壁。金床の迫力は距離と低いカメラで出し、家具と比べて数mの金床にはしない。

### 用事と寄りのショット

作業を見る中景は客側から、炉→職人の手元→金床の向きがつながる。素材の寄りは既存の鉄・骨片・封蝋の扱いを示す範囲。

### 矛盾を防ぐ確認

通常の炉と換気につながる煙道。桶・火ばさみ・ハンマーは手で扱える大きさ。低いカメラでも金床の台が床に接地する。

## 画像から確認した造形

石の炉の橙火、黒金床、木梁と工具棚。炉と作業床を保持。

## 縦版のショット計画（制作案）

スマホの縦長の画面（`useWide` が偽）では `world.json` の `image`、横長の画面では `wideImage` を使う。縦版は横版 `smithy-fisheye-comic-v3.webp` と同じ場所・家具の左右関係・色相を保ち、縦の枠で構図を組み直す（中央の切り抜きにしない）。

- ショット: 金床の手前の低い位置から見上げる。金床と台を中央下寄り、石の炉と火を中央上の奥に重ねる。壁の道具掛けは槌と刃を数本だけ。水桶は右下、鉄の延べ棒は左下の隅。火は平らな橙と黄の面で、光のにじみを描かない。
- 共通: 主役を中央70%の幅に収め、手前の枠の物は左右の端と下の隅だけに置く。下の中央（横20〜80%、縦55〜88%）は人物の上半身を重ねるため、平らで物の少ない床にする。
- 描き込み: 農場の縦版 `quick-farm-v1-fisheye-comic-v3` の密度を上限にし、横版より減らす。小物・木目・目地・板や瓦の一枚ずつ・細かな装飾を省き、大きな形と平らな色面で組む。網点は影の一部だけ。
- 明るさと線: 横版と同じ時間帯・明るさ・色相を保ち、明るさの補正をしない。大きな面すべてに太い黒の輪郭を引き、影には境界の分かる漫画の網点をはっきり使う。ブラシ跡・グラデーション・霞は描かない。

## 建物と生活区画

この背景で見える売場・作業場は room:smithy-work、寝室と生活設備を含む配置は map:smithy を参照。店の仕事場の制作寸法を保ち、寝台・台所・洗身・便所は奥の独立した区画へつなぐ。画像一枚に全機能が見える必要はないが、住まいとしての経路は資料間で成立させる。
