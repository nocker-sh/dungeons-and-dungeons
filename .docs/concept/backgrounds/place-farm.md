街の近くで短い依頼戦闘を行う場所。探索の移動を挟まず、畑や収穫を守る一戦に入る。

## 暮らし（制作案）

街の外の畑。冒険者に頼む小さな依頼が出る場所で、収穫が守れれば野菜で礼をする家もある、という程度の暮らしの近さで描く。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

街の近くの普通の畑。守る収穫と、人が働く場所の間で短い戦闘が起こる。

### 広さと使う人数

戦闘用に見せる土の空き地は約8m×6m。納屋は幅6m×奥行8m、戸高さ2.1m、柵高さ1m、作物0.2〜0.5mを目安にする。

### 配置と接続

空き地から納屋・畑の畝・柵の門へ通れる。戦闘を見やすくするために畑全体を無人の荒野へ変えない。遠くに街の屋根を置き、街との距離は厳密には決めない。

### 主ショット

柵の門のすぐ内側、高さ0.6mから畑と納屋を仰ぐ魚眼。近い柵で画面を囲い、中央に4人と敵が立つ床を残す。

手前は柵と畝、中景は戦闘の床、奥は通常寸法の納屋と街。青い夕暮れから夜へつながる光を計画する。

### 用事と寄りのショット

依頼の場面は納屋側から畑を見渡す中景。作物の寄りは実際の畝の位置から撮る。

### 矛盾を防ぐ確認

納屋の戸と作物で人の寸法が分かる。縦横版で同じ納屋・柵・門を引き継ぐ。迫力のために野菜や柵だけを巨大化しない。

## 画像から確認した造形

夕方の畑、木の納屋と柵、案山子、土の前景。縦横画像は構図が異なるので伸ばして代用しない。

## 戦闘用背景のショット計画（制作案）

探索・場所の背景とは別に、戦闘の後ろに置く絵。通常の背景（低い位置から仰ぐ強い魚眼）とは別のショット。高さ約2.5m・約25°見下ろしの弱い魚眼で、奥の壁で閉じる。画面の下から上4割近くまでを平らで何も置かない床にし、敵の立つ中央を空ける。手前の縁取りは左右端の小さな形だけにする。

| 項目   | 内容                                                                                     |
| ------ | ---------------------------------------------------------------------------------------- |
| 戦う床 | 納屋の前の土の空き地（約8m×6m）。茶の土の色面                                            |
| 奥     | 奥を横切る低い木の柵（1m）と門                                                           |
| 置く物 | 柵の向こうに畝、左奥に納屋（幅6m・戸2.1m）、右奥に小さなかかし、遠くの丘に小さな街の屋根 |
| 上端   | 上端だけに紺の夜空                                                                       |

戦闘中は背景の層が約1.18倍に寄って少し傾き、明るさ35%・彩度70%に落ちる（`director.ts` の突入演出）。縦は上部に行動順と敵の札、下部に隊列と指示、横は右上に敵の札・右下に発動が重なるため、主張のある物は奥の壁の左右に小さく置く。
