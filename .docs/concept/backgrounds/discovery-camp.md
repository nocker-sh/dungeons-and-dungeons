# 見捨てられた野営地

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

歩く道の脇に残った荷と古いテント。持ち主や見捨てた理由は未設定のまま残す。

### 寸法と動線

約4m×4mの足場。テント床2.4m×2m・棟高1.5m、寝袋長さ2.1m、やかん0.25m、消えた焚き火直径0.6m。テントと火は1m以上離す。

### 主ショット

道から足を踏み入れる高さ0.6m、近い荷越しにテントの開口を見る魚眼。手前の荷、中景の火と寝袋、奥の戻る道。

### 寄りと整合の確認

テントの中を見る寄りでも大人が寝られる長さ。4人用の宿泊施設だと確定しない。置き去りの理由を説明する新しい手紙や遺体は足さない。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
