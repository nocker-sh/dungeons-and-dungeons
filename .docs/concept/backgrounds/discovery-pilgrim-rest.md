# 巡礼者の最後の灯

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

道の脇で灯りと封蝋を世話し、巡礼者が休めた場所。今は仕事の途中の休み場として見る。

### 寸法と動線

約4m×3mの石の脇間。作業台1.2m×0.6m・高さ0.75m、長椅子1.8m・座面0.45m、灯り0.25m。机と長椅子の間に幅0.9mを取る。

### 主ショット

長椅子の端、高さ0.5mから灯り越しに戻る道へ向ける魚眼。手前の背板、中景の火と作業台、奥の赤紫の柱。

### 寄りと整合の確認

封蝋の寄りは台の同じ隅。火を巨大な篝火にせず、世話する人が手の届く灯りを保つ。巡礼の宗派は決めない。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
