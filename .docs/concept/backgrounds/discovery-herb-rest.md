# 薬草の乾燥室

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

湿った温室の通路の脇で、薬草を干し、種を煎じ、休む小部屋。

### 寸法と動線

内寸3m×4m・高さ2.4m程度。机は幅1.2m・高さ0.75m、乳鉢0.15m、吊るす束0.3m、椅子座面0.45m。通路側の入口から机の前を通れる。

### 主ショット

戸口脇、高さ0.9mから吊った束の下を抜いて机を見せる魚眼。手前の柱と束、中景の作業台、奥の腰掛け。梁に束を掛けても入口は塞がない。

### 寄りと整合の確認

種と乳鉢の寄りは同じ机。乾かす場所と毒水に浸る外の床を区別し、机を沼へ直接置かない。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
