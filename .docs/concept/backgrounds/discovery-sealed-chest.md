# 封じられた宝箱

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

道の脇で開けるか判断する、鎖と錠のある箱。周囲の足場から実際に触れられる。

### 寸法と動線

幅0.9m×奥行0.5m×高さ0.6mの箱、錠0.1m、荷袋0.5m。前に屈める幅0.9mを残し、蓋が開く後方の余白も取る。

### 主ショット

屈んだ高さ0.5mから錠と箱の上面へ斜めに向ける魚眼。手前の鎖、中景の蓋、奥の足場の端。

### 寄りと整合の確認

錠の寄りと全景で鎖の掛かる方向を保つ。鎖が蝶番や開口をすり抜けない。箱を家ほど大きくしない。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
