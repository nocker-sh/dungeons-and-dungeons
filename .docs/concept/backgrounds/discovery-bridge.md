# 鉄橋の巻き上げ機

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

橋の保守床で落ちた部品を扱う設備。人が操作する手と綱の行き先が分かる。

### 寸法と動線

作業足場約3m×3m、下の足場との高低差約2mを制作基準。巻き胴直径0.6m、操作柄0.35m、手すり高さ1m。足場への階段幅0.9m。

### 主ショット

上の足場の入口、高さ0.7mから巻き胴越しに下の足場へ斜めに向ける魚眼。手前の柄、中景の綱、奥か下方の部品を置いた床。

### 寄りと整合の確認

操作の寄りでは柄・軸・巻き胴・綱を一つの設備としてつなぐ。下の足場を孤立させず、同じ橋の梁と支えに接続する。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
