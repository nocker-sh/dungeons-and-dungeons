# 道具屋

## 設定・制作メモ

片眼鏡の旦那が営む。購入・売却・会話・ガラクタから道具を得る鑑定。

## 暮らし（制作案）

爆弾、煙玉、ロープ、松明など、谷の仕事で消えていく道具を売る。ガラクタの鑑定もする。鍵の束が壁一面に掛かっているが、錆びた鉄橋の下の扉に合う鍵の話は会話で少しずつ触れるだけにする。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

持ち帰ったガラクタと、明日の仕事の道具が行き交う小さな店。

### 広さと使う人数

売場内寸4.5m×6m、天井2.8m程度。帳場約1m、棚奥行0.4m、客側の通路1.2m。

### 配置と接続

右に帳場、左に荷袋とロープ、奥の壁に鍵の束。奥へ通る床を取る。高い棚のための脚立は壁へ収納し、動線に立てっぱなしにしない。

### 主ショット

入口左、高さ1.2mからロープ棚の縁越しに帳場へ向ける魚眼。

手前は吊ったロープの一部、中景は鑑定と買い物の台、奥は鍵の壁。ロープの輪を大きく写しても荷袋より何倍も巨大な現物にしない。

### 用事と寄りのショット

帳場で広げたガラクタと、奥にある鍵を一緒に見る中景。鍵の寄りで特定の扉との対応を勝手に示さない。

### 矛盾を防ぐ確認

荷袋約0.5m、ロープの巻き約0.35m、樽約0.7m。棚・帳場・奥の扉は同じ床面を使う。

## 画像から確認した造形

黄灯り、縄の輪と桶、茶木棚と緑敷物、道具袋。

## 縦版のショット計画（制作案）

スマホの縦長の画面（`useWide` が偽）では `world.json` の `image`、横長の画面では `wideImage` を使う。縦版は横版 `tools-fisheye-comic-v3.webp` と同じ場所・家具の左右関係・色相を保ち、縦の枠で構図を組み直す（中央の切り抜きにしない）。

- ショット: 小さな赤い敷物越しに帳場を斜めに見上げる。中景の中央に赤い旗の帳場と腰掛け、奥の棚は品物の小さな列を描かず大きな塊にする。巻いた縄は左端、樽は右下の隅だけに置く。
- 共通: 主役を中央70%の幅に収め、手前の枠の物は左右の端と下の隅だけに置く。下の中央（横20〜80%、縦55〜88%）は人物の上半身を重ねるため、平らで物の少ない床にする。
- 描き込み: 農場の縦版 `quick-farm-v1-fisheye-comic-v3` の密度を上限にし、横版より減らす。小物・木目・目地・板や瓦の一枚ずつ・細かな装飾を省き、大きな形と平らな色面で組む。網点は影の一部だけ。
- 明るさと線: 横版と同じ時間帯・明るさ・色相を保ち、明るさの補正をしない。大きな面すべてに太い黒の輪郭を引き、影には境界の分かる漫画の網点をはっきり使う。ブラシ跡・グラデーション・霞は描かない。

## 建物と生活区画

この背景で見える売場・作業場は room:tools-work、寝室と生活設備を含む配置は map:tools を参照。店の仕事場の制作寸法を保ち、寝台・台所・洗身・便所は奥の独立した区画へつなぐ。画像一枚に全機能が見える必要はないが、住まいとしての経路は資料間で成立させる。
