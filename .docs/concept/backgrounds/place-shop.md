# 商店街

## 設定・制作メモ

武器と防具、鍛冶屋、道具屋、薬屋が並ぶ。鑑定は武器と防具の店と道具屋で行う。

## 暮らし（制作案）

夕方、谷から上がった冒険者が換金袋を持って店を回る。店どうしは素材と品を融通し合っている。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

2棟の間の曲がる商店街。谷帰りの人が必要な店を回れる日常の道。

### 広さと使う人数

通り幅4m、店の外形は幅6〜8m×奥行8〜10m、階高約3mを制作目安にする。ギルドと宿より小さい。

### 配置と接続

武器店と鍛冶屋は隣同士。道具屋と薬屋もこの通りに置くが、左右の厳密な番地はまだ決めない。入口の段差と商品台は道を狭めすぎない。

### 主ショット

曲がり角の直前、高さ0.8mから通りを斜めに見上げる。魚眼で両側の庇が覆いかぶさる。

手前は軒先の樽と庇、中景は行ける店の入口、奥は角の向こうへ消える道。巨大な瓶を画面の縁に貼って迫力を作らない。

### 用事と寄りのショット

店の戸口越しに同じ通りを振り返る中景。別店舗の寄りでも通りの向きと灯りを保持する。

### 矛盾を防ぐ確認

石畳、建物の階高、窓の灯りを街から継続。通りを巨大な都市峡谷にしない。看板は文字を画像に焼き込まない。

## 画像から確認した造形

赤紫の光の木組み商店街、斜め石畳と連なる店。現行と青空の街通り案を区別。

## 縦版のショット計画（制作案）

スマホの縦長の画面（`useWide` が偽）では `world.json` の `image`、横長の画面では `wideImage` を使う。縦版は横版 `shop-fisheye-comic-v3.webp` と同じ場所・家具の左右関係・色相を保ち、縦の枠で構図を組み直す（中央の切り抜きにしない）。

- ショット: 石畳の低い位置から、奥へ曲がっていく通りを画面中央で見上げる。左右に木骨の店先と窓灯り・日除けを縦に立て、絵文字の看板（剣・乳鉢・薬瓶）だけを吊るす。樽は左下、品物の箱は右下の隅。空は上端に平らな藍色の面と三日月。石畳は一枚ずつ描かず大きな面にする。
- 共通: 主役を中央70%の幅に収め、手前の枠の物は左右の端と下の隅だけに置く。下の中央（横20〜80%、縦55〜88%）は人物の上半身を重ねるため、平らで物の少ない床にする。
- 描き込み: 農場の縦版 `quick-farm-v1-fisheye-comic-v3` の密度を上限にし、横版より減らす。小物・木目・目地・板や瓦の一枚ずつ・細かな装飾を省き、大きな形と平らな色面で組む。網点は影の一部だけ。
- 明るさと線: 横版と同じ時間帯・明るさ・色相を保ち、明るさの補正をしない。大きな面すべてに太い黒の輪郭を引き、影には境界の分かる漫画の網点をはっきり使う。ブラシ跡・グラデーション・霞は描かない。

## 市場の配置（制作案・2026-10-12）

- 街の大通りの右の脇道から、アーチを抜けた先の小さな夜の市場。中央に屋台の日よけが少し並び、周りに4軒の店先がある。- 店の並び（画面の左から）：武器と防具（左手前・剣と盾の看板）、鍛冶屋（その隣・槌と金床の看板、戸口に炉の火）、道具屋（右奥・鍵と縄の看板）、薬屋（右手前・瓶と葉の看板）。武器店と鍛冶屋は隣同士という前の制作案を保つ。看板は文字なしの記号。前の `shop-fisheye-comic-v3` と縦版は残す。- 各店の吹き出しの先端は `world.json` の `entrances`（縦長 `narrow`・横長 `wide`、画像の左上0・右下1）。縦版の両端の店は、スマホ縦の表示範囲の端にかかる。
