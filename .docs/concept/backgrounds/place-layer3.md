# 毒沼の温室

## 設定・制作メモ

3層。割れたガラス屋根の温室が毒沼の上に広がる。誰が建てたかは決めていない。

## 今の雰囲気（制作案）

湿って暑く、甘い匂いと腐った水の匂いが混ざる。マスクと手袋が欠かせず、帰りの籠では誰もが咳をしている。種床や薬草の乾燥室が残り、冒険者は休むついでに種を煎じる。

## 切なさの種（制作案）

乾燥室には、札を付けた薬草の束が吊るされたまま残っている。札の字は丁寧で、どれも同じ人の手。最後の束だけ札が書きかけになっている。

## 持ち帰る物と、それで守られているもの（制作案）

毒花の種や花弁、胞子の袋は薬屋のモルナが干して毒消しや咳止めにする。温室帰りの冒険者の咳も、その咳止めで止まる。蔦は織り手に回り、毒に強い装束になる。

## 背景の制作メモ

探索中の3層専用背景。割れたガラス屋根と濁った緑の水、角張った葉を大きな色面で描き、鉄橋の錆色と場所を見分けられるようにする。中央の通路はスマホの縦表示でも残す。植え込みを回る左の通路は分かれ道の存在を視覚的に示す構図上の要素で、道のりの実際の接続はゲームデータを正とする。現在の画像には線路と奥の駅が描き込まれており、線路をやめた世界設定に合わせて描き直しが要る。背景へ文字や人物を焼き込まない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

毒沼の上に残る割れた温室。人が使った通路と、今も育つ植物を見せる。

### 広さと使う人数

温室内の描く区画は幅8m×奥行12m・棟高6m程度。通路幅1.5m、種床高さ0.75m、ガラス一区画約1mを制作基準にする。

### 配置と接続

通路は水より高い位置で植え込みを回り、種床と乾燥室へ分岐する。柱・屋根・床は支え合い、浮いた作業台を毒水へ置かない。建設者は決めない。

### 主ショット

通路の曲がり角、高さ0.8mから葉の下を抜き、割れた屋根へ斜めに仰ぐ魚眼。

手前は葉と通路の縁、中景は種床と歩く道、奥はガラスの屋根。濁った緑の水は広い面で、葉や金属とは材質を分ける。

### 用事と寄りのショット

種床を見る中景は通路側から。乾燥室の戸口を振り返るショットで、湿った外と乾かす内側の違いを作る。

### 矛盾を防ぐ確認

線路や駅を残さない。種床と乳鉢は人の作業高さ。毒の花が大きくても、全ての葉で人物の床を隠さない。

## 画像から確認した造形

緑のガラス温室と梁、中央の線路、左右の植物床と湿った水面。

## 戦闘用背景のショット計画（制作案）

探索・場所の背景とは別に、戦闘の後ろに置く絵。通常の背景（低い位置から仰ぐ強い魚眼）とは別のショット。高さ約2.5m・約25°見下ろしの弱い魚眼で、奥の壁で閉じる。画面の下から上4割近くまでを平らで何も置かない床にし、敵の立つ中央を空ける。手前の縁取りは左右端の小さな形だけにする。

| 項目   | 内容                                                                                   |
| ------ | -------------------------------------------------------------------------------------- |
| 戦う床 | 温室の中の水より高い石敷きの台（幅約8m）。灰色の石敷き                                 |
| 奥     | 低い植え込み（0.75m）と温室の下のガラス壁                                              |
| 置く物 | ガラスの向こうは空でなく洞窟の緑灰の岩壁。左右の端だけに濁った緑の水と大きな角張った葉 |
| 上端   | 割れたガラス屋根の鉄枠の上は岩の天井で、空・月を見せない                               |

戦闘中は背景の層が約1.18倍に寄って少し傾き、明るさ35%・彩度70%に落ちる（`director.ts` の突入演出）。縦は上部に行動順と敵の札、下部に隊列と指示、横は右上に敵の札・右下に発動が重なるため、主張のある物は奥の壁の左右に小さく置く。

## 探索の背景の候補とショット計画（制作案）

ユーザー指示「同じ画像だと飽きる」「宝箱を見つけたり休憩する場所もほしい」に合わせ、層の背景を地点ごとに替える。地形・色・素材はこの層で揃え、地点だけを変える。どれも下へ潜る向きで描く。寸法と配置は上の空間設計に従う制作案で、確定したゲーム仕様ではない。

`world.json` の層の場所の `scenes` に縦（`image`）・横（`wideImage`）の組で登録する。エンジンは出来事が宝箱なら `treasure`、休む・手当ての選択肢がある発見なら `rest`、それ以外（戦闘・罠・ほかの発見）なら `path` の候補を、同じ種類の地点を通るたびに順に回して選ぶ。
