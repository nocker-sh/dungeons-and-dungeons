# 墓守の灯

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

骨の間の道にある石の腰掛けと灯り。人が立ち止まって油を足せる場所。

### 寸法と動線

足場約3m×3m。石の座面0.45m、灯り0.25mを高さ1.8m程度の支えへ掛ける。供物と骨片の小箱は0.4m程度。道幅2mを塞がない。

### 主ショット

道側の低い高さ0.6mから灯りの支えと骨を仰ぐ魚眼。手前の腰掛け、中景の人用の灯り、奥の大きい骨。

### 寄りと整合の確認

灯りの寄りにも吊る金具と支えを残す。巨人の墓場だからと人用のベンチや灯りを巨大化しない。油を足した人物は描き足さない。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
