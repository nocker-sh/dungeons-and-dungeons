# 結晶の洞窟

## 設定・制作メモ

0層。結晶を拾える洞窟で、籠を降りてすぐの浅い仕事場。

## 今の雰囲気（制作案）

朝一の籠には新人と古株が混ざって乗り、踊り場で手袋をはめ直してから散っていく。壁の結晶が灯りを返すので、奥まで薄明るい。スタンプダックやジェムホッグがうろつくが、気をつけていれば日帰りで稼げる層として扱う。

## 切なさの種（制作案）

採り尽くされた壁には、昔の採掘者がつるはしで刻んだ名前と日付が残っている。新しい名前の横には、同じ字で何度も刻み直された古い名前がある。誰のものかは書かない。

## 持ち帰る物と、それで守られているもの（制作案）

洞窟の結晶は薬屋のモルナが高く買い取り、砕いて薬に混ぜる。新人の最初の稼ぎはたいていこの結晶で、そのまま宿の部屋代と仕送りに消える。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

籠を降りてすぐの浅い仕事場。奥へ歩ける道と、拾える結晶を見せる。

### 広さと使う人数

主な洞内空間は幅8m・高さ6m程度、道は幅2m。結晶は0.2〜0.7mを中心に、少数の大きいものも1m程度を制作基準にする。

### 配置と接続

踊り場から人用の道が岩を回り込む。つるはしや荷箱は道の脇。洞窟の空間と谷の落差を別に考え、すべてを深い縦穴へ置き換えない。

### 主ショット

踊り場を出た岩陰、高さ0.7mから近い結晶越しに道の先を見る魚眼。

手前は岩と結晶の輪郭、中景は歩ける床と作業跡、奥は曲がる洞。青緑は結晶に限定し、岩を同じ発光色で埋めない。

### 用事と寄りのショット

仕事の中景では通常寸法の荷箱と採集場所を並べる。結晶の寄りにも持ち帰れる欠片の大きさを残す。

### 矛盾を防ぐ確認

籠の大きさは地上と同じ。道の途中に別の巨大昇降機を増やさない。洞内の道から各イベントへ歩いて入れる。

## 画像から確認した造形

青緑に光る結晶の洞窟、暗い多面体の岩、吊り構造と青い灯り。

## 戦闘用背景のショット計画（制作案）

探索・場所の背景とは別に、戦闘の後ろに置く絵。通常の背景（低い位置から仰ぐ強い魚眼）とは別のショット。高さ約2.5m・約25°見下ろしの弱い魚眼で、奥の壁で閉じる。画面の下から上4割近くまでを平らで何も置かない床にし、敵の立つ中央を空ける。手前の縁取りは左右端の小さな形だけにする。

| 項目   | 内容                                                                                        |
| ------ | ------------------------------------------------------------------------------------------- |
| 戦う床 | 結晶の洞窟の広い洞内（幅約8m×奥行約6m）。灰ベージュの岩の床                                 |
| 奥     | 面の大きな灰青の岩壁                                                                        |
| 置く物 | 壁の左右の根元に青緑の結晶（0.2〜0.7m、一つだけ約1m）と荷箱・小さな吊り灯り。岩は光らせない |
| 上端   | 上は岩の天井で閉じ、空を見せない                                                            |

戦闘中は背景の層が約1.18倍に寄って少し傾き、明るさ35%・彩度70%に落ちる（`director.ts` の突入演出）。縦は上部に行動順と敵の札、下部に隊列と指示、横は右上に敵の札・右下に発動が重なるため、主張のある物は奥の壁の左右に小さく置く。

## 探索の背景の候補とショット計画（制作案）

ユーザー指示「同じ画像だと飽きる」「宝箱を見つけたり休憩する場所もほしい」に合わせ、層の背景を地点ごとに替える。地形・色・素材はこの層で揃え、地点だけを変える。どれも下へ潜る向きで描く。寸法と配置は上の空間設計に従う制作案で、確定したゲーム仕様ではない。

`world.json` の層の場所の `scenes` に縦（`image`）・横（`wideImage`）の組で登録する。エンジンは出来事が宝箱なら `treasure`、休む・手当ての選択肢がある発見なら `rest`、それ以外（戦闘・罠・ほかの発見）なら `path` の候補を、同じ種類の地点を通るたびに順に回して選ぶ。

一度生成した版はユーザーの背景への差し戻し（明るすぎる、輪郭と漫画のトーンが少ない）を受け、構図を保ったまま地下の暗さ・すべての大きな面の太い輪郭・影の網点を増やして描き直した（ファイル名の `-ink`）。後処理の明るさ補正は使っていない。描き直し前の版も消さずに残す。
