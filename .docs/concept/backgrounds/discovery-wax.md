# 封蝋の巡礼所

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

石の道の脇で封蝋を納める場所。祭壇と遺物の箱は人が使える距離で並ぶ。

### 寸法と動線

脇の空間約3m×4m。祭壇幅1.2m・高さ0.9m、箱幅0.8m×奥行0.5m・高さ0.6m、封蝋0.05〜0.15m。前の幅0.9mの足場をつなぐ。

### 主ショット

入口の柱の影、高さ0.6mから祭壇と箱へ斜めに向ける魚眼。手前の柱、中景の使う天板、奥の戻る道と少ない灯り。

### 寄りと整合の確認

封印の寄りでも箱と蓋の接合を保つ。建設者、宗派、封印の由来は補わない。主層の巨大な柱に合わせて箱を巨大化しない。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
