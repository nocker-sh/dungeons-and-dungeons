# 橋脚の整備小屋

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

主橋から保守の足場で降りた、橋脚に沿う小さな仕事と休憩の場所。

### 寸法と動線

小屋は内寸3m×4m・高さ2.4m。作業台幅1.2m・高さ0.75m、椅子座面0.45m、歯車直径0.15〜0.4m。入口は高さ2.1m、足場は幅0.9m。

### 主ショット

保守足場の入口、高さ0.7mから戸口越しに作業台と頭上の橋桁を見上げる魚眼。手前の手すり、中景の小屋、奥の橋脚。

### 寄りと整合の確認

歯車の寄りは作業台の同じ位置。整備小屋を玩具サイズにしない。主橋の床と小屋の床の高さの違いは階段で接続する。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
