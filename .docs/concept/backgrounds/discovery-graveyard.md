# 墓守の供物台

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

骨を掘る道の脇に残る供物台。大きな骨の景色の中で、人が使う低い場所。

### 寸法と動線

台は幅1.2m×奥行0.6m・高さ0.75m。供物皿0.25m、骨片0.1〜0.3m、墓碑高さ0.8m。前に立つ幅0.9mを残す。

### 主ショット

道側、高さ0.5mから皿の縁と奥の墓碑を仰ぐ魚眼。手前の台の脚、中景の皿、奥の掘り跡と骨。

### 寄りと整合の確認

供物の寄りは同じ皿の上。巨人の頭骨と人用の皿の寸法を混同しない。供物を置いた人を確定しない。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
