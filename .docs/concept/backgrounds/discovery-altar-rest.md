# 血の祭壇と休憩所

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

血を捧げる場所と、荷を下ろして休む場所が同じ道の脇にある。宗教や来歴を新しく補わない。

### 寸法と動線

約4m×3mの脇の足場。祭壇は幅1.2m・高さ0.9m、器直径0.3m、長椅子は長さ1.8m・座面0.45m。4人は腰掛けと周囲の地面を使う制作案で、椅子の定員をゲーム制約にしない。

### 主ショット

長椅子の座った高さ0.5mから、荷越しに祭壇を見る魚眼。手前の荷、中景の腰掛けと祭壇、奥の帰る道。祭壇の方だけ床を高くしない。

### 寄りと整合の確認

捧げる行為の中景は天板の手前側。血の量や惨状を勝手に強めず、既存の機能が伝わる器と使う場所を描く。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
