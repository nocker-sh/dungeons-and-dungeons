# 谷縁の道

街の門から街はずれの乗り場へ向かう、大渓谷の縁に沿った道。短い依頼戦闘を行う場所で、探索の移動を挟まず一戦に入る。道の来歴・管理者は未設定。

## 暮らし（制作案）

朝は昇降機へ向かう冒険者、夕方は換金袋を下げて戻る冒険者が歩く。籠を待つ人が手すりぎわで立ち止まる。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。寸法と配置は背景制作の検討用で、確定した建築・ゲーム仕様ではない。

### この場所で見せること

門の外、谷の上端を通る石畳の道。戦う床は手すりぎわの待避場。

### 広さと使う人数

道幅約4m、待避場は約8m×6m。谷側の低い石の手すり約1m、灯りの柱約2.2m。

### 配置と接続

門→谷縁の道→街はずれの乗り場の順。道の先に昇降機の木組みと滑車を小さく置く。谷側に橋・線路・駅を描かない。

### 主ショット

手すり近く、高さ0.8mから道の先を見上げ、右へ谷が開ける魚眼。右手前に石の手すりと綱、左手前に岩肌と灯りの柱。

手前は手すり・岩肌、中景は待避場の石畳、奥は乗り場の木組みと谷の向こうの崖。

### 矛盾を防ぐ確認

乗り場の籠は人の寸法のまま遠くに小さく描く。各層の踊り場と混同しない。床の石畳を街と同じ材質でつなぐ。

## 戦闘用背景のショット計画（制作案）

探索・場所の背景とは別に、戦闘の後ろに置く絵。通常の背景（低い位置から仰ぐ強い魚眼）とは別のショット。高さ約2.5m・約25°見下ろしの弱い魚眼で、奥の壁で閉じる。画面の下から上4割近くまでを平らで何も置かない床にし、敵の立つ中央を空ける。手前の縁取りは左右端の小さな形だけにする。

| 項目   | 内容                                                                                                   |
| ------ | ------------------------------------------------------------------------------------------------------ |
| 戦う床 | 谷縁の石畳の道の待避場（約8m×6m）。灰青の石畳の色面                                                    |
| 奥     | 右奥の低い石の手すり（1m）と綱、その向こうの対岸の崖                                                   |
| 置く物 | 左奥に岩肌と灯りの柱（2.2m）、右の遠くに乗り場の木組みと滑車を人の寸法で小さく。橋・線路・駅は描かない |
| 上端   | 上端だけに紺の夜空                                                                                     |

戦闘中は背景の層が約1.18倍に寄って少し傾き、明るさ35%・彩度70%に落ちる（`director.ts` の突入演出）。縦は上部に行動順と敵の札、下部に隊列と指示、横は右上に敵の札・右下に発動が重なるため、主張のある物は奥の壁の左右に小さく置く。
