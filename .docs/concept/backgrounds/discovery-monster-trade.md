# 魔物の交換屋

イベント用の独立した場所IDは実行データにないため、実行用参照は未設定。用途・選択肢・報酬は実行用データを正とし、ここには複製しない。

## 空間とショットの設計（制作案）

[[concept/world/world-space-camera|共通設計]]に沿う。以下は画像制作の検討用で、確定した寸法・施設機能ではない。

### 場所と使い方

道の脇に寄せた荷車で品を交換する場所。商人の正体や新しい来歴は決めない。

### 寸法と動線

荷車は長さ2m×幅1.1m、車輪直径0.6m、荷台約0.75m。天秤高さ0.4m、本長辺0.3m。道幅2mとは別に客が立つ脇の余白を取る。

### 主ショット

客が立つ側、高さ1mから荷台の縁越しに天秤を見る魚眼。手前の車輪と縁、中景の取引台、奥のその層の道。

### 寄りと整合の確認

取引の中景で品と本が台に乗ることを見せる。既存の商人の姿を勝手に変えず、背景へ新しい人物を増やさない。車輪と荷台の構造をつなぐ。

### 挿絵と全景の使い分け

小さな挿絵では主役と寸法の基準になる物を絞り、全景を制作する時は道へ戻る床と周囲を描く。同じ物の寸法・配置を引き継ぎ、両方を別の場所にしない。
