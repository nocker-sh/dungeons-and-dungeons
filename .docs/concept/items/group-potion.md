# 全体回復薬

## 画像から確認した造形

桃白の噴霧瓶。通常ポーションの栓瓶と区別。

## 暮らしの中での取り扱い

霧を出す口を泥から守り、薬袋で押し潰さない。客室での手入れでは飲食物から離し、噴霧を遊びに使わない。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

桃色とクリーム色の手動噴霧瓶。金属ノズルは一本とし、手で押すレバーと瓶につながるポンプの構造を見せる。底を広く、携行帯を革にする。電動機器にしない。
