# ネルの住まいの洗い場

## この部屋の役割と配置

3.1×2mの洗い場。桶と手洗い、乾いた着替えの台を分ける。換気は東の外壁へ逃がし、寝室へ湿りを戻さない。

## 日々の使い方

帰宅後は手と体を洗い、肩掛け袋から紙と画鋲の缶を外してから衣服を扱う。依頼書を濡れた台へ置かず、乾いた着替えを用意する。熱い湯の運搬を子供だけの役目にせず、使い終わった床の水を拭く。

空間は今回の制作設定。[[concept/maps/nell-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
