# 普通客室・通り側

四人が装備をほどき、翌日の仕事へ戻る相部屋。

## 家具と身体の収まり

2.1×0.9mの寝台を左右に二台ずつ。中央通路は0.9m以上。奥の窓下に0.8×0.5mの机。各寝台に荷物箱と手元灯を付ける。

## 一日の使い方

靴と濡れた上着は階下で処理する。早立ちの荷造りは寝台脇で済ませ、他人の寝台を通路にしない。

## 生活を支える経路

食事と飲用水は炊事室、洗身は洗い場、排泄は同じ階の便所へつなぐ。用途が違う水と容器を混ぜない。各接続先はメタデータの資料IDで管理する。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。
