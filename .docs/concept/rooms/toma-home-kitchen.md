# トーマの住まいの台所

## この部屋の役割と配置

3.1×3mの台所。東壁側に炉と排気口、隣に食材と器の作業台を置き、西の戸から幅1.2mの立つ範囲を空ける。

## 日々の使い方

針と幌布を食品の台から分け、手を洗ってから食事を作る。布を乾かすために炉へ近付けず、飲用水と布の洗い水を兼用しない。火を扱った後は残り火を確かめ、食事を居間で取る。

空間は今回の制作設定。[[concept/maps/toma-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
