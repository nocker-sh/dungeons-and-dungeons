# ギルドの一階便所

食事と寝床から排泄を分離する。

## 家具と身体の収まり

二つの個室、手洗い、外側から交換できる密閉容器。換気は外壁へ独立して抜く。

## 一日の使い方

回収容器は裏庭へ直接出し、食材の搬入時刻と分ける。内容物を雨水溝や飲用水へ流さない。

## 生活を支える経路

食事と飲用水は炊事室、洗身は洗い場、排泄は同じ階の便所へつなぐ。用途が違う水と容器を混ぜない。各接続先はメタデータの資料IDで管理する。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。
