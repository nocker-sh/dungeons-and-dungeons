# ハンナの住まいの便所

## この部屋の役割と配置

3.1×2mの便所。密閉回収式の便器と手洗いを置き、通路側の個別の戸から利用する。換気は外壁へ抜く。

## 日々の使い方

寝室や台所を通り抜けず、通路の戸から利用する。子供にも手洗いの水が届く高さとし、夜は固定灯で足元を見られるようにする。回収をハンナ一人の日課へ固定せず、食材の搬入と時刻を分けて裏口から行う。

空間は今回の制作設定。[[concept/maps/hanna-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
