# ネルの住まいの寝室

## この部屋の役割と配置

3.1×5.6mの寝室。0.9×2.1mの寝台を左右二列に四つまで配置する。西の戸は列と列の間へ置き、戸から中央の幅1.1mの通り道へ入る。寝台間の仕切りは通路と換気を塞がない。

## 日々の使い方

ネル本人と弟が使える別の寝台を用意し、肩掛け袋や画鋲を寝具へ置かない。最大四つの寝台を置ける部屋で、残りの空床から他の家族を創作しない。弟の年齢は寝台寸法で確定せず、私物の収納を分け、犬耳を狭い壁際へ押し込まず起き上がれるようにする。

空間は今回の制作設定。[[concept/maps/nell-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
