# ゼップの住まいの寝室

## この部屋の役割と配置

3.1×4mの寝室。0.9×2.1mの寝台一つを西の戸から離れた壁側へ置き、足元から戸へ抜ける範囲を空ける。

## 日々の使い方

膝に負担を掛けず起き上がれる高さの寝台を一つ、戸から離れた壁側へ置く。足元の衣服を片付け、夜は固定灯を使って段差のない通路へ出る。手元のランタンを点けたまま寝具の横へ置かず、火を消して休む。

空間は今回の制作設定。[[concept/maps/zepp-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
