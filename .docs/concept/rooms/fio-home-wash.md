# フィオの住まいの洗い場

## この部屋の役割と配置

3.1×2mの洗い場。桶と手洗い、乾いた着替えの台を分ける。換気は東の外壁へ逃がし、寝室へ湿りを戻さない。

## 日々の使い方

外で使った布マスクと着替えを分けて洗い、乾いてから収納へ戻す。剪定ばさみの手入れと本人の洗身は別の器で行い、刃を桶に沈めたままにしない。採取物を洗う水を飲用や体を洗う水へ戻さない。

空間は今回の制作設定。[[concept/maps/fio-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
