# ヌイとトリスの寝室

糸と石をそれぞれの持ち物として保ち、休息の邪魔にしない。

## 家具と身体の収まり

二つの寝台、各自の低い棚、糸を乾いたまま保管する箱。床に糸を渡したり石を転がしたりしない。

## 一日の使い方

ヌイは糸巻きを収め、トリスは三つの石を自分の棚へ戻す。持ち物の由来の未判明部分は埋めない。

## 生活を支える経路

食事と飲用水は地下の食事準備室で受け取り、食器はそこへ返す。洗身と便所は地下の別室を使い、飲用容器を洗身・汚物の容器と共用しない。西側の寝室からは共用室南側の通路、東の前室、サービス通路の順に進み、契約の円を横切らない。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。

## 通路と扉

内寸4.4×3.2m。西の戸から幅1.4mの共用通路へ出る。東側の生活設備へは共用室の空けた通路を通り、ロクスたちやヨルの寝室は通らない。
