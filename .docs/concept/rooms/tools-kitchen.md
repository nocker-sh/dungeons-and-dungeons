# 道具屋の台所

食材と飲用水を覆って保管し、調理する。店で使う薬・油・粉・金属片の器を持ち込まない。食事の卓は作業台と分け、使用後に器を洗って乾かす。

## 家具と出入り

西壁の戸口は北端から0.8mの位置に幅0.9m。西側に幅1.2mの経路を残し、扉と椅子の引く範囲を重ねない。北壁沿いの奥行き0.6mの台に流しと下ごしらえの面を取り、北東隅の生活用の竈は東の外壁へ排煙する。南側に幅0.8m・奥行き0.6mの一人用の食卓を置き、椅子は北側へ引く。東壁の食器棚は竈の直下と窓を避け、奥行き0.4mまでとする。客を待たせる席や商品の仮置場には数えない。

## 一日の使い方

売物の燃料瓶や使いかけの油差しを食材棚へ入れない。閉店時は売場の灯りと燃料の口を確かめてから台所へ移り、手を洗う。食材と食器は自分用の棚へ収め、食事の途中に商品を並べ直す台として使わない。

## 生活のつながり

ウォルターの仕事と休息を、同じ台や寝床へ押し込めない。食事と飲用水は台所、身体を洗うのは洗い場、排泄は便所、睡眠は寝室で扱う。それぞれの扉は生活用通路へ開き、裏口から清潔な荷の搬入と回収を時刻を分けて行う。

## 図面と実装

仕事場の幅と奥行は既存の画面設計を保ち、私生活の区画を奥へつなぐ。見える売場を二階建てへ描き変えない。建物配置は map:tools を参照。追加した部屋は制作設定であり、新しい店員・ゲーム内の住居購入・回復効果を実装した意味ではない。既存の家族や過去の未判明部分は確定しない。
