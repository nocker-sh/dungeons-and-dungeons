# イルマの住まいの台所

## この部屋の役割と配置

3.1×3mの台所。東壁側に炉と排気口、隣に食材と器の作業台を置き、西の戸から幅1.2mの立つ範囲を空ける。

## 日々の使い方

帳面と鉛筆を調理台へ持ち込まず、手を洗ってからパンや食材を扱う。湯気を帳面の乾燥手段にせず、食事の器だけを居間へ運ぶ。飲用水の容器を筆記具洗いに転用せず、食後の器を戻して清潔にする。

空間は今回の制作設定。[[concept/maps/irma-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
