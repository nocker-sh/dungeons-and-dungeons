# ボリスの住まいの寝室

## この部屋の役割と配置

3.1×4mの寝室。0.9×2.1mの寝台一つを西の戸から離れた壁側へ置き、足元から戸へ抜ける範囲を空ける。

## 日々の使い方

寝台一つを仕事の荷と分け、息子の擦り切れたブーツを寝具へ載せない。錐と糸は蓋の閉じる道具入れへ戻し、夜に戸へ歩く足元を空ける。本人用の寝台の数を、息子が家を出たことや現在の同居の根拠にしない。

空間は今回の制作設定。[[concept/maps/boris-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
