# ピムの住まいの寝室

## この部屋の役割と配置

3.1×5.6mの寝室。0.9×2.1mの寝台を左右二列に四つまで配置する。西の戸は列と列の間へ置き、戸から中央の幅1.1mの通り道へ入る。寝台間の仕切りは通路と換気を塞がない。

## 日々の使い方

ピム本人の寝台とマフラーを置く乾いた収納を用意する。寝る時は長いマフラーを戸や寝台へ巻き付けずに外す。家族用の寝台は最大四つの設計とし、母以外の家族を追加したり、空床を母が戻らないことの証拠にしたりしない。

空間は今回の制作設定。[[concept/maps/pim-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
