# ネムと相棒の住まいの便所

密閉回収式の便器と手洗い。回収は裏口から行い、食材の受け取りと時刻を分ける。換気を寝室へ戻さない。

## 一日の使い方

人は通路から便所へ行き、手洗いを済ませて居間へ戻る。相棒の排泄物は別の清掃道具で回収し、食器を洗う水や台所の容器を転用しない。密閉した回収物は裏口から出す。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:nem-home を参照。
