# ピムの住まいの居間

## この部屋の役割と配置

4.5×4.2mの居間。食卓を入口と奥の通路の直線上から外し、壁際に本人の荷を置く範囲を設ける。

## 日々の使い方

家の窓辺に小石を並べる浅い受け皿を置き、窓を開け閉めする範囲から外す。石は食事の器へ入れず、持ち帰ったら手を洗ってから食べる。窓辺に置く石の数を、待っている年数や母の生死の証拠に変えない。

空間は今回の制作設定。[[concept/maps/pim-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
