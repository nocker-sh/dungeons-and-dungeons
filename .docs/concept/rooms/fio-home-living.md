# フィオの住まいの居間

## この部屋の役割と配置

4.5×4.2mの居間。食卓を入口と奥の通路の直線上から外し、壁際に本人の荷を置く範囲を設ける。

## 日々の使い方

採取物の整理を終えたら食事の卓を空け、種袋は専用の収納へ戻す。剪定ばさみは閉じて覆いを掛け、卓の縁から刃が出ない位置へ置く。師匠の株の所在を、窓辺の新しい鉢として勝手に追加しない。

空間は今回の制作設定。[[concept/maps/fio-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
