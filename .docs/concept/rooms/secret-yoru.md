# ヨルの寝室

昼の光を避けながら、閉め切らずに眠れる私室。

## 家具と身体の収まり

寝台と衣服棚、飲み物を置く小卓。外気口には光を折り返す覆いを付け、通気そのものは止めない。

## 一日の使い方

夜間の活動後に眠る。スープの器は溜めずに返す。部屋の古さや由来を新しく決めない。

## 生活を支える経路

食事と飲用水は地下の食事準備室で受け取り、食器はそこへ返す。洗身と便所は地下の別室を使い、飲用容器を洗身・汚物の容器と共用しない。西側の寝室からは共用室南側の通路、東の前室、サービス通路の順に進み、契約の円を横切らない。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。
