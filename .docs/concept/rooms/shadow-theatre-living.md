# 六席の影絵小屋の舞台と六席

客席は二列三席の六席。舞台は奥行1.5m、右側の幅1.2mを入口から舞台脇の退避口まで空ける。紙と灯りの間を離し、子供のために空ける一席へ道具を積まない。

## 一日の使い方

興行前に客の出入りを確かめ、影絵の道具と客席の荷を出口の前から外す。終演後は客が退出してから道具を片付け、寝室へ持ち込む清潔な衣類と分ける。生活区画の扉を観客用の出入口にしない。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:shadow-theatre を参照。
