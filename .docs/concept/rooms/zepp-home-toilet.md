# ゼップの住まいの便所

## この部屋の役割と配置

3.1×2mの便所。密閉回収式の便器と手洗いを置き、通路側の個別の戸から利用する。換気は外壁へ抜く。

## 日々の使い方

通路から段差なく入り、立ち座りの際に手を添える固定した横木を壁側へ設ける。裏口からの回収物を戸の前へ積まず、夜も固定灯で足元を見られる状態にする。利用後は手洗いを済ませる。

空間は今回の制作設定。[[concept/maps/zepp-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
