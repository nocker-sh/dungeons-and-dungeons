# ロイドの住まいの便所

## この部屋の役割と配置

密閉回収式の便器と手洗いを置き、換気は東の外壁へ抜く。戸は通路から入り、居間・台所・寝室を横切らない。回収容器を置くために戸の可動範囲を狭めない。

## 日々の使い方

利用後に手を洗う。回収物は通路の裏口から外へ出し、食材の搬入と時刻を分ける。密閉容器を居間の卓や厨房へ仮置きしない。夜も通路の固定灯で足元を確認して利用する。

寸法・接続は[[concept/maps/lloyd-home|生活配置図]]へつなぐ。空間は今回の制作設定であり、宿泊料金・回復量・運行時刻や購入できる家を実行用データへ追加しない。
