# フィオの住まいの生活用通路

## この部屋の役割と配置

居間の奥から各室の西側の戸と裏口へつながる幅1.2mの生活用通路。各室の家具を動かさずに出入りできるようにする。

## 日々の使い方

採取袋を戸の前へ置かず、刃の覆いをした剪定ばさみを収納へ戻す。乾燥中の布を低く横断させず、兎耳や荷が掛からない状態にする。薬草の納品荷と食材の搬入を分け、裏口まで通れる幅を残す。

空間は今回の制作設定。[[concept/maps/fio-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
