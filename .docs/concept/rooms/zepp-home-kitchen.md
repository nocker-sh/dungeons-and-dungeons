# ゼップの住まいの台所

## この部屋の役割と配置

3.1×3mの台所。東壁側に炉と排気口、隣に食材と器の作業台を置き、西の戸から幅1.2mの立つ範囲を空ける。

## 日々の使い方

手が届く高さに飲用水と食器を置き、重い水を持ったまま屈み込む回数を減らす。油と芯は食品から離して保管し、調理の火をランタンへ移す作業と同時に行わない。食事を運んだ後は炉の火を確かめ、座って休めるよう片付ける。

空間は今回の制作設定。[[concept/maps/zepp-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
