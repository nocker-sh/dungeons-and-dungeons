# ガンツの住まいの居間

## この部屋の役割と配置

4.5×4.2mの居間。食卓を入口と奥の通路の直線上から外し、壁際に本人の荷を置く範囲を設ける。

## 日々の使い方

食事の卓は自分が座って食べるために使い、弁当箱の受け渡しを入口の外まで広げない。持ち帰った弁当箱はまず台所へ、粉の付いた採掘帽とつるはしは外側で汚れを落としてから壁の道具置きへ戻す。自分の食事を済ませてから翌日の準備を行う。

空間は今回の制作設定。[[concept/maps/gantz-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
