# ネムと相棒の住まいの台所

飲用水を覆った容器で保ち、食材・食器・汚れた器を分ける。人の食事の器を道具や動物の餌入れに転用しない。

## 一日の使い方

人の調理台と相棒の餌の取り分けを時刻と器で分ける。餌袋は蓋付きの収納へ戻し、相棒の身体が入ったまま狭い台所で火を扱わない。用意した餌は居間の決めた位置へ運ぶ。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:nem-home を参照。
