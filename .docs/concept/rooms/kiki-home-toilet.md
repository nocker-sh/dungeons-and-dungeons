# キキの住まいの便所

## この部屋の役割と配置

3.1×2mの便所。密閉回収式の便器と手洗いを置き、通路側の個別の戸から利用する。換気は外壁へ抜く。

## 日々の使い方

安全帯や縄を戸の把手に掛けず、通路から戸を開けられる幅を保つ。使用後は手を洗い、清掃道具と命綱を同じ容器へ入れない。密閉回収物は裏口から出し、食材の搬入と分ける。

空間は今回の制作設定。[[concept/maps/kiki-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
