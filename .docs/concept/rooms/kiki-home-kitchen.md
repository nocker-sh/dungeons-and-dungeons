# キキの住まいの台所

## この部屋の役割と配置

3.1×3mの台所。東壁側に炉と排気口、隣に食材と器の作業台を置き、西の戸から幅1.2mの立つ範囲を空ける。

## 日々の使い方

縄と安全帯を食品の台へ置かず、手を洗ってから食事を用意する。汚れた縄を茹でたり、飲用水の容器へ浸けたりしない。食べる物と道具の手入れを別にして、仕事から帰った本人の夕食を取れるようにする。

空間は今回の制作設定。[[concept/maps/kiki-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
