# 鍛冶屋の仕事場

右奥の炉、中央寄りの金床、左の材料と帳場。炉から金床へ幅1.2mの作業動線を取り、客は入口側で待つ。排気を外へ抜き、骨粉と煤を居室へ運ばない。

## 生活のつながり

ヒルデの仕事と休息を、同じ台や寝床へ押し込めない。食事と飲用水は台所、身体を洗うのは洗い場、排泄は便所、睡眠は寝室で扱う。それぞれの扉は生活用通路へ開き、裏口から清潔な荷の搬入と回収を時刻を分けて行う。

## 図面と実装

仕事場の幅と奥行は既存の画面設計を保ち、私生活の区画を奥へつなぐ。見える売場を二階建てへ描き変えない。建物配置は map:smithy を参照。追加した部屋は制作設定であり、新しい店員・ゲーム内の住居購入・回復効果を実装した意味ではない。既存の家族や過去の未判明部分は確定しない。
