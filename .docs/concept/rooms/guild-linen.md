# 客室階の寝具室

清潔な寝具と使用済み寝具を混ぜず、二十床を維持する。

## 家具と身体の収まり

乾いた棚を壁へ固定。返却籠は入口側、清潔な布は奥側。棚の前に一人が布を抱えて通れる余地を残す。

## 一日の使い方

回収後に手を洗ってから清潔な布へ触れる。洗濯室から乾燥済みの布だけを運び上げる。

## 生活を支える経路

食事と飲用水は炊事室、洗身は洗い場、排泄は同じ階の便所へつなぐ。用途が違う水と容器を混ぜない。各接続先はメタデータの資料IDで管理する。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。
