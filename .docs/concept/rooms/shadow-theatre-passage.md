# 六席の影絵小屋の生活用通路

興行の区画の奥から私生活の各室へつながる。幕や棒を運ぶ時も、通路の終端の裏口と各室の戸を塞がない。

## 一日の使い方

興行の区画の奥から生活設備へ分かれる。長い幕の棒と畳んだ道具は専用の収納へ戻し、裏口の戸を開けるために動かす必要がある場所には置かない。客を寝室へ通さずに片付けと洗身を済ませる。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:shadow-theatre を参照。
