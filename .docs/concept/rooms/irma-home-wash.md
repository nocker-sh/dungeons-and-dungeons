# イルマの住まいの洗い場

## この部屋の役割と配置

3.1×2mの洗い場。桶と手洗い、乾いた着替えの台を分ける。換気は東の外壁へ逃がし、寝室へ湿りを戻さない。

## 日々の使い方

墓地から戻った衣服と、紙の記録を別にする。外着の泥を扱ってから手を洗い直し、乾いた着替えへ触れる。帳面を水場の台へ開かず、眼鏡の手入れに使う清潔な布と床拭きを分ける。

空間は今回の制作設定。[[concept/maps/irma-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
