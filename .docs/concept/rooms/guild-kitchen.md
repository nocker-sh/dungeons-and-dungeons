# ギルドの炊事室

宿とホールの食事を作り、地下の住人にも温かい食事を届ける。

## 家具と身体の収まり

炉を外壁側、洗い物を汚れ側、配膳を廊下側に置く。生ものと食器の棚を分ける。

## 一日の使い方

食材は裏庭から搬入。地下への汁物は蓋付き容器でサービス通路から運ぶ。残り火を管理し、炉の前で寝ない。

## 生活を支える経路

食事と飲用水は炊事室、洗身は洗い場、排泄は同じ階の便所へつなぐ。用途が違う水と容器を混ぜない。各接続先はメタデータの資料IDで管理する。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。
