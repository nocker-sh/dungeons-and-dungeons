# ハスキーが維持する二人の貸間の洗い場

桶、手洗い、乾いた着替え台を分ける。衣類を洗った水は飲用へ戻さず、濡れた床を乾かしてから退出する。

## 一日の使い方

帰還後は外着の泥を落とし、乾いた着替えを台へ置いてから体を洗う。濡れた衣類と二人分の清潔な寝具を混ぜない。終えたら桶を伏せ、床の水を拭き取って次の利用に備える。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:husky-home を参照。
