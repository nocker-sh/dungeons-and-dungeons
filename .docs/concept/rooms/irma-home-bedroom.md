# イルマの住まいの寝室

## この部屋の役割と配置

3.1×4mの寝室。0.9×2.1mの寝台一つを西の戸から離れた壁側へ置き、足元から戸へ抜ける範囲を空ける。

## 日々の使い方

眼鏡と鉛筆を手の届く乾いた棚へ置き、帳面は寝具の外の収納へ収める。寝台で数を照合し続けるのを日課にせず、食事と洗身を終えた後に休息を取る。戸から寝台までに帳面の束を積まない。

空間は今回の制作設定。[[concept/maps/irma-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
