# フィオの住まいの台所

## この部屋の役割と配置

3.1×3mの台所。東壁側に炉と排気口、隣に食材と器の作業台を置き、西の戸から幅1.2mの立つ範囲を空ける。

## 日々の使い方

食用の材料と納品する薬草・種を別にする。素性を確かめていない採取物を食材として煮ず、選別用の器を食事の椀へ兼用しない。湯気や炉の熱で種を乾かそうとせず、本人の食事を清潔な台で作る。

空間は今回の制作設定。[[concept/maps/fio-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
