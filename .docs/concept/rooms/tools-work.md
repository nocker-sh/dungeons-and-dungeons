# 道具屋の仕事場

棚の奥行は0.4m、客の通路は1.2m。売り物を渡す台と百二十本の私物の鍵を数える卓を分け、私物の鍵を客が触れない位置へ置く。

## 生活のつながり

ウォルターの仕事と休息を、同じ台や寝床へ押し込めない。食事と飲用水は台所、身体を洗うのは洗い場、排泄は便所、睡眠は寝室で扱う。それぞれの扉は生活用通路へ開き、裏口から清潔な荷の搬入と回収を時刻を分けて行う。

## 図面と実装

仕事場の幅と奥行は既存の画面設計を保ち、私生活の区画を奥へつなぐ。見える売場を二階建てへ描き変えない。建物配置は map:tools を参照。追加した部屋は制作設定であり、新しい店員・ゲーム内の住居購入・回復効果を実装した意味ではない。既存の家族や過去の未判明部分は確定しない。
