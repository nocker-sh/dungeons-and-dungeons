# トーマの住まいの洗い場

## この部屋の役割と配置

3.1×2mの洗い場。桶と手洗い、乾いた着替えの台を分ける。換気は東の外壁へ逃がし、寝室へ湿りを戻さない。

## 日々の使い方

外の泥を衣服から落とし、本人の洗身と幌の手入れの水を分ける。布を扱う前に針を確認して収納し、洗い場の床へ落とさない。濡れた幌を寝室で乾かさず、水気を切った上で風の通る場所へ運ぶ。

空間は今回の制作設定。[[concept/maps/toma-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
