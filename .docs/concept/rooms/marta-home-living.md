# マルタの住まいの居間

## この部屋の役割と配置

4.5×4.2mの居間。食卓を入口と奥の通路の直線上から外し、壁際に本人の荷を置く範囲を設ける。

## 日々の使い方

卓の上で地図を広げる時は食器を片付け、確認を終えたら地図筒へ戻す。翌朝も食べる面を残し、組の前金の記録を私費の食事と混ぜない。長い地図筒は壁側の留め具へ収め、椅子と戸の間へ横倒しにしない。

空間は今回の制作設定。[[concept/maps/marta-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
