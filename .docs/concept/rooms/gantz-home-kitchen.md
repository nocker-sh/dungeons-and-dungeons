# ガンツの住まいの台所

## この部屋の役割と配置

3.1×3mの台所。東壁側に炉と排気口、隣に食材と器の作業台を置き、西の戸から幅1.2mの立つ範囲を空ける。

## 日々の使い方

朝は手と台を洗ってから組の弁当を詰める。人数は実際の仕事の予定に合わせ、狭い台へ全員分を無理に並べず回数を分ける。結晶の粉が付いた帽子やつるはしを食品の台へ置かず、清潔な布包みと回収した空箱を分ける。

空間は今回の制作設定。[[concept/maps/gantz-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
