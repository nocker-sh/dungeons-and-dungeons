# ダンの住まいの洗い場

## この部屋の役割と配置

3.1×2mの洗い場。桶と手洗い、乾いた着替えの台を分ける。換気は東の外壁へ逃がし、寝室へ湿りを戻さない。

## 日々の使い方

仕事後は骨の粉と泥を外着から落とし、手を洗う。背負子の紐と体を洗う桶を分け、濡れた紐は乾く場所へ移す。頬の絆創膏の扱いを新しい怪我や回復効果の設定へ広げず、乾いた着替えで寝室へ戻る。

空間は今回の制作設定。[[concept/maps/dan-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
