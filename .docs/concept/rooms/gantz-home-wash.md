# ガンツの住まいの洗い場

## この部屋の役割と配置

3.1×2mの洗い場。桶と手洗い、乾いた着替えの台を分ける。換気は東の外壁へ逃がし、寝室へ湿りを戻さない。

## 日々の使い方

採掘の粉は台所へ入る前に手と外着から落とす。外着を扱う桶と体を洗う水を分け、清潔な布包みを汚れた着替えに重ねない。朝は弁当を詰める前に手を洗い、夜は乾いた服で寝室へ戻る。

空間は今回の制作設定。[[concept/maps/gantz-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
