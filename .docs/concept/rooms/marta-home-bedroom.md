# マルタの住まいの寝室

## この部屋の役割と配置

3.1×4mの寝室。0.9×2.1mの寝台一つを西の戸から離れた壁側へ置き、足元から戸へ抜ける範囲を空ける。

## 日々の使い方

寝台脇には清潔な衣類を置き、地図筒と巻き尺は壁際の収納へ戻す。眠る前に道具を床から外し、夜の便所へ出る経路を空ける。調査を続けるために寝台を机へ替えたり、寝具の上で巻き尺を引き伸ばしたりしない。

空間は今回の制作設定。[[concept/maps/marta-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
