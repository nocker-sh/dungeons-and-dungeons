# ロイドの住まいの台所

## この部屋の役割と配置

東の外壁側へ小さな炉と排気口を置き、その隣に冷めた器を洗う台を設ける。西の通路側から炉まで1.2mの立つ幅を空ける。蓋付きの飲用水は火と洗い水から離し、食材を受け取る台を床から上げる。

## 日々の使い方

運行前に食事を用意し、外へ出る時は火が残っていないか確かめる。帰宅後は使った食器を洗って伏せる。機構の油や整備道具を調理台へ載せず、飲用水の容器を油入れにしない。
