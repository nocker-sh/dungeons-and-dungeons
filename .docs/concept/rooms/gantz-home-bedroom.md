# ガンツの住まいの寝室

## この部屋の役割と配置

3.1×4mの寝室。0.9×2.1mの寝台一つを西の戸から離れた壁側へ置き、足元から戸へ抜ける範囲を空ける。

## 日々の使い方

寝台一つと清潔な着替えの棚を置き、寝る前につるはしを戸の可動範囲から外す。枕元を採掘帽の充電や灯りの点検台にせず、帰還後は洗身してから寝具へ入る。班員が寝泊まりする寮や新しい同居人をこの寝台から設定しない。

空間は今回の制作設定。[[concept/maps/gantz-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
