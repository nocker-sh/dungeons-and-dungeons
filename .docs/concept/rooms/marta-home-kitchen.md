# マルタの住まいの台所

## この部屋の役割と配置

3.1×3mの台所。東壁側に炉と排気口、隣に食材と器の作業台を置き、西の戸から幅1.2mの立つ範囲を空ける。

## 日々の使い方

地図、鉛筆、巻き尺を調理台から外してから食事を用意する。湯気が記録へ当たらないよう食べ物だけを居間へ運び、飲用水と道具の洗浄水を分ける。包んだ食材を測量道具の入れ物へそのまま入れない。

空間は今回の制作設定。[[concept/maps/marta-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
