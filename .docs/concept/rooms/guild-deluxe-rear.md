# 上等客室・裏庭側

同じ四人泊でも荷物と身支度の余地を広く取る。

## 家具と身体の収まり

2.1×1mの寝台を左右に二台ずつ。中央に直径0.8mの卓。椅子を引いた状態でも出入口への通路を残す。収納は奥壁へ寄せる。

## 一日の使い方

湯は洗い場で使う。室内に浴槽や炉を足さず、清潔な寝具、広い荷物置き、静かな身支度を上等さの根拠にする。

## 生活を支える経路

食事と飲用水は炊事室、洗身は洗い場、排泄は同じ階の便所へつなぐ。用途が違う水と容器を混ぜない。各接続先はメタデータの資料IDで管理する。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。

中央卓と四脚の椅子は、引いた時も含め幅2mの使用範囲へ収める。寝台の中央側の縁との間を左右各0.9m以上残し、椅子を際限なく引かない。入口から窓側まで、卓の横を通って歩ける。
