# キキの住まいの寝室

## この部屋の役割と配置

3.1×4mの寝室。0.9×2.1mの寝台一つを西の戸から離れた壁側へ置き、足元から戸へ抜ける範囲を空ける。

## 日々の使い方

寝台一つの足元と戸口を空け、二本の命綱は乾いていることを確かめて別の収納へ戻す。縄を寝具の上で乾かさず、安全帯を着けたまま眠る前提にしない。就寝するのは本人で、相方の現在を寝台数で決めない。

空間は今回の制作設定。[[concept/maps/kiki-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
