# 六席の影絵小屋の洗い場

桶、手洗い、乾いた着替え台を分ける。衣類を洗った水は飲用へ戻さず、濡れた床を乾かしてから退出する。

## 一日の使い方

幕や道具の手入れで汚れた手を洗い、乾いた着替えを濡らさずに体を洗う。舞台道具の洗浄と洗身を同時に行わず、作業後は桶と床を清潔に戻す。寝間着は乾いた台で着る。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:shadow-theatre を参照。
