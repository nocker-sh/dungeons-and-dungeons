# ハスキーが維持する二人の貸間の居間

二人で使う卓を置く。二本の鍵は紐でまとめて首から下げるため、通路へ引っ掛かる金具を出さない。相棒の席を物置へ変えず、離れている間も二人分の居場所を維持する。

## 一日の使い方

帰宅後は二人用の卓の自分の側で荷を下ろす。相棒の席は空けておき、食事の器と修理道具を同じ面へ出しっぱなしにしない。首から下げる二本の鍵を椅子や壁の金具へ引っ掛けない。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:husky-home を参照。
