# ネルの住まいの便所

## この部屋の役割と配置

3.1×2mの便所。密閉回収式の便器と手洗いを置き、通路側の個別の戸から利用する。換気は外壁へ抜く。

## 日々の使い方

通路の個別の戸から入り、手洗い後に依頼書や食品へ戻る。画鋲の缶は乾いた収納へ置き、便所へ持ち込まない。夜も固定灯で足元を見られるようにし、汚れ物の回収を子供二人だけの日課として固定しない。

空間は今回の制作設定。[[concept/maps/nell-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
