# ロイドの住まいの洗い場

## この部屋の役割と配置

足元を洗う桶、手を洗う水、乾いた着替えの台を分ける。湯は台所で温めて運び、室内へ別の炉を足さない。湿りは東の開口から外へ逃がし、寝室側へ戻さない。

## 日々の使い方

帰宅したら外着を脱ぎ、汚れた手で寝具へ触れる前に洗う。洗濯物を飲用水の容器に浸けず、洗い終えた水は回収へ回す。桶を伏せ、床の水を拭いて通路へ戻る。

寸法・接続は[[concept/maps/lloyd-home|生活配置図]]へつなぐ。空間は今回の制作設定であり、宿泊料金・回復量・運行時刻や購入できる家を実行用データへ追加しない。
