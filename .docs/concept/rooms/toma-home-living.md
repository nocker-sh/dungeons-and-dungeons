# トーマの住まいの居間

## この部屋の役割と配置

4.5×4.2mの居間。食卓を入口と奥の通路の直線上から外し、壁際に本人の荷を置く範囲を設ける。

## 日々の使い方

幌を繕う時は卓から食器を片付け、針を外して数を確かめてから食事へ戻す。大きな幌は室内の床全面へ広げず、必要な部分だけを引き出す。縫い目が下手なことを、新しい怪我や妻の不在の説明へ変えない。

空間は今回の制作設定。[[concept/maps/toma-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
