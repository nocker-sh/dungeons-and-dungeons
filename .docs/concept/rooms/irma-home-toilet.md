# イルマの住まいの便所

## この部屋の役割と配置

3.1×2mの便所。密閉回収式の便器と手洗いを置き、通路側の個別の戸から利用する。換気は外壁へ抜く。

## 日々の使い方

帳面を持ち込まず、通路の個別の戸から利用する。手洗い後に記録へ戻り、回収物を紙の収納の前へ仮置きしない。裏口の回収は食材を入れる時刻と分け、厨房を通らずに行う。

空間は今回の制作設定。[[concept/maps/irma-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
