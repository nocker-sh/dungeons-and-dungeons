# ダンの住まいの寝室

## この部屋の役割と配置

3.1×4mの寝室。0.9×2.1mの寝台一つを西の戸から離れた壁側へ置き、足元から戸へ抜ける範囲を空ける。

## 日々の使い方

寝台は仕事の荷から分け、背負子の紐を寝具や戸の把手へ掛けない。清潔な着替えを棚にしまい、眠る前には足元に骨片が落ちていないか確かめる。寝室の整備を実家の屋根が修理済みになった描写として使わない。

空間は今回の制作設定。[[concept/maps/dan-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
