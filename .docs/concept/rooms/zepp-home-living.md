# ゼップの住まいの居間

## この部屋の役割と配置

4.5×4.2mの居間。食卓を入口と奥の通路の直線上から外し、壁際に本人の荷を置く範囲を設ける。

## 日々の使い方

入口の内側の壁際に腰掛けを置き、帰宅したら膝を休めてから奥へ進めるようにする。食事の卓に油の容器を載せず、長い火消し竿は壁の留め具へ収める。椅子を引いても通路へ出る経路を残す。

空間は今回の制作設定。[[concept/maps/zepp-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
