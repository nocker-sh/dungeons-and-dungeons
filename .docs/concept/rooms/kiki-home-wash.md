# キキの住まいの洗い場

## この部屋の役割と配置

3.1×2mの洗い場。桶と手洗い、乾いた着替えの台を分ける。換気は東の外壁へ逃がし、寝室へ湿りを戻さない。

## 日々の使い方

本人の洗身と縄の汚れ落としは別の器と手順で行う。縄は二本を識別できるまま水気を切り、乾燥させる場所へ運ぶ。濡れた縄を熱い炉のそばへ吊らず、乾いた寝具と着替えを濡らさない。

空間は今回の制作設定。[[concept/maps/kiki-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
