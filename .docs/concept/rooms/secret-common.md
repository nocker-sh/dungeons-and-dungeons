# 地下の秘密の共用室

ヨルと五人の悪魔が話し、契約の支度をする共用室。寝室とは分ける。

## 家具と身体の収まり

直径1.5mの円と、北壁に沿った長さ1.8m・奥行き0.45mの三人掛けベンチ。食事には個別の膝上盆を使い、使わない盆は壁の棚へ戻す。六人の在室定員を六人分の食事席とは数えず、食事は三人ずつ交代する。円の外周と扉までの経路を荷物で塞がない。常設寝台は置かない。

## 一日の使い方

全員がここに住むという設定は、同じ一室で寝ることを意味しない。食事の器は食事準備室へ戻す。

## 生活を支える経路

食事と飲用水は地下の食事準備室から東の前室を通して運び、器は食後に返す。洗身と便所は東のサービス通路から別室へ向かう。西の寝室からの通り抜けと、食事の席を重ねない。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。

## 通り抜ける床と支度する床

西と東の戸を幅1.2mとし、室内南寄りに同じ幅の経路を空ける。円の中心は室内北端から2m、直径1.5m。北壁のベンチを使っても南側の経路を塞がない。誰かが契約の支度中でも、西の寝室の住人は食事や便所へ出られる。
