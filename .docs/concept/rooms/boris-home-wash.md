# ボリスの住まいの洗い場

## この部屋の役割と配置

3.1×2mの洗い場。桶と手洗い、乾いた着替えの台を分ける。換気は東の外壁へ逃がし、寝室へ湿りを戻さない。

## 日々の使い方

作業の手を洗ってから体を洗い、靴を拭く器と本人の洗身の桶を兼用しない。革や糸を排水へ流さず拾って回収する。乾いた着替えと清潔な布を用意し、修理待ちの靴を濡れた床へ並べない。

空間は今回の制作設定。[[concept/maps/boris-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
