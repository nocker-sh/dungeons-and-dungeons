# 受付係の寝室

遅い帰還まで待つミレナに、受付から短く戻れる私室を確保する。

## 家具と身体の収まり

長さ2.1m・幅0.9mの寝台を長辺へ。反対側は浅い衣服棚と折り畳み机。寝台脇に幅0.9mの経路を残す。

## 一日の使い方

帳簿は受付の施錠棚へ戻す。部屋へ持ち込むのは私物と着替え。受付から声は届くが寝台は客の視線から隠す。

## 生活を支える経路

食事と飲用水は炊事室、洗身は洗い場、排泄は同じ階の便所へつなぐ。用途が違う水と容器を混ぜない。各接続先はメタデータの資料IDで管理する。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。
