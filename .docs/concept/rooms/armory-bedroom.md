# 武具店の住人の寝室

長さ2.1m・幅0.9mの寝台、衣服棚、小卓を置く。寝台脇の0.9m以上を歩く面とし、扉の前へ道具を積まない。仕事着を脱いでから寝具へ入る。

## 生活のつながり

オットーの仕事と休息を、同じ台や寝床へ押し込めない。食事と飲用水は台所、身体を洗うのは洗い場、排泄は便所、睡眠は寝室で扱う。それぞれの扉は生活用通路へ開き、裏口から清潔な荷の搬入と回収を時刻を分けて行う。

## 図面と実装

仕事場の幅と奥行は既存の画面設計を保ち、私生活の区画を奥へつなぐ。見える売場を二階建てへ描き変えない。建物配置は map:armory を参照。追加した部屋は制作設定であり、新しい店員・ゲーム内の住居購入・回復効果を実装した意味ではない。既存の家族や過去の未判明部分は確定しない。
