# ボリスの住まいの便所

## この部屋の役割と配置

3.1×2mの便所。密閉回収式の便器と手洗いを置き、通路側の個別の戸から利用する。換気は外壁へ抜く。

## 日々の使い方

道具入れを収納へ戻してから利用し、錐を衣服に刺したまま出入りしない。使用後に手を洗い、清掃道具と靴直しの道具を分ける。回収物は裏口から出し、預かり靴や食品の搬入へ混ぜない。

空間は今回の制作設定。[[concept/maps/boris-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
