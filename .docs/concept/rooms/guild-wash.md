# ギルドの洗い場

帰還後に体と手を洗い、寝具へ泥を持ち込まない。

## 家具と身体の収まり

二つの仕切り付き洗い場と乾いた着替え台。大浴槽は設けない。桶の湯は炊事室から蓋をして運ぶ。

## 一日の使い方

入口に使用札。濡れた床と着替え側を分け、排水の詰まりと手すりを毎日確かめる。

## 生活を支える経路

食事と飲用水は炊事室、洗身は洗い場、排泄は同じ階の便所へつなぐ。用途が違う水と容器を混ぜない。各接続先はメタデータの資料IDで管理する。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。
