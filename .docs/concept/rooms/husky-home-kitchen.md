# ハスキーが維持する二人の貸間の台所

飲用水を覆った容器で保ち、食材・食器・汚れた器を分ける。人の食事の器を道具や動物の餌入れに転用しない。

## 一日の使い方

一度に火を使うのは一人。外の食材を受け取る時は通路の回収作業と重ねず、食材を床へ置かない。食事を居間へ運んだ後は使用済みの器を洗い、飲用水の容器には専用の蓋を戻す。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:husky-home を参照。
