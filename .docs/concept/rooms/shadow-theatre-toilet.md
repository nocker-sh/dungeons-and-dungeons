# 六席の影絵小屋の便所

密閉回収式の便器と手洗い。回収は裏口から行い、食材の受け取りと時刻を分ける。換気を寝室へ戻さない。

## 一日の使い方

生活用通路から入り、利用後は手を洗う。密閉容器の回収は終演後、観客の退出と食材の搬入が終わってから裏口側で行う。回収経路を客席や調理台の前に延ばさない。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:shadow-theatre を参照。
