# ガンツの住まいの生活用通路

## この部屋の役割と配置

居間の奥から各室の西側の戸と裏口へつながる幅1.2mの生活用通路。各室の家具を動かさずに出入りできるようにする。

## 日々の使い方

入口から食卓、台所、洗い場、寝室へ分かれる。つるはしの柄、帽子、弁当箱の束を通路へ立てかけず、道具と食品の置き場へ分ける。裏口までの幅1.2mを荷物で縮めず、粉の清掃道具も収納へ戻す。

空間は今回の制作設定。[[concept/maps/gantz-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
