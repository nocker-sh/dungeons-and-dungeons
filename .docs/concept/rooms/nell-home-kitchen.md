# ネルの住まいの台所

## この部屋の役割と配置

3.1×3mの台所。東壁側に炉と排気口、隣に食材と器の作業台を置き、西の戸から幅1.2mの立つ範囲を空ける。

## 日々の使い方

依頼書や画鋲を食品の台へ持ち込まず、手を洗ってから食器を取る。子供が届く台と飲用水を用意し、火や重い湯を一人で扱う役目を固定しない。紙の整理と調理を同時にせず、弟を養う家の全作業をネル一人へ背負わせない。

空間は今回の制作設定。[[concept/maps/nell-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
