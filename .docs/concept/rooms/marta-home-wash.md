# マルタの住まいの洗い場

## この部屋の役割と配置

3.1×2mの洗い場。桶と手洗い、乾いた着替えの台を分ける。換気は東の外壁へ逃がし、寝室へ湿りを戻さない。

## 日々の使い方

道具に付いた泥と本人の洗身を分ける。濡れた巻き尺は拭いて乾かし、乾いた地図筒と衣類へ触れさせない。鉛筆を衣類から取り分けてから洗濯物を扱い、清潔な服で寝室へ戻る。

空間は今回の制作設定。[[concept/maps/marta-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
