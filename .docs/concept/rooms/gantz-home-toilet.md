# ガンツの住まいの便所

## この部屋の役割と配置

3.1×2mの便所。密閉回収式の便器と手洗いを置き、通路側の個別の戸から利用する。換気は外壁へ抜く。

## 日々の使い方

個別の戸で通路から利用し、戻る前に手を洗う。回収は弁当の調理と受け渡しが終わってから裏口側で行い、包んだ弁当と回収物を同じ通路で行き交わせない。汚れた容器を食品の台へ置かない。

空間は今回の制作設定。[[concept/maps/gantz-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
