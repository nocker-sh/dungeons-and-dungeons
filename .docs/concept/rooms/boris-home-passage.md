# ボリスの住まいの生活用通路

## この部屋の役割と配置

居間の奥から各室の西側の戸と裏口へつながる幅1.2mの生活用通路。各室の家具を動かさずに出入りできるようにする。

## 日々の使い方

預かり靴と修理後の靴を通路の床へ並べず、棚で分けて管理する。糸や靴紐が戸へ掛からないように収める。居間から寝室・便所・裏口までを空け、生活の出入口を客の待ち場所として塞がない。

空間は今回の制作設定。[[concept/maps/boris-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
