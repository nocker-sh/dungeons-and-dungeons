# トーマの住まいの生活用通路

## この部屋の役割と配置

居間の奥から各室の西側の戸と裏口へつながる幅1.2mの生活用通路。各室の家具を動かさずに出入りできるようにする。

## 日々の使い方

荷車本体を家の通路へ押し込まず、室内へ持ち込む荷だけを壁側の収納へ分ける。幌の端を各室の戸に挟まず、針は閉じる箱へ戻す。夜も寝室から便所へは荷台を跨がずに行ける幅を残す。

空間は今回の制作設定。[[concept/maps/toma-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
