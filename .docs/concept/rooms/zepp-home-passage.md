# ゼップの住まいの生活用通路

## この部屋の役割と配置

居間の奥から各室の西側の戸と裏口へつながる幅1.2mの生活用通路。各室の家具を動かさずに出入りできるようにする。

## 日々の使い方

全室を地上階の幅1.2mの通路で結ぶ。敷物の端や油の容器を床へ出さず、火消し竿は各室の戸へ倒れない留め方で収納する。居間から便所と寝室へは階段を通らず、裏口まで固定灯で足元を確認できるようにする。

空間は今回の制作設定。[[concept/maps/zepp-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
