# ダンの住まいの生活用通路

## この部屋の役割と配置

居間の奥から各室の西側の戸と裏口へつながる幅1.2mの生活用通路。各室の家具を動かさずに出入りできるようにする。

## 日々の使い方

大きな背負子は壁際の荷置きへ収め、横へ張り出した紐をまとめる。骨片を束ねる作業は通路で行わず、入口から居間、寝室、裏口まで歩ける状態を保つ。家を実家への納品先や親の住まいと呼ばない。

空間は今回の制作設定。[[concept/maps/dan-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
