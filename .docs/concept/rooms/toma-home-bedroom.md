# トーマの住まいの寝室

## この部屋の役割と配置

3.1×4mの寝室。0.9×2.1mの寝台一つを西の戸から離れた壁側へ置き、足元から戸へ抜ける範囲を空ける。

## 日々の使い方

寝台に幌布を積まず、針を刺した布を寝具の横へ持ち込まない。乾いた衣服を棚へ戻し、翌日の荷を床から外して休む。本人用の寝台を、妻と別れたことや妻が亡くなったことの根拠にしない。

空間は今回の制作設定。[[concept/maps/toma-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
