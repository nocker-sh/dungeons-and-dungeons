# ハンナの住まいの居間

## この部屋の役割と配置

4.5×4.2mの居間。食卓を入口と奥の通路の直線上から外し、壁際に本人の荷を置く範囲を設ける。

## 日々の使い方

本を読む席と食事の卓を用意し、根菜の籠は食品を扱う台側へ置く。泥の付いた前掛けを椅子へ掛けず、本代の小銭と釣銭の包みを別にしまう。日暮れ前に帰った後、売り物の整理だけで夜が終わらず、食事と読書の時間を取れるようにする。

空間は今回の制作設定。[[concept/maps/hanna-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
