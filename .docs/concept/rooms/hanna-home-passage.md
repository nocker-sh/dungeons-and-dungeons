# ハンナの住まいの生活用通路

## この部屋の役割と配置

居間の奥から各室の西側の戸と裏口へつながる幅1.2mの生活用通路。各室の家具を動かさずに出入りできるようにする。

## 日々の使い方

籠と前掛けは各室の決めた場所へ戻し、床へ根菜や硬貨を落としたままにしない。居間から寝室へは作物の荷を跨がずに移動できるようにする。通路を家族の人数の根拠にせず、各室の戸と裏口を常に開けられる状態に保つ。

空間は今回の制作設定。[[concept/maps/hanna-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
