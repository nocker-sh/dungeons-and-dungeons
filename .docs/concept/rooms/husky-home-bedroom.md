# ハスキーが維持する二人の貸間の寝室

寝台を二つ置き、相棒の寝台を荷物置き場にしない。相棒の生存を前提とするが、今いる場所と帰還の時期は決めない。

## 一日の使い方

自分の寝台で休み、相棒の寝台と足元を空けておく。未使用の寝具も湿気を確かめて干し、戻した後は埃を避ける。寝台二つの間を抜けて通路側の戸へ出られる幅を保つ。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:husky-home を参照。
