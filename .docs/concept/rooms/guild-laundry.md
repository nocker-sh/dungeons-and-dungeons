# ギルドの洗濯室

汗と谷の泥を客室から切り離す。

## 家具と身体の収まり

汚れ物の籠、予洗い桶、すすぎ桶、絞り台を順に並べる。乾燥は裏庭の物干しへ運び、室内の通路に吊らない。

## 一日の使い方

飲用水の容器で洗濯水を運ばない。床の水を集水溝へ寄せ、作業後に乾かす。

## 生活を支える経路

食事と飲用水は炊事室、洗身は洗い場、排泄は同じ階の便所へつなぐ。用途が違う水と容器を混ぜない。各接続先はメタデータの資料IDで管理する。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。
