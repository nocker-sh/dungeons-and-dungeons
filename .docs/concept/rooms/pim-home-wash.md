# ピムの住まいの洗い場

## この部屋の役割と配置

3.1×2mの洗い場。桶と手洗い、乾いた着替えの台を分ける。換気は東の外壁へ逃がし、寝室へ湿りを戻さない。

## 日々の使い方

持ち帰った小石を洗う器と、手や体を洗う水を分ける。マフラーを寝具の上で乾かさず、水気を切って干す場所へ運ぶ。子供が熱い湯の運搬を一人で担う設計にせず、乾いた着替えと固定した腰掛けを使えるようにする。

空間は今回の制作設定。[[concept/maps/pim-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
