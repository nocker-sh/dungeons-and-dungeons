# ダンの住まいの台所

## この部屋の役割と配置

3.1×3mの台所。東壁側に炉と排気口、隣に食材と器の作業台を置き、西の戸から幅1.2mの立つ範囲を空ける。

## 日々の使い方

骨片と背負子は食品の台へ載せず、荷を扱った後は手を洗ってから食事を用意する。荷の洗浄水を飲用へ戻さず、食べる器と骨を選別する器を分ける。調理後は火を確かめ、寝る前に食器を片付ける。

空間は今回の制作設定。[[concept/maps/dan-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
