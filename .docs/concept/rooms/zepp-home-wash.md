# ゼップの住まいの洗い場

## この部屋の役割と配置

3.1×2mの洗い場。桶と手洗い、乾いた着替えの台を分ける。換気は東の外壁へ逃がし、寝室へ湿りを戻さない。

## 日々の使い方

腰掛けて足元を洗える座面と、手の届く位置の桶を置く。濡れた床へ竿を杖代わりに立てず、拭いて滑りを減らす。重い湯を一度に運ばず、小分けにして準備してから着替えを乾いた台へ置く。

空間は今回の制作設定。[[concept/maps/zepp-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
