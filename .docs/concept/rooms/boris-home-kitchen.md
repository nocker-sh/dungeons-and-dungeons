# ボリスの住まいの台所

## この部屋の役割と配置

3.1×3mの台所。東壁側に炉と排気口、隣に食材と器の作業台を置き、西の戸から幅1.2mの立つ範囲を空ける。

## 日々の使い方

錐と革屑を食品の台へ持ち込まず、作業後に手を洗ってから調理する。靴を拭いた布と食器を拭く布を分ける。食事の器は調理台へ戻し、修理で使う液体や道具を飲用水の容器へ入れない。

空間は今回の制作設定。[[concept/maps/boris-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
