# マルタの住まいの便所

## この部屋の役割と配置

3.1×2mの便所。密閉回収式の便器と手洗いを置き、通路側の個別の戸から利用する。換気は外壁へ抜く。

## 日々の使い方

通路から個別の戸で入り、手洗いを済ませてから地図や記録へ触れる。裏口側の回収物を地図筒と一緒に運ばず、厨房への食材搬入と時刻を分ける。夜も固定灯の通路を使い、寝台を跨がずに行く。

空間は今回の制作設定。[[concept/maps/marta-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
