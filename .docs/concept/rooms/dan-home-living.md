# ダンの住まいの居間

## この部屋の役割と配置

4.5×4.2mの居間。食卓を入口と奥の通路の直線上から外し、壁際に本人の荷を置く範囲を設ける。

## 日々の使い方

骨を納めた後に背負子を外し、本人が食事を取る卓を空ける。取り分と実家の屋根の修理に回す金は袋を分け、食品の上へ硬貨を広げない。骨片を居間の床へ積み、毎回跨いで暮らす配置にしない。

空間は今回の制作設定。[[concept/maps/dan-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
