# 屋根裏客室

安い寝床にも四人分の睡眠と安全な出入りを保障する。

## 家具と身体の収まり

寝台2.1×0.9mを左右二台ずつ。棟下の中央を立って歩く通路にする。側壁高1.3m・棟高2.4m。頭を上げる位置に梁を渡さない。

## 一日の使い方

背面の小切妻の下に収める。窓と通気口を塞がず、油灯は固定金具へ。荷物を階段口に積まない。

## 生活を支える経路

便所は屋根裏階には設けず、前室と客室階段を通って一つ下の客室階の便所を使う。夜も階段と段差の灯りを残す。食事と飲用水、洗身は一階の炊事室と洗い場へ向かい、湯の桶を寝台の間で運び回らない。接続先はメタデータの資料IDにそろえる。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。

## 正面の入口

側壁は低く、寝台が二台ずつ並ぶ。入口はその隙間へ押し込まず、棟の高い正面の中央へ幅1.2mで取る。階段から前室を回るため、寝台を動かさず入室できる。
