# ハンナの住まいの台所

## この部屋の役割と配置

3.1×3mの台所。東壁側に炉と排気口、隣に食材と器の作業台を置き、西の戸から幅1.2mの立つ範囲を空ける。

## 日々の使い方

泥の付いた根菜を扱う面と、洗った食品を切る面を分ける。飲用水は蓋付きの容器に入れ、籠を床に置いたまま食べ物を戻さない。火と重い湯の作業をハンナ一人の役目へ固定せず、食事を分ける作業も子供が届く高さで行えるようにする。

空間は今回の制作設定。[[concept/maps/hanna-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
