# フィオの住まいの便所

## この部屋の役割と配置

3.1×2mの便所。密閉回収式の便器と手洗いを置き、通路側の個別の戸から利用する。換気は外壁へ抜く。

## 日々の使い方

種袋と剪定ばさみは清潔な収納へ置いてから利用する。手洗いを済ませて採取物へ戻り、回収物と薬草の搬出を同時に行わない。夜は通路の固定灯を使い、寝台や採取袋を跨がずに行く。

空間は今回の制作設定。[[concept/maps/fio-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
