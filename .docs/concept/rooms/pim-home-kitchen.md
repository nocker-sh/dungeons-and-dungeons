# ピムの住まいの台所

## この部屋の役割と配置

3.1×3mの台所。東壁側に炉と排気口、隣に食材と器の作業台を置き、西の戸から幅1.2mの立つ範囲を空ける。

## 日々の使い方

本人が水と食器に届く高さを確保し、熱い炉と湯を扱う作業を八歳の子供一人の仕事へ固定しない。食べ物を分ける台と小石を洗う器は分ける。母の帰宅時刻や不在期間は未指定のまま、日々食事を取れる生活設備を用意する。

空間は今回の制作設定。[[concept/maps/pim-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
