# ネルの住まいの居間

## この部屋の役割と配置

4.5×4.2mの居間。食卓を入口と奥の通路の直線上から外し、壁際に本人の荷を置く範囲を設ける。

## 日々の使い方

食事の卓と依頼書を整理する時間を分け、画鋲の缶は閉じてから卓を空ける。駄賃の空き缶と画鋲の缶を同じ物にまとめず、弟の靴代を取り分ける私物として保管する。煮込みをもらうことがある既存の暮らしを、毎日無料で食事できる規則に変えない。

空間は今回の制作設定。[[concept/maps/nell-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
