# キキの住まいの居間

## この部屋の役割と配置

4.5×4.2mの居間。食卓を入口と奥の通路の直線上から外し、壁際に本人の荷を置く範囲を設ける。

## 日々の使い方

二本の命綱を別々に広げて確かめる時は、食器を片付けた作業の時間を取る。点検後は二本を分けて収納し、卓を再び食事に使えるようにする。相方用の一本を、別人の同居や帰還済みの根拠にしない。

空間は今回の制作設定。[[concept/maps/kiki-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
