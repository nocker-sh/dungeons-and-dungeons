# ハスキーが維持する二人の貸間の便所

密閉回収式の便器と手洗い。回収は裏口から行い、食材の受け取りと時刻を分ける。換気を寝室へ戻さない。

## 一日の使い方

通路から利用し、寝室や台所を通り抜けない。使用後の手洗いを済ませ、裏口から回収する日は食材の受け取りをずらす。回収容器を二人の居間へ一時置きしない。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:husky-home を参照。
