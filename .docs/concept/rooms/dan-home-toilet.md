# ダンの住まいの便所

## この部屋の役割と配置

3.1×2mの便所。密閉回収式の便器と手洗いを置き、通路側の個別の戸から利用する。換気は外壁へ抜く。

## 日々の使い方

通路の戸から利用し、背負子を背負ったまま狭い便所へ入らない。手洗いを終えてから食品や私物へ触れる。回収物は裏口から出し、骨の納品荷と食材を一時置きする場所へ混ぜない。

空間は今回の制作設定。[[concept/maps/dan-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
