# マルタの住まいの生活用通路

## この部屋の役割と配置

居間の奥から各室の西側の戸と裏口へつながる幅1.2mの生活用通路。各室の家具を動かさずに出入りできるようにする。

## 日々の使い方

地図筒は縦に留めた収納へ、巻き尺は各室の道具入れへ戻す。筒を床へ転がしたままにせず、組の集まりを通路で始めない。各室から裏口まで幅を保ち、運ぶ荷と戸の可動範囲を分ける。

空間は今回の制作設定。[[concept/maps/marta-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
