# ロイドの住まいの居間

## この部屋の役割と配置

帰還後に腰を下ろして食べる卓と一人分の椅子を置く。卓は戸口の直線上から外し、濡れた外着は洗い場へ運ぶ。籠の操作場所へ食べ物を持ち込んで済ませず、運行を終えた後に家で食事を取れる場所を確保する。

## 日々の使い方

勤務前は飲用水と食事を取り、出口の壁際で身支度する。帰宅後はまず洗い場で手を洗い、食事を終えた器を台所へ戻す。最後の籠を待つ仕事を、本人に睡眠が不要な理由にしない。

寸法・接続は[[concept/maps/lloyd-home|生活配置図]]へつなぐ。空間は今回の制作設定であり、宿泊料金・回復量・運行時刻や購入できる家を実行用データへ追加しない。
