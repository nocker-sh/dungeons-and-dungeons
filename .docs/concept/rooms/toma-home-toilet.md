# トーマの住まいの便所

## この部屋の役割と配置

3.1×2mの便所。密閉回収式の便器と手洗いを置き、通路側の個別の戸から利用する。換気は外壁へ抜く。

## 日々の使い方

荷車を止めてから家の便所を利用し、通路の個別の戸から入る。使用後の手洗いを済ませ、回収物と食材の搬入を分ける。清掃用の布を幌の修繕布へ転用せず、回収物は裏口から外へ出す。

空間は今回の制作設定。[[concept/maps/toma-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
