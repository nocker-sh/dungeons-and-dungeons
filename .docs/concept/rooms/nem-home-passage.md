# ネムと相棒の住まいの生活用通路

居間の奥からネムの生活設備へつながる。相棒の身体が休む面は居間側に置き、餌袋を通路へ並べない。

## 一日の使い方

ネムが各室へ移動するための通路として空けておく。相棒の休息面と餌袋は居間側へ収め、狭い通路で人と一体の相棒を無理にすれ違わせない。奥の裏口を清掃と回収のためにも使える状態に保つ。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:nem-home を参照。
