# イルマの住まいの生活用通路

## この部屋の役割と配置

居間の奥から各室の西側の戸と裏口へつながる幅1.2mの生活用通路。各室の家具を動かさずに出入りできるようにする。

## 日々の使い方

帳面の束と鉛筆の箱は各室の収納へ収め、通路の床を臨時の書庫にしない。居間から寝室・水場・便所へは仕事の記録を跨がずに移動する。固定灯で足元を照らし、裏口を紙箱で塞がない。

空間は今回の制作設定。[[concept/maps/irma-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
