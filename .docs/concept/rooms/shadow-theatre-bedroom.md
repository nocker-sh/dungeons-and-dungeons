# 六席の影絵小屋の寝室

興行の片付けを終えてから休む。人形と紙は乾いた箱へ、灯りの器は冷ましてから別の棚へ戻し、舞台の上を寝床にしない。

## 一日の使い方

ミミカは客が帰った後に寝室で休む。幕と影絵の道具を寝台の上へ積まず、衣服の収納と分ける。閉じた客席を寝台の追加人数に数えず、客席を横切らず便所へ行ける経路を残す。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:shadow-theatre を参照。
