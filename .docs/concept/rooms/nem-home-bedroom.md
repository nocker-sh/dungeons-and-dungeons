# ネムと相棒の住まいの寝室

人の寝台は相棒の休む床と分ける。人も食事と睡眠を取り、餌代のために本人が生活できなくなる配置や運営を正解にしない。

## 一日の使い方

ネムは人の寝台で休み、相棒は別に確保した居間の休息面を使う。餌袋と汚れた散歩道具は寝具から離す。夜も戸の前を空け、相棒の三つの頭のうち一つだけが入口を塞ぐ配置にしない。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:nem-home を参照。
