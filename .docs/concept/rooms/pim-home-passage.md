# ピムの住まいの生活用通路

## この部屋の役割と配置

居間の奥から各室の西側の戸と裏口へつながる幅1.2mの生活用通路。各室の家具を動かさずに出入りできるようにする。

## 日々の使い方

窓辺の小石とマフラーは居間・寝室側へ収め、床へ転がさない。各室から食事・洗身・就寝へ移動でき、乗り場の柵で夜を明かす必要のない住まいにする。戸を開ける高さに本人の手が届くようにし、裏口を荷で塞がない。

空間は今回の制作設定。[[concept/maps/pim-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
