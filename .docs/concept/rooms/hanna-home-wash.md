# ハンナの住まいの洗い場

## この部屋の役割と配置

3.1×2mの洗い場。桶と手洗い、乾いた着替えの台を分ける。換気は東の外壁へ逃がし、寝室へ湿りを戻さない。

## 日々の使い方

農場や売り場から戻ったら前掛けの泥を落とし、手を洗ってから本と食事に触れる。野菜を洗う桶と体を洗う桶を分け、乾いた着替えを濡らさない。濡れた床を拭き、子供が重い湯を抱えて歩く前提にしない。

空間は今回の制作設定。[[concept/maps/hanna-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
