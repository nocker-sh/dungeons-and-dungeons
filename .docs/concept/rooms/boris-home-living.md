# ボリスの住まいの居間

## この部屋の役割と配置

4.5×4.2mの居間。食卓を入口と奥の通路の直線上から外し、壁際に本人の荷を置く範囲を設ける。

## 日々の使い方

食事を取る卓と靴を直す作業の時間を分け、食べる前には革屑と糸を片付ける。預かった靴は本人の私物と分け、息子の靴だけを代金なしで直す扱いを他の客全員へ広げない。客の列を生活用通路へ入れない。

空間は今回の制作設定。[[concept/maps/boris-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
