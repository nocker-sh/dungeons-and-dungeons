# ネルの住まいの生活用通路

## この部屋の役割と配置

居間の奥から各室の西側の戸と裏口へつながる幅1.2mの生活用通路。各室の家具を動かさずに出入りできるようにする。

## 日々の使い方

肩掛け袋を戸の把手へ掛けず、各室の収納へ戻す。落ちた画鋲を拾ってから通路を空け、弟や本人が裸足で踏む状態にしない。依頼書の束を床へ積まず、居間から各寝台・洗い場・便所・裏口へ通れる幅を保つ。

空間は今回の制作設定。[[concept/maps/nell-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
