# 六席の影絵小屋の台所

飲用水を覆った容器で保ち、食材・食器・汚れた器を分ける。人の食事の器を道具や動物の餌入れに転用しない。

## 一日の使い方

興行の道具を置く卓と、人が食べる調理台を分ける。食事を済ませてから器を洗い、影絵の灯りや幕を台所の火へ近付けない。終演後も飲用水を取りに来られるよう通路側を空ける。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:shadow-theatre を参照。
