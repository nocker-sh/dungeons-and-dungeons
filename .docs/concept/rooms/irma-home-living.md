# イルマの住まいの居間

## この部屋の役割と配置

4.5×4.2mの居間。食卓を入口と奥の通路の直線上から外し、壁際に本人の荷を置く範囲を設ける。

## 日々の使い方

帳面を読む間は卓から食器を外し、読み終えたら乾いた棚へ戻す。数が合った日に買う甘いパンは皿へ載せ、帳面に紙屑や食べかすを挟まない。椅子を引いても奥の通路へ出られる幅を残す。

空間は今回の制作設定。[[concept/maps/irma-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
