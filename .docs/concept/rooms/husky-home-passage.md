# ハスキーが維持する二人の貸間の生活用通路

居間の奥から台所・寝室・洗い場・便所の個別の戸へ分かれる。二人分の荷物は各室に収め、通路の終端の裏口まで幅を保つ。

## 一日の使い方

居間から各室へ分かれ、奥の裏口へ抜ける。ハスキーの荷と替えの衣服は各室の収納へ戻す。相棒のために空けた寝台へ荷を寄せる代わりに、必要な収納量を自分の側で管理する。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:husky-home を参照。
