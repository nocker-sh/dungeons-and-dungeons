# ネムと相棒の住まいの洗い場

桶、手洗い、乾いた着替え台を分ける。衣類を洗った水は飲用へ戻さず、濡れた床を乾かしてから退出する。

## 一日の使い方

人が体を洗う桶と、相棒の器・足元を拭く道具を分ける。濡れた布は換気のある場所で乾かし、寝具と餌袋へ触れさせない。相棒の身体全体を人用の洗い場へ無理に押し込む設計にはしない。

## 制作設定の範囲

人物の既存の動機と持ち物を、暮らせる空間へつなぐ設計。新しい人物の名前・生死・帰還の結末は決めず、ゲーム内の無料宿や購入できる住居も追加しない。位置と接続は map:nem-home を参照。
