# ロイドの住まいの寝室

## この部屋の役割と配置

0.9×2.1mの寝台を一つ、西の戸から離れた壁側へ置く。寝台の足元から戸へ抜ける範囲を空け、乾いた着替えの棚を北東の壁へ寄せる。乗り場の操作台や待合の椅子を、夜の寝床に数えない。

## 日々の使い方

運行を終えて帰った後、洗身して乾いた服に替えてから寝具へ入る。休息中の対応を常時呼び出し前提にせず、再開時刻まで寝られる時間を取る。運行の交代制や新しい同僚はこの寝室の設計から作らない。

寸法・接続は[[concept/maps/lloyd-home|生活配置図]]へつなぐ。空間は今回の制作設定であり、宿泊料金・回復量・運行時刻や購入できる家を実行用データへ追加しない。
