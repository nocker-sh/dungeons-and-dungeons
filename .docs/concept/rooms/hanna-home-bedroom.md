# ハンナの住まいの寝室

## この部屋の役割と配置

3.1×5.6mの寝室。0.9×2.1mの寝台を左右二列に四つまで配置する。西の戸は列と列の間へ置き、戸から中央の幅1.1mの通り道へ入る。寝台間の仕切りは通路と換気を塞がない。

## 日々の使い方

ハンナ本人の寝台と本の収納を用意し、本を寝具へ積んで寝る場所を減らさない。家族構成が未決定でも使えるよう寝台は最大四つまでの設計とし、空床の数から兄弟や両親の人数を決めない。各寝台の収納と仕切りで私物を分け、中央の戸まで通れる幅を保つ。

空間は今回の制作設定。[[concept/maps/hanna-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
