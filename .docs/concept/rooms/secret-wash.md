# 地下の洗い場

地下の住人が地上の客室を横切らずに洗身する。

## 家具と身体の収まり

仕切り付き洗い台と乾いた着替え棚。床の水を一か所へ集め、寝室側へ流さない。

## 一日の使い方

湯は容器で運ぶ。使用後に床を乾かし、湿気は外へ抜く。暗さの好みを換気不足の理由にしない。

## 生活を支える経路

食事と飲用水は地下の食事準備室から共用室へ運び、作業を終えて手を洗ってから取る。この室の作業用の器や回収物は食事の器と分け、東のサービス通路に置きっぱなしにしない。就寝は各自の寝室へ戻る。

## 実装との境界

寸法と人数は空間の制作設計。宿泊料金、回復量、パーティ上限、部屋の購入条件は実行用データを正とし、この資料から新しい効果を作らない。
