# フィオの住まいの寝室

## この部屋の役割と配置

3.1×4mの寝室。0.9×2.1mの寝台一つを西の戸から離れた壁側へ置き、足元から戸へ抜ける範囲を空ける。

## 日々の使い方

乾いた寝間着と清潔な布を寝台側の棚へ収め、採取袋と剪定ばさみを寝具へ載せない。兎耳を寝台と壁の狭い隙間へ押し付けずに起き上がれる余白を保つ。納品前の種を枕元へ広げて寝床を減らさない。

空間は今回の制作設定。[[concept/maps/fio-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
