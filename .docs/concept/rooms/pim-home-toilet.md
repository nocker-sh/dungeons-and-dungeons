# ピムの住まいの便所

## この部屋の役割と配置

3.1×2mの便所。密閉回収式の便器と手洗いを置き、通路側の個別の戸から利用する。換気は外壁へ抜く。

## 日々の使い方

夜も家の通路から便所へ行けるよう、固定灯と手が届く手洗いを設ける。マフラーや小石を便器の脇へ置かない。回収物の搬出を子供だけの仕事にせず、食材を運ぶ時間と分けて裏口側で行う。

空間は今回の制作設定。[[concept/maps/pim-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
