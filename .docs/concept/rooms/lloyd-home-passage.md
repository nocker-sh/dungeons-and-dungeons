# ロイドの住まいの生活用通路

## この部屋の役割と配置

幅1.2mの通路を居間の奥から裏口まで通し、台所・寝室・洗い場・便所へ個別の戸を設ける。戸を開けるために隣室の家具を押す構造にせず、床へ道具を常置しない。

## 日々の使い方

外着は洗い場、清潔な服は寝室、食器は台所へ戻す。食材と回収物は同時に運び込まず、裏口の前を空けておく。退避時は各室から通路を通って表か裏の屋外へ出る。

寸法・接続は[[concept/maps/lloyd-home|生活配置図]]へつなぐ。空間は今回の制作設定であり、宿泊料金・回復量・運行時刻や購入できる家を実行用データへ追加しない。
