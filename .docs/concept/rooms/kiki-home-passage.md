# キキの住まいの生活用通路

## この部屋の役割と配置

居間の奥から各室の西側の戸と裏口へつながる幅1.2mの生活用通路。各室の家具を動かさずに出入りできるようにする。

## 日々の使い方

二本の縄の輪を床へ置かず、各室の収納へ収める。濡れた道具を運ぶ時は床の水を拭き、足を引っ掛けない状態に戻す。橋の荷を家の通路へ常置せず、居間から寝室と裏口へ抜けられるようにする。

空間は今回の制作設定。[[concept/maps/kiki-home|生活配置図]]で戸口と寝台の位置を照合する。既存の来歴や報酬、家族構成はここから変更しない。
