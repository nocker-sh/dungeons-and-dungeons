# ギルドの裏庭と搬入・回収

食べて洗って眠れる部屋を支える裏側。内側の制作寸法を幅17.4m・奥行6mとして、食料と水、布、密閉回収物を同じ面へ置かない。

西側は食材と飲用水の受け取り。覆った台を地面から上げ、炊事室へ運ぶ。飲用水の容器に回収用の札や器を使い回さない。上流側の清潔な配水から受け、雨樋の水を飲用へ直結しない。

中央は洗濯物の乾燥。布は通る頭の上へ垂らさず、物干しの下を搬入や避難の経路にしない。雨の時は奥行の浅い庇下へ移し、風を通す。湿った布を地下の寝具室に干し続けない。

東奥は便所の密閉容器と汚れた作業布の受け渡し。容器は蓋をして倒れ止めのある面へ置く。食材の受け取りを終えてから回収し、同じ台車や容器へ混ぜない。排泄物を庭へ埋めたり、水路や農場へそのまま流したりしない。

建物の裏口と回収側の門を結ぶ幅1.4mの経路は常に空ける。地下西通路の避難口と、客室階からの外階段がこの庭へ出る。誰かが物干しを使っていても、避難する人が布や容器を避けて細い隙間を抜ける配置にしない。門は内側から開けられ、戻る路地へ抜ける。

この資料は生活と保守の制作設計。ゲームに清掃費・水代・新しい操作を追加する規則ではない。回収担当者の名前や新しい来歴は決めず、住人の生活を支える仕事として扱う。
