# 響銅の剣盾

## 画像から確認した造形

灰の剣に金の鐘。鐘を鍔の平板に置換しない。

## 暮らしの中での取り扱い

刃を覆って寝台の外側へ収め、足で跨ぐ置き方をしない。手入れの油は食器から分け、使った布を枕元へ積まない。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 受けの直後に二度返す剣盾。

造形: 片手剣と浅い椀形の丸盾。鐘の吊り輪・大きい割れ口をなくす。

素材の働き: 古い鐘の銅材を再鋳造し、鋼縁を持つ携行盾へ仕立てる。鐘の器形を残さず材質の音だけ継ぐ。

現行ワザとの関係: シールドバッシュ・二段斬り・見切りが実スキル。岩塊の壁などを追加しない。

発見の魅力: 受けるたび短く鳴る金属。音を持つ盾の手入れを想像できる。
