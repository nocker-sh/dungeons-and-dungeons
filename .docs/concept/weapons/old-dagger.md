# 詰め直しの短剣

## 画像から確認した造形

灰錆の欠けた短刃、白布の握り。

## 暮らしの中での取り扱い

小さくても刃を裸のまま私物箱へ入れず、鞘や覆いを付ける。刃物を出したまま眠らず、洗濯物の中へ紛れ込ませない。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 短い間合いと投擲を使う旧型。

造形: 短い三角刃とやや長めの古い柄。切先は完全に作り直されている。

素材の働き: 折れたままの先端ではなく、再成形した鋼の研ぎ面。

現行ワザとの関係: 刺突・投げ短剣・毒塗りに使える形へ修理済み。既存の短剣と輪郭長で区別。

発見の魅力: 誰かの使った道具が、自分の最初の武器になる。
