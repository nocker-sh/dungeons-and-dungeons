# 鋼拳の手甲

## 画像から確認した造形

左右一対の灰鉄の拳、赤い袖口。

## 暮らしの中での取り扱い

小さくても刃を裸のまま私物箱へ入れず、鞘や覆いを付ける。刃物を出したまま眠らず、洗濯物の中へ紛れ込ませない。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 素手の連打と受けを装甲で支える。

造形: 左右一対、拳板・独立した親指・短い袖口。岩塊や指なしグローブにしない。

素材の働き: 鋼板は拳の外側、革の関節は内側。拳の衝撃を袖口の帯へ逃がす。

現行ワザとの関係: 鉄拳連打は重なる拳板、刺突は指先の一点、見切りは手首の可動域に対応。

発見の魅力: 自分の拳が武器になる密着感。左右が揃った完成品の格好よさ。
