# 朱印の短剣

## 画像から確認した造形

暗灰短刃と赤封蝋、赤握り。

## 暮らしの中での取り扱い

小さくても刃を裸のまま私物箱へ入れず、鞘や覆いを付ける。刃物を出したまま眠らず、洗濯物の中へ紛れ込ませない。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 連続した精密な切り込みと位置取り。

造形: 細い黒鋼刃、小さい朱の核、掌長の暗い柄。

素材の働き: 封止材を鍔の小核へ限定し、刃は鍛造鋼のまま。

現行ワザとの関係: 背刺し・連ね斬り・影踏みを軽い刀身で支える。異能の核は現行技以上の能力を追加しない。

発見の魅力: 派手な装飾ではなく、黒刃と一点の朱が記憶に残る。
