# 歯鋼の大斧

## 画像から確認した造形

橙錆の歯車形斧頭と茶柄、赤巻き。

## 暮らしの中での取り扱い

重い頭を人の足へ倒さない受けに置き、柄を通路へ突き出さない。汚れを拭く卓と食事の卓を分ける。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 主刃で割り、背の短い鉤で引く。

造形: 一枚の広い主刃、後ろの短い鉤、厚い中心ソケット。巨大歯車の半切りはやめる。

素材の働き: 硬い歯材を有効刃へ加工し、元の歯形は後頭に二つまで残す。

現行ワザとの関係: 打ち砕き・叩き割りは連続する主刃、引っ掛けは短い背鉤に対応。

発見の魅力: 遺跡機械の鋼質が、武具専用の刃形へ生まれ変わる。
