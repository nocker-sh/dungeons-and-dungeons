# 星灰の魔法銃

## 画像から確認した造形

紫の香室と金の蓋の魔法銃。

## 暮らしの中での取り扱い

長さのある道具は壁際の受けへ置き、人や出入口へ向けない。手入れの小部品と薬、食事、火を使う作業を分ける。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 広い放出、貫通、味方への治癒を使い分ける。

造形: 太い短銃身、閉じた黒い薬室、小さい紫金色の核窓。香炉の蓋・足・煙を付けない。

素材の働き: 星灰を安定した核へ焼結し、金属の座に保持する提案。器をそのまま銃へ接続しない。

現行ワザとの関係: 星屑の雨・貫通弾・治癒弾が実スキル。旧descの溜め撃ちは約束しない。

発見の魅力: 小さい窓の奥に散る核が、広い空間へ開く一発を想像させる。
