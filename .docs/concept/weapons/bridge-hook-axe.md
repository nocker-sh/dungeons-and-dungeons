# 橋鋼の鉤斧

## 画像から確認した造形

錆色の大きな鉤状刃と茶柄。

## 暮らしの中での取り扱い

重い頭を人の足へ倒さない受けに置き、柄を通路へ突き出さない。汚れを拭く卓と食事の卓を分ける。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 引き寄せと回転する打撃。

造形: 広い前刃、短い後鉤、厚い中央首と長柄。留め金そのものの輪郭を避ける。

素材の働き: 遺跡鋼を一体の斧頭へ鍛造。鉤は接着部品でなく同じ厚い鋼の続き。

現行ワザとの関係: 引っ掛け・重ね打ち・旋風斧を同じ長柄の向きで対応。旧descの打ち砕きは記さない。

発見の魅力: 用途の違う二つの先端が、一つの強い頭に収まる。
