# 縫い代の身体

## 資料の対象

実行用データでは装備として管理される契約に関わる身体の造形。通常の店売りの武器を一本追加した設定として扱わない。形と説明の正本は runtime の参照先。

## 生活の中での取り扱い

伸びた糸が通路や他人の荷へ絡まないよう、身体の手入れは明るい卓の前で行う。浅くなる縫い代を、普通の布の在庫で無制限に補えるとしない。

## 整合性

人物の生活動機や未判明の約束を、この形の由来として新しく確定しない。使用条件、能力、ワザ、変化の進行は実行用の契約と装備の規則に従う。制作上の取り扱いを、追加の回復・修復・燃料・移動能力へ変えない。
