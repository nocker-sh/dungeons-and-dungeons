# 前衛の剣盾

## 画像から確認した造形

灰の剣と木茶の盾に金属縁・赤帯。二点一組。

## 暮らしの中での取り扱い

刃を覆って寝台の外側へ収め、足で跨ぐ置き方をしない。手入れの油は食器から分け、使った布を枕元へ積まない。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 受けた直後に剣を返す前衛の一式。

造形: 剣一本と角を落とした小盾一枚。盾の中心金具と腕帯を一体の荷重構造にする。

素材の働き: 木板の芯に金属縁と中央座金。盾面は平板の貼り物でなく厚い積層断面。

現行ワザとの関係: シールドバッシュの押す面、斬り上げの空間、見切りの軽い取り回しを両立する。

発見の魅力: 仲間の前へ立てる装備が一式そろう。盾の手触りと剣の軽さを対にする。
