# 継鋼の剣盾

## 画像から確認した造形

灰剣と赤白帯の鋲付き盾。

## 暮らしの中での取り扱い

刃を覆って寝台の外側へ収め、足で跨ぐ置き方をしない。手入れの油は食器から分け、使った布を枕元へ積まない。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 強い盾打ちと速い剣の返し。

造形: 継ぎ目を刃元に収めた剣と、重ね板の角盾。散漫なパッチワークにしない。

素材の働き: 鋲は荷重のかかる重なり面だけ。切刃を継ぎ接ぎせず一本の鍛造材にする。

現行ワザとの関係: シールドバッシュ・早突き・十字斬りを盾面と素直な直刃で支える。

発見の魅力: 同じ鋼の一枚物とは違う、職人が組み上げた厚み。
