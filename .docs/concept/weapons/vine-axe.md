# 翠芯の戦斧

## 画像から確認した造形

灰斧頭と緑蔓の巻く茶柄。

## 暮らしの中での取り扱い

重い頭を人の足へ倒さない受けに置き、柄を通路へ突き出さない。汚れを拭く卓と食事の卓を分ける。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 回転を含む連撃と強い打撃。

造形: 重い片刃、やや細い長柄、ソケットから見える緑褐色の積層断面。

素材の働き: 植物繊維は柄の内部の強靭材。外周を巻く生蔦・棘・葉は使わず握りを平滑にする。

現行ワザとの関係: 打ち砕き・旋風斧・重ね打ちは粘る柄と重い頭の組み合わせ。

発見の魅力: 見た目は締まった斧なのに、柄の断面に温室材の秘密がある。
