# 鍛鉄の大剣

## 画像から確認した造形

灰色の長く幅広い刃、赤巻きの長柄、灰の鍔。両手で握る長さを保つ。

## 暮らしの中での取り扱い

長い刃を出入口へ立て掛けず、刃を覆って倒れ止めのある壁際へ置く。抜き差しと背負い直しは他人の寝台から離れた場所で行う。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 正面を押し開き、群れを薙ぐ両手武器。

造形: 幅広い直刃、厚い刃元、長い赤革の両手柄。鍔と大きい柄尻で輪郭を締める。

素材の働き: 鍛鉄の厚みを中央へ集め、切先を薄く整える。赤革は柄だけ。

現行ワザとの関係: 円を描く大車輪斬り、上から落とす兜割り、直進する踏み込み斬りを、一枚の長刃の向きの違いで読ませる。

発見の魅力: 初めて重い武器を持てるようになった成長が、一本の長さで伝わる。
