# 継ぎ柄の大剣

## 画像から確認した造形

欠けた錆茶の灰刃と古い布巻きの長柄。

## 暮らしの中での取り扱い

長い刃を出入口へ立て掛けず、刃を覆って倒れ止めのある壁際へ置く。抜き差しと背負い直しは他人の寝台から離れた場所で行う。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 駆け出しが両手武器の動きを覚える。

造形: 細く減った大剣刃と長い継ぎ革柄。大きい欠損や破断は付けない。

素材の働き: 摩耗は背の古い鍛肌へ限定。接合部を補修した鋼と新しい革が使用可能を伝える。

現行ワザとの関係: 大車輪斬り・兜割り・踏み込み斬りができる、軽く研ぎ減った旧型。威力は既存値を維持。

発見の魅力: いつか新しい大剣へ持ち替えるまで付き合える、安いが頼れる一振り。
