# 影断ちの鋏

## 画像から確認した造形

大きな金の鍵。穴のある頭と歯の向きを維持。

## 暮らしの中での取り扱い

小さくても刃を裸のまま私物箱へ入れず、鞘や覆いを付ける。刃物を出したまま眠らず、洗濯物の中へ紛れ込ませない。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 影を切り取り、動きを縛る特殊短剣枠。

造形: 長い二枚刃、一つの支点、掌を入れられる二つの金色輪。鍵の歯は消す。

素材の働き: 黒鋼の合わせ面に影を扱う結晶線。実際の鋏構造と異能の線を分ける。

現行ワザとの関係: 影切り・投げ短剣・影踏みを保持。投擲は閉じた一体の形として示し、新たな召喚効果は足さない。

発見の魅力: 普通の鋏の拡大ではなく、影の境界を扱う専用武具という異質さ。
