# 割鉄の戦斧

## 画像から確認した造形

茶木柄、赤巻き、灰の大きな片刃。

## 暮らしの中での取り扱い

重い頭を人の足へ倒さない受けに置き、柄を通路へ突き出さない。汚れを拭く卓と食事の卓を分ける。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 重い頭を使って硬い相手を崩す。

造形: 大きい片刃と低い後頭、湾曲を抑えた長柄。斧頭の差し込み穴を見せる。

素材の働き: 木の連続柄を鉄の頬板で挟み、刃頭の抜けを防ぐ。薪割り道具のままにはしない。

現行ワザとの関係: 叩き割りと渾身の一撃は頭の質量、重ね打ちは振り戻せる短い後頭に対応。

発見の魅力: 仕事の道具から専門の武具へ進んだ、重さの頼もしさ。
