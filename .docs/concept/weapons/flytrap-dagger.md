# 双牙の短剣

## 画像から確認した造形

白いギザギザの歯状短刃と緑葉。

## 暮らしの中での取り扱い

小さくても刃を裸のまま私物箱へ入れず、鞘や覆いを付ける。刃物を出したまま眠らず、洗濯物の中へ紛れ込ませない。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 毒塗りと近距離/投擲を使う。

造形: 二層の淡色短剣刃、一つの鋼口金、一つの柄。大きく開く花の口にしない。

素材の働き: 植物の硬化牙を選別し、二枚を積層して刃材へ加工。棘は削り、切断面へ集約する。

現行ワザとの関係: 毒塗り・刺突・投げ散らしを保持。旧説明の蔦縛りは付けない。

発見の魅力: 植物の牙が、白い双層の刃へ研ぎ出される異素材の美しさ。
