# 晶角の穿ち斧

## 画像から確認した造形

茶木柄の赤巻き、紫白の多面体の両頭、赤先端、灰留金。

## 暮らしの中での取り扱い

重い頭を人の足へ倒さない受けに置き、柄を通路へ突き出さない。汚れを拭く卓と食事の卓を分ける。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 一点を狙って崩す斧系武具。

造形: 長短二つの加工結晶頭、厚い中央ソケット、連続した長柄。

素材の働き: 原石を結び付けず、穂の根を面で研磨して金属の受けへ収める。赤紫の筋を断面に残す。

現行ワザとの関係: 打ち砕き・叩き割り・重ね打ちは、長い穂と短い後頭の向きの使い分け。

発見の魅力: 拾った結晶が、硬さを生かした端正な穂へ加工される。
