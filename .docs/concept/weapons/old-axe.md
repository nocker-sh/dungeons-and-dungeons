# 研ぎ減りの戦斧

## 画像から確認した造形

欠けた錆灰の斧頭、茶木柄と白布。

## 暮らしの中での取り扱い

重い頭を人の足へ倒さない受けに置き、柄を通路へ突き出さない。汚れを拭く卓と食事の卓を分ける。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 基礎の打撃戦技を使う旧型。

造形: 小さく減った片刃と太い柄、新しい楔。

素材の働き: 減った刃頭と確かなソケットを対比。古さを腐った柄にしない。

現行ワザとの関係: 叩き割り・渾身の一撃・重ね打ちを支える連続柄を確保。

発見の魅力: 次の品へ進むまで、きちんと働く最初の重い武器。
