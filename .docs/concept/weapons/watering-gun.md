# 滴晶の魔法銃

## 画像から確認した造形

緑のじょうろ型の銃。注ぎ口と握りを保持。

## 暮らしの中での取り扱い

長さのある道具は壁際の受けへ置き、人や出入口へ向けない。手入れの小部品と薬、食事、火を使う作業を分ける。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 味方を支える射撃と通常の攻撃を両立。

造形: 細い古式銃身と本体の小さい緑結晶槽。じょうろ・散水口・運搬取手は捨てる。

素材の働き: 温室の薬材を調整した核を密閉槽で保持する案。薬液の滴を観察窓の内側だけへ限定。

現行ワザとの関係: 治癒弾・魔弾・溜め撃ちを現行のまま。浄化の光など未所持技は加えない。

発見の魅力: 武器で味方を支えられる驚きが、揺れる一滴で伝わる。
