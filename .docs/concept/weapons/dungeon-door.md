# 門衛の剣盾

## 画像から確認した造形

赤茶の木扉と鍵金具。盾のように持つ大型道具。

## 暮らしの中での取り扱い

刃を覆って寝台の外側へ収め、足で跨ぐ置き方をしない。手入れの油は食器から分け、使った布を枕元へ積まない。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 押し返しながら味方の足場を守る。

造形: 太い片手剣と大きめの角盾。建物の扉や巨大鍵を携行しない。

素材の働き: 門の鋼板を切断・再鍛造し、腕で持てる湾曲盾へ仕立てる。鍵穴は小さい鍛造紋。

現行ワザとの関係: 扉で殴るは既存ID/効果を保持し、盾の厚い打撃縁として視覚化。シールドバッシュ・斬り上げとも整合。ワザ名改訂は別提案。

発見の魅力: 街の門の頼もしさを自分の腕へ収めた装備。
