# 使い込みの狩刃

## 画像から確認した造形

細く短い錆刃と白布巻き柄。

## 暮らしの中での取り扱い

小さくても刃を裸のまま私物箱へ入れず、鞘や覆いを付ける。刃物を出したまま眠らず、洗濯物の中へ紛れ込ませない。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 細かい取り回しを重視する旧型短剣。

造形: 腹が浅い片刃、丸い背、手に沿う革柄。old-daggerの三角刃と分ける。

素材の働き: 切断面に大きい欠けはなく、研ぎ減りと柄の摩耗で履歴を見せる。

現行ワザとの関係: 刺突・投げ短剣・毒塗りを保持。片刃の平滑な面を薬剤処理と結び付ける。

発見の魅力: 鑑定で形の違う旧品が出る楽しみ。低性能でも壊れ物には見せない。
