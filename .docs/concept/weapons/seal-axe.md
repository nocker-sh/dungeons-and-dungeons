# 封重の大斧

## 画像から確認した造形

暗灰の斧頭に赤封蝋、赤柄。

## 暮らしの中での取り扱い

重い頭を人の足へ倒さない受けに置き、柄を通路へ突き出さない。汚れを拭く卓と食事の卓を分ける。

## 造形の制作案

制作案であり、画像の採用・承認やゲーム規則の変更を意味しない。

用途: 大質量で崩し、背鉤で引く。

造形: 丸みのある大きい鋼斧頭と短い背鉤、長い革柄。重さは蝋の盛り付けで出さない。

素材の働き: 高密度の祭壇核を斧頭内部へ収め、鋼の外殻と頬板で支持。赤い封止材は接合線だけ。

現行ワザとの関係: 打ち砕き・地鳴らしは核の質量、引っ掛けは短い背鉤へ対応。

発見の魅力: 小さく見える核が、持つと重い。深層の素材感を頭の厚みで出す。
