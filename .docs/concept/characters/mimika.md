# ミミカ

表示名・紹介文・ひとことは [[concept/data/characters.json]]・`dialogues.json`、会話用の口調と来歴の要約は `conversation-profiles.json`、台本は [[content/data/conversations.json]]、役割・ワザ・得意武器は [[content/data/recruits.json]] を正とし、ここには複製しない。

ミミカは影絵の悪魔をモチーフとするNの仲間。宝箱・ミミックの造形を使わず、固有の武器と装備の固定を持たない。

## 制作上の決め事（確定）

- 影絵の悪魔で、職業は影絵師。流派は悪魔。
- 一人称は「あたし」、相手は「あんた」。いたずら好きで、人や物の影の形をほめる。仲間の影だけは切らない。
- ワザ（影の使い魔・影踏み・影絵の牙）は影の設定に合わせたまま変えない。
- 台本で出ている事実：影の濃い道を好む。祭壇まで行けたら仲間の影絵を作る約束をしている（クレフと）。

## 制作案（来歴・想い）

- 稼ぐ理由：街の路地裏に、客席が六つしかない影絵小屋を借りている。谷で稼いだ日当は小屋代と灯りの油に消える。
- 想い：小屋の幕いっぱいに、見た子が声を上げる影絵を映したい。谷の底は影が濃いので、新しい形の練習場にもなっている。
- 小道具・習慣：自分で切った紙の切符を持ち歩き、気に入った相手に渡す。切符はいつも一枚多く切る。
- 切なさの種：悪魔の見た目を怖がって、客はなかなか来ない。前は毎晩来ていた子が大きくなって来なくなり、その子の席だけは今も空けてある。
- 一緒に働きたい理由：いたずらは驚かせて終わりで、怪我をさせない。疲れた夜の宿で、天井いっぱいに影絵を映してくれる。

## 見た目（作り直し）

短く左右非対称な藍色のボブに、片側だけ白い房。小さな角と、べた塗りの紫の目。口を閉じて片方の牙だけ見せるすまし顔で、横目で見る。裾を鳥・猫・星の切り絵の形に切った紺のケープ。手には何も持たず、胸の前で指を組んで影絵のキツネを作る。足元の影から角のある小鬼の切り絵が顔を出す（影の使い魔）。旧デザインの白いツインテール・赤いリボン・青緑の目・宝箱・大きな鍵は使わない。

## 制作メモ

- 以前の固有の武器「大きな鍵」は「影切りの鋏」に名前を変えたが、N になって使う仲間がいなくなった。旧保存の互換のため品物のデータは残している。
- 画像は作り直した。現在の全身は `character_23_mimika_v5`、胸像は `character_23_mimika_v6_bust_*`。v2 は鋏を持ち、顔と角度がクレフと似ていたので使わない。
- 着替えの上半身は、ユーザー指摘「装備で頭が小さすぎ。腰が下になるように」で `outfit_mimika_*_bust_waist`（robe・vine-armor は `_bust_waist_v2`）へ作り直した。頭の大きさと腰を下端に置く構図は会話の上半身 `v6_bust_normal` に合わせる。旧 `_bust_tone` は頭幅が肩幅の約0.4〜0.47で、袖が左右の枠に接していた。

## 画像から確認した造形

現行の全身v5・胸像v6は、左右非対称の短い藍色髪と白い一房、小さな黒角と尖耳、べた塗りの紫眼、片牙の閉じた口、切り絵形の裾を持つ紺ケープ。手は空で胸の前に影絵を作る。大鋏を持つv2、巨大鍵・箱を持つ白髪の初期案を現行へ混ぜない。旧胸像v3の元PNGは裾まで入り、公開WebPは胸上へ切り抜かれているため、同じ構図として比較しない。

## 生活動線の制作設計

六席の影絵小屋では客席から出口までを空け、舞台の灯りを紙から離す。空けておく一席を物置にせず、片付け後に休む。

## 整合性を守る境界

客席を増やすために固有の一席をなくさない。興行の成功を決定済みの未来にしない。

来歴・会話・報酬をこの生活設計から書き換えない。収納と休息の場所は、ゲーム内の追加効果を意味しない。
