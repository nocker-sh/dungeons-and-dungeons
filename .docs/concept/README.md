# 設定資料

一つの対象に一つの正本JSONと、その説明資料を対応させる。構造化データは[[concept/lore]]、本文は意味・理由・未決定事項を所有し、値を重複させない。人物・生物は固有の造形、来歴、関係、暮らしを、場所は用途、配置、設備、移動経路を記す。名前とIDだけの索引は作らない。

形式と検査は[[concept-data|資料の規約]]、生活設計の共通条件は[[concept/world/world-living|生活の共通方針]]を参照する。ゲームの確定仕様は[[game-spec]]、文章の調子は[[writing-tone]]、画像の共通条件は[[image-generation]]を正とする。

実行用JSONと同じ名前・紹介文・台詞・画像一覧を転記しない。日付別の作業報告、一時ファイル、検証件数、生成プロンプトを設定本文へ積み上げない。

出典が支える事実と制作案を区別する。意図的に伏せた生死や謎を補完しない。部屋の生活設備と動線は関連する資料の両側で整合させる。
